# 유미당

## 행사 화면·연결 기준

일반 작성의 행사 영역은 하단, 행사 상세 진입은 상단이다. 행사 기간과 만남 일정 겹침을 강제하지 않고 검색을 날짜로 자동 축소하지 않으며 달력에 행사 날짜만 강조한다. 직접 입력은 공고 전용이다. 공식 동일 행사 근거가 확인된 원천만 통합하고 필드별 출처·원천 ID·공고 관계를 보존한다. 비표출 원천 자료는 숨기되 다른 공개 원천은 유지하며 핵심 정보 충돌은 안내하고 새 연결을 제한한다.

직접 입력 저장·등록 검증 변경·동일 행사 통합·상태/비표출 안전 응답·핵심조건 변경·앱 안 알림은 민규 서버 계약/구현 연결이 필요하다. 문서·UX 모형과 실제 앱/DB/운영 완료를 구분한다. [행사 UX 확정 명세](docs/collaboration/requests/jonghyun/2026-10-20-event-ux-approved-spec.md) 및 [정책8장](정책.md#8-행사-탐색과-공식-순위)을 따른다.


브랜치를 받은 뒤 “나 종현이야”·“나 유미야”·“나 민규야”라고 입력하면 [팀원별 시작 안내](docs/collaboration/team-start.md)에 따라 Notion 담당 작업을 바로 이어간다.

## 현재 팀 역할
