# 유미당

## 현재 팀 역할

BE·AI·서버 운영은 민규 전담, FE·UX/UI·앱·서비스 연동·빌드 준비는 종현, PM/기획·브랜딩·UT는 유미, 정책은 유미·종현 공동 정리, QA는 공통 담당이다. 성호의 현재 담당은 제거했다. [담당 재배정](docs/collaboration/requests/minkyu/2026-10-14-role-reassignment.md)·[소유권 정책](backend/ownership.json)·[협업 규칙](docs/collaboration/README.md)을 따른다. 기존 이름이 든 경로와 완료 증거는 보존한다.


성인 여성의 무료 1:1 동행 서비스입니다. 현재 기준은 [정책.md](정책.md)와 사용자의 최신 답변입니다.

- [PRD](docs/planning/requirements/PRD.md) · [IA](docs/planning/design/IA.md) · [사용자 흐름](docs/planning/design/USERFLOW.md)
- [계획](PLAN.md) · [상세 설계](PLAN_상세설계.md)
- [와이어프레임](docs/planning/design/유미당%20와이어프레임.html)
- [작업 지침](AGENTS.md) · [협업 규칙](docs/collaboration/README.md)
- [종현 업무](docs/collaboration/jonghyun.md) · [민규 업무](docs/collaboration/minkyu.md) · [백엔드 연결](backend/README.md)

문서는 현재 정책 본문으로 관리합니다. 과거 정책·승인·검증 원문을 현재 문서에 덧붙이지 않습니다. 와이어프레임은 합성 자료와 로컬 상태로 화면·행동을 검토하는 도구이며 실제 네이버·AI·행사 공급사·DB 연결 성공을 의미하지 않습니다.

서버 코드·SQL·소유권·배포 설정은 이번 동기화 범위 밖입니다. 기존 구현과 최신 요구사항의 차이는 담당 계약에서 확인하고 승인된 후속 구현에서 검증합니다. 포텐스닷 회신, AI 가입 필수 동의 적합성, 신고 담당과 운영 준비 등은 정책 상단에 남깁니다. 비밀 환경 파일을 공유하지 않습니다.
