# 민규 진행 작업 현황

현재 작업은 [정책.md](../../정책.md)의 최신 사용자 답변을 문서에 동기화하는 작업이다. 코드·DB·HTML·공급사·배포는 이번에 변경·검증하지 않았다. 아래 기록의 완료율·검사 수는 당시 범위이며 현재 서비스 전체 완료율이 아니다.

## 현재 기준과 다음 작업

1. 네이버 전용·무료 1:1·필수 사진/선택 성향, 기존 계정 제한·복구 경계를 계약과 실제 코드에 대조한다. 학교메일은 추후, 유료·1원인증 세부는 팀 검토다.
2. 연결 행사명 검색·작성자 만 19~99세·공고 수정/마감/삭제·최종 동의 한 명 요청/24시간 또는 시작 시각 만료·미선정 대화 종료·취소 후 정보 숨김을 연결한다.
3. 예상 종료 후 개인 완료 확인에 따른 선제 후기 제출과 실제 동행 완료를 분리한다. 실제 완료 전 비공개, 실제 완료+7일 작성 마감/한쪽 24시간 공개, 양쪽 후기와 완료 조건 충족 시 즉시 공개·당도 열람 가능 시·횟수 완료 시 반영을 각각 검증한다.
4. 행사 정렬과 KOPIS 전국 전체 공연 Top 10·뮤지컬 전환·어제까지 최근 7일·일일 갱신을 연결한다. 서울 열린데이터 연결 조건·연결 여부는 팀 검토다.
5. AI 추천 설명·개인정보 전송 차단/출력 숨김·원문 미저장·실제 회원 원문 외부 전송 보류, 운영자 채팅 DB 직접 접근 금지·제출 캡처 접수를 반영한다. 팀 보류 숫자·정책을 임의 구현하지 않는다.

역할별 구현 경계는 [상세 설계11장](../../PLAN_상세설계.md#11-2인-담당-업무와-협업-경계), 현재 남은 공통 연결은 [R1~R7](requests/jonghyun/2026-09-29-claude-minkyu-requests.md), 세부 작업은 [종현 계획](../../260929_종현담당_PLAN.md)을 따른다. 자기소개나 이 목록을 코드 실행·외부호출·배포의 새 승인으로 해석하지 않는다. 이미 승인된 작업은 같은 확인을 반복하지 않는다.

## 기존 구현의 재사용 근거

[결함5건 수정](requests/jonghyun/2026-09-30-five-defects-fixed.md)과 [Git 통합 인계](requests/jonghyun/2026-09-30-jonghyun-integration-handoff.md)는 기존 구현·로컬 검증 근거다. 어댑터·검색·F1~F5를 다시 처음부터 만들지 않는다. 정식 제안 SQL 채택·허용 목록·공통 HTTP·환경·CORS·실제 AI 품질·운영 배포와 최신 정책 반영은 각각 별도다.

## 다음 대화에서 재개할 순서

현재 폴더·브랜치·미커밋과 정책을 확인하고, 승인된 작업 범위에서 계약→영향 코드→필요한 검사 순으로 진행한다. 실제 공급사 조건·보관·법률·기술 검증과 사용자 정책 선택을 구분한다. 지침·소유권·hook을 바꾸어 검사 우회하지 않는다. 문서 작업만 끝난 것을 기능 완료로 표시하지 않는다.

# 민규 업무 연결 실시간 진행

이번 요청의 5개 항목을 각각 계약·구현·개별 검증·실제 연결의 4개 확인점으로 추적한다. 전체 서비스 출시 진행률과 다르다.

현재: **100% (20/20 확인점, 이번 로컬 구현·검증·인계 범위)**. 실제 JWT·Deno HTTP·Supabase 연결 시나리오 8개 PASS. 단위 81개·SQL 6개 스위트·경쟁 6개·실제 JWT/HTTP 8개 PASS. 전달 문서·보존 감사와 전용 로컬 환경 중지 완료.

| 항목 | 진행률 | 현재 상태 |
|---|---:|---|
| 양측 완료 | 100% | 양측 확인·재요청·실제 API PASS |
| DB·인증 | 100% | 단위14개·실제 JWT 검증·역할 분리 PASS |
| 업무 API | 100% | 단위22개·실제 핵심 흐름 PASS |
| 후기 자동화 | 100% | 실제 HTTP 공개·중복 없는 큐 등록 PASS |
| 통합 검증 | 100% | 로컬 통합·문서·소유권·332개 기존 파일 보존 PASS, Supabase/Colima 중지 완료 |

보류 대상: PASS/문자/계좌 실제 공급사, 미정 분쟁 판단·계좌 효력 정책, 외부 모델 설정, 칭찬 키워드 허용 목록. 보류 대상 외 구현은 계속한다.

NOT_RUN: 관리형 Edge 호스팅/gateway, 외부 인증·계좌 공급사, 외부 AI 모델·예약 실행·프런트엔드 전체 연결, 원격 DB·운영 배포. 전체 서비스 출시나 민규 업무 전체의 완료율이 아니다. 이후 사용자가 여기까지 커밋·푸시를 요청했다. 반영 결과는 Git 로그·원격 브랜치로 확인한다. 후속 준비와 재개 순서는 [민규 현황](minkyu.md#다음-대화에서-재개할-순서)에 기록했다.
