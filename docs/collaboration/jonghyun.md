# 종현 현재 작업과 연결 상태

기준은 [정책.md](../../정책.md)와 사용자 최신 답변이다. 현재 구현은 `.worktrees/jonghyun-policy-integration`의 `jonghyun/policy-integration-20261005` 브랜치에 있으며 루트 체크아웃과 분리했다. 이 현황은 해당 구현 커밋에 포함하며 원격 반영 여부는 Git 기록으로 확인한다. 최신 세부 인수인계는 [정책 구현 인계](requests/jonghyun/2026-10-05-policy-implementation-handoff.md)를 따른다.

## 구현한 영역

- 검색: 16개 분류·17개 시도·만19~99 숫자 범위·전체 상한 없음·비로그인 일정/나이 제한·작성자 정보 미반환·권한/필터에 묶인 커서. 기존 `search_public_posts_v2` 이름을 유지하고 `p_contract_version:'2026-10-05'`, `p_region`, `p_filters`, `p_cursor`, `p_limit`을 전달한다. HTTP는 `ageMin/ageMax`다.
- AI 탐색: 회원당 동시1개 점유·첫 모델 시작 시 KST 하루20회 차감의 원자 RPC 어댑터, 철회/전송 준비 확인, 출력 개인정보 중단, 요청 전체 자동 재시도1회, 후보 현재 권한 재조회와 성향 조건 설명. 공식 공급사 준비·승인된 안전 검사기 없이는 실제 원문 전송을 중단한다.
- 후기 요약: 적격 공개 텍스트 후기3개 이상·전체 근거 분할/재개·최대300자·현재 revision/작업/전역 점유 검사·작성자/대상자 철회 효과 분리. 일반 공개 후기와 AI 요약 상태를 분리했다.
- 행사·장소: 이번 주 신규 중 미종료·진행 중 포함·과거 조회·목요일 귀속 월 주차·콘서트 음악3종·공식 무료 판정·공식 Top10 전체/뮤지컬·공급사 상세·장소10개·공식 우편번호 선택. 공급사 장애를 정상0건으로 저장하지 않는다.
- 작업 실행: 일일00:01 멱등 등록/초기 호출과 별도 상주 후속 처리·180초 점유·10작업/60초·연장 없음·실패 영역별 재시도·Top10 모드별 영속 작업과 원자 완료. 자동 완료의 기존 별도 실행기를 재사용한다.
- 모바일: 미리보기와 실제 API 모드를 분리했다. 공고·행사·프로필·후기·칭찬·요약·AI·장소/주소/행사 선택을 연결하며 오류와 빈 결과를 구분한다. 실제 인증/공통 변경 API가 없으면 저장·신청 등을 성공으로 표시하지 않는다.

## 민규와 실제 환경의 남은 연결

공통 인증·HTTP·DB 클라이언트·SQL·설정은 민규만 수정한다. 현재 `service-api/search-http.ts` 구 연령대 타입 때문에 공통 HTTP 타입 검사에 실패한다. 최신 검색/요약/행사/AI 한도·피드백 RPC와 DB 권한, 네이버 세션·Storage·프로필/행사 추가 조회 경로를 연결해야 한다. 정확한 인수·반환·원자 검사 기준은 인계 문서와 [검색](../../backend/contracts/search.md)·[AI](../../backend/contracts/ai-chat.md)·[요약](../../backend/contracts/review-summary.md) 계약에 둔다.

확정/변경6시간 만료·완료+7일 후기 공개·분쟁·당도·제재·탈퇴·실명/상세 위치는 공통 HTTP/SQL의 실제 검증이 남았다. 종현은 이 파일들을 직접 수정하지 않았다. 공개 프로필 사진·작성자 프로필 연결 ID·행사 연결 공고 조회도 공통 연결이 필요하다.

서울의 보안 연결/진행 중 갱신 어댑터는 사용자 A안으로 보류하며 전체 담당 구현은7/8≈88%다. HTTP의 API 키 도청·행사 응답 변조 위험을 정책과 인계 상단에 명시했다. 3개 공급사 출시 목표는 유지하고 완료한 나머지 작업을 커밋·푸시한다. 공식 HTTPS 미리보기/다운로드의 존재와 자동 수집 계약 미확인을 구분한다. KOPIS·TourAPI는 상세 자동 큐와 ID별 갱신을 합성 검증했다.

공급사 규격/보관/출력 토큰 상한·합성 품질 공동 검토·비용/담당 배정은 정책의 팀 검토를 유지한다. 실제 회원 데이터 전송·DB 동시성/철회·상주 호스트 복구·iOS/Android 기기·배포·스토어·UT/QA는 실행하지 않았다. 최상위 PLAN의 과거 소스 차이 목록을 현재 코드 상태로 갱신할 작업은 민규에게 인계한다.

## 검증 상태

현재 owned 단위/합성 테스트415개와 탐색 합성 연동5개가 통과했다. 프론트 최종 검사 수치는 인계 문서에 기록하며 부분 검사를 실제 운영 성공으로 확대하지 않는다. DB 회귀 검사는 전용 로컬 DB 환경이 준비되지 않아 미실행이다. 각 소스·검증 파일은 현재 브랜치에서 확인한다.
