담당 코드의 초기 구현·합성 검증 완료는 전체 AI 출시 준비 완료를 뜻하지 않는다. 민규 공통 연결 외에도 다음 과제가 남아 있다.

- AI 개인정보 검사기의 실제 연결·검증.
- 후기 요약의 의미·근거 검사기와 AI 설명 의미 검사기의 실제 연결·검증.

- 새 다중 계정 기능의 계정 선택·사용량 매핑·정산·소진 판단·전체 소진 처리. 민규 공통 설정·DB/RPC와 함께 연결한다.
- KOPIS 순위 기간 증명과 서울 HTTPS 수집 경로 등 공급사 확인 후 보류 영역 재검증.

다중 계정 환경변수와 담당 계약 제안은 [민규 연결 요청](requests/jonghyun/2026-10-05-current-connection-requests.md)에 추가했다. [포텐스닷.md](../../포텐스닷.md)는 제공 약관·개인정보·보안 원문의 검토 근거로 유지하며, 사용자 요청으로 민규 원본 폴더에서 종현 작업본으로 내용 동일 확인 후 이동했다. 공식 회신·출처 확보 후 중복 여부를 다시 판단한다. 현재 민규 원본 폴더와 종현 별도 작업본은 다른 브랜치이며 최신 변경은 아직 공유 브랜치에 합쳐지지 않았다.

현재 보류 항목은 본 연결·운영 검증 기준이다. 개인정보·요약/설명 의미 검사는 승인된 검사 기준/포트와 개인정보 조건 확인 후, 출력 상한은 공급사 공식 지원 필드 확인 후, KOPIS·서울은 공급사 근거/보안 경로 확인 후 연결·재검증한다. 설계·합성 준비는 일부 먼저 가능하다. 사용자가 팀원 동의 확보와 진행을 승인해 다중 계정 선택·예약·정산 모델 포트를 구현했고14개 단위 검사와 타입 검사를 통과했다. 운영 런타임은 미연결이며 민규 공통 계약과 확정된 예산의 실제 설정·원장 적용이 필요하다. [최신 연결 인계](requests/jonghyun/2026-10-06-potens-account-pool-handoff.md)를 따른다.
