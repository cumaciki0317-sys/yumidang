## 종현이 준비·결정할 것

2026-09-23 최신 지시: **실제 DB·외부 API 연결은 대기**한다. 외부 API 어댑터는 종현 담당이고, DB 구조·권한·공통 인증·환경은 민규 담당이다. 실제 연결과 통합 검증은 협업 단계다. 아래의 자료 준비나 미정 정책 확인은 계속할 수 있다.

| 항목 | 종현이 준비·결정할 것 |
|---|---|
| 우편번호 주소 선택 | **확정:** Kakao 우편번호 서비스 사용. 공급사 선택은 완료했고 실제 주소 선택창 연결은 대기한다. |
| Kakao 장소 검색 | **미정·팀원 확인:** 사용할 앱·API 이용 권한·키 준비 상태를 팀원에게 확인한다. 비밀값은 대화/문서에 넣지 않고 민규와 환경 주입 방식을 연결한다. |
| 행사 제공처 자료 | **미정·팀원 확인:** 계획의 **KOPIS·서울 열린데이터광장·TourAPI**별 이용 신청·키 준비 상태를 확인하고 공식 API 문서·응답 예제를 준비한다. 실제 제공처 변환 코드·DB 페이지 연결은 남아 있다. |
| 행사 수집 범위·주기 | **미정·팀 결정:** 제공처의 과거 조회 가능 범위를 확인한 뒤 최초 수집 기간을 결정한다. 제공처별 갱신 주기도 미정이다. 과거 행사를 볼 수 있는 정책 자체는 이미 확정이다. |
| 포텐스닷 API | **기본 안내 수령:** HTTP 주소·인증·요청 필드·모델 목록 안내 확보. 성공/한도 오류 응답 예제·정확한 토큰 구조·출력 제어·계정 한도·무료 조건은 추가 확인. 예제의 키가 실제 키면 폐기·재발급 준비. 최종 모델은 미정이다. |
| AI 모델·개발 예산 | **미정·팀 검토:** 실제 AI 개발·검증 비용의 금액·기간. 승인된 유료 호출 예산은 없다. 대체 모델도 미정이며 같은 사례의 품질·속도·비용 평가를 거쳐 결정할 필요가 있다. |
| 외부 AI 원문 보관 | **미정·팀 검토:** 미보관 요구 자체, 허용 보관 범위·기간·법률/안전 예외. 유미당 서버의 대화 이력·원문 로그 미저장은 확정이다. |
| AI 품질·검사 방식 | **미정·팀 검토:** 실제 모델의 합격 기준, 설명/요약 의미·개인정보 검사 방식. 현재 의미 검사기는 가상이며, 실제 설명/요약 품질은 검증 전이다. |
| 운영 한도 | **미정·팀 검토:** 입력/출력·사용자별 호출량·시간 제한, 작업 실행 주기·점유 시간·재시도 간격/횟수·동시 처리 수. 테스트 수치는 운영값으로 사용하지 않는다. |
| 지표·중간 결과 보관 | **미정·팀 검토:** 지표 저장 위치·보관기간·대상 가명 ID 사용 여부, 방치된 중간 요약의 최대 보관기간. 완료/폐기/후기 변경 시 중간 결과 정리는 확정이다. |
| 공통 검색 반환 계약 | **민규 협업 대기:** 표시 이름의 마스킹 규격·시군구·신청 자격, 나이 필터·페이지/커서·전체 요청/응답 규격. |
| 실제 DB·API·화면 연결 | **대기:** 민규의 DB/RPC·권한·인증·공통 환경에 종현 모듈 연결 후 통합 검증. HTTP 진입 파일은 아직 골격이며, 화면 연결 담당·시점도 협의가 필요하다. |

우편번호는 Kakao로 확정했고 AI 검증 예산은 팀 검토 미정으로 남겼다. 포텐스닷 기본 호출 안내를 받았고 키를 제외한 규격만 별도 기록했다. Kakao/행사 API 준비 여부는 팀원 확인, 과거 수집 범위는 제공처 범위 확인 후 팀 결정, 운영·보관·품질 기준은 팀 검토용 미정으로 정리하라는 답변을 받았다. 현재 질문한 항목은 모두 답변을 받았고, 팀 검토 항목의 실제 값은 아직 확정하지 않았다. 재개 중 새 충돌이 생기면 질문하며 미응답을 확정으로 처리하지 않는다. 외부 보관 요구는 사용자 지시대로 팀 검토 대상에 유지한다.

## 이번 보완 사항

- 외부 AI 미보관 필수 조건을 팀 검토 대기 상태로 변경했다. 기본·대체 제공사 각각 결정 참조를 확인하며, 실제 제공사는 구성하지 않았다. 유미당 서버의 대화 이력·원문 로그 미저장은 유지한다.
- 행사 검색 범위를 사용자 답변대로 구현하고 AI→키워드/기간/지역/종류→행사 결과 연결을 합성 데이터로 확인했다.
- 원문 없는 지표 수신 계약을 구현했다. 임의 metadata·오류 원문·개인정보·미등록 버전·잘못된 사용량·중복 기록 경로를 가상 수신부로 검사했다.
- 우편번호 공급사 선택은 완료했고 실제 주소 선택창·API/DB·권한 연결, 모델/예산·운영 수치·품질 검사는 남아 있다. 미응답이나 테스트용 값을 승인된 운영 설정으로 사용하지 않는다.
