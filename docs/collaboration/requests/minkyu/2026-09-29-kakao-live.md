# Kakao 장소 검색 실호출 진단 — 2026-09-29

## 실제 결과

- 최신 재검증: `execution=PASS`, HTTP `200`, 안전한 분류 `PUBLIC_QUERY_SUCCEEDED`.
- 사용자가 카카오맵 사용 설정을 ON으로 변경했다고 알린 뒤 총괄이 기존 도구로 **서울역, page=1, size=1** 최소 조회를 한 번 실행했다. 장소 검색 최소 요청이 성공했고 응답의 documents 목록·meta 및 최대 1건 형식 검사를 통과했다. 실제 반환 건수는 출력하지 않았으므로 1건 반환을 확인했다는 뜻은 아니다.
- 이전 이력: 첫 요청은 `execution=FAIL`, HTTP `403`, `MAP_LOCAL_SERVICE_DISABLED`였다. 응답의 오류 종류와 지도·로컬 서비스 비활성화 고정 문구를 메모리에서 확인했다.
- 누적 실제 요청은 **2회: 설정 변경 전 403 1회 + 사용자 ON 완료 고지 후 200 1회**다. 계정 설정은 사용자가 변경했으며 도구나 에이전트가 변경하지 않았다.
- 앱 이름·키·오류 원문·검색 결과는 문서나 출력에 기록하지 않았다. 이번 성공은 공식 장소 검색 최소 요청의 입력·접근 검증 결과이며, 다른 API·계정 과금 조건·전체 장소 연동 완료를 검증한 것은 아니다.

## 계정 설정 조치와 다음 단계

사용자는 입력한 REST API 키의 앱에서 카카오맵 사용 설정을 ON으로 변경했다고 알렸다. 공식 문서의 **[카카오맵] → [사용 설정] → [상태] ON** 요구에 따른 조치 후 동일한 최소 요청의 HTTP 200을 확인했다. 민규의 이번 활성화 확인·재검증은 완료했으며, 다음은 종현 담당 장소 어댑터 연결과 실제 처리 검증이다. [카카오맵 공식 사용 안내](https://developers.kakao.com/docs/ko/kakaomap/common)

공식 안내는 2026-07-21부터 개발자 계정의 첫 활성화 앱에 무료 쿼터를 제공하며, 두 번째 이후 앱 또는 무료 쿼터를 초과하는 경우 유료 API 설정이 필요하다고 명시한다. 현재 계정의 첫 활성화 앱 여부·결제 설정은 확인하지 않았다. 도구에서 계정 설정을 바꾸거나 유료 사용을 활성화하지 않았다. [카카오맵 공식 사용 안내](https://developers.kakao.com/docs/ko/kakaomap/common)

공식 공통 오류의 `-3`은 기능 활성화 또는 사용 가능 API 호출 허용 설정, `-5`는 API 요청 권한 문제로 구분한다. 최초 403 응답은 지도·로컬 비활성화에 대한 별도 고정 문구로 분류했다. callback URL을 추가하면 해결된다고 단정하거나 임의 URL·다른 키를 사용하지 않는다. [공식 REST 오류 코드](https://developers.kakao.com/docs/ko/rest-api/error-code)

## 도구와 검증

- 도구: `tools/local/check_kakao_api.py`.
- 기본 실행은 키 입력 형식만 확인하고 `NOT_RUN`을 출력한다. 실제 공식 HTTPS 조회는 `--run`을 명시한 경우에만 실행한다.
- 사용 예시: `python3 -B tools/local/check_kakao_api.py --env-file <본인 로컬 .env 절대 경로> --run`.
- 기존 dotenv 읽기·파싱 도구를 재사용하며 입력 파일은 읽기만 한다. 명령 인수에 키를 넣지 않고 `/usr/bin/curl`의 표준입력 설정으로 인증 헤더를 전달한다.
- 시스템 TLS 검증을 사용한다. 고정 HTTPS 주소만 요청하며 리디렉션·재시도·TLS 검증 생략을 허용하지 않는다. 연결 5초·요청 15초·프로세스 20초·본문 64KiB 제한을 둔다.
- stdout은 허용된 분류·HTTP 상태·공식 코드만 출력한다. 응답 원문·stderr·예외 메시지를 출력하거나 파일에 저장하지 않는다.
- 독립 테스트 **7개 PASS**: 기본 무호출, 키의 인수 제외, 헤더·설정 주입 거절, 403 고정 분류, 원문 미노출, 네트워크·본문 제한, CLI 입력 오류.
- 실제 호출: **누적 2회**, 최초 403·사용자 활성화 후 재검증 200. 최신 최소 요청 검증은 PASS이며 종현 어댑터·서버 경로 통합 검증과는 구분한다.

## 담당 경계

민규는 입력·권한 문제 진단 및 계정 준비를 담당한다. 종현의 장소 어댑터·검색 코드·서버 진입점은 수정하지 않았다. 계정 활성화 후 최소 요청 성공을 확인했으므로 종현은 담당 어댑터 연결·실제 처리 검증을 진행할 수 있다. 원격 DB·배포·커밋·푸시는 수행하지 않았다.
