# 종현 요청: 출시 빌드 입력 확정

WBS 6.4a·8.19·8.22·8.23 / 민규 / 2026-10-21

HEAD `1ec4f62`의 `apps/mobile/app.json`을 읽었다. 앱 이름은 유미당·버전은 1.0.0이며 이 파일에는 `android.package`와 `ios.bundleIdentifier`가 없다. 이 사실만으로 다른 빌드 설정·외부 서명 자료가 없다고 단정하지 않는다.

종현은 최신 소유권에 따른 별도 작업 공간에서 실제 사용 중인 Android package ID·서명된 AAB/APK·versionCode·커밋/해시·설치 방법·API 환경을 연결해 달라. 이미 확정한 package ID·서명 자료가 있으면 그 원본을 사용하며 임의로 새 식별자나 서명을 만들지 않는다. iPhone은 bundle ID·서명/프로비저닝·실제 설치 가능 조건을 구분한다.

현재 Play Console의 유미당 이름 검색에는 일치 결과가 없다. 계정은 개인 계정이며 연락처 인증 표시는 확인했지만 생성일과 유미당 앱별 테스트·출시 권한은 미확인이다. 다른 앱의 프로덕션 상태를 유미당 권한으로 승계하지 않는다. 새 앱 생성·업로드·제출·공개·결제는 이 요청 문서에서 실행하지 않았다.

공동 QA·실회원 검증은 사용자 재개 전 HOLD다. 민규는 앱/FE 파일을 수정하지 않았고 이 문서는 저장소 내부 요청이며 외부 메시지는 보내지 않았다. 전체79%(22/28)를 유지한다.
