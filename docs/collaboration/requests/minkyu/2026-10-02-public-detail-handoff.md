전체100%목표와43%·6/14 유지. 정책.md의 비로그인 공고 목록·상세 허용을 기존 get_service_post SQL 투영과 연결한다. 현재 handler의 모든 일반 경로 회원인증 강제를 정확한 공고 상세 GET에 한해 공통 optional principal과 좁은 public client로 연결한다. 잘못된 인증은 익명으로 강등하지 않는다.

신규 단위15개가 모두 통과했다. 기본 runtime을 실제 로컬 Auth·PostgREST·DB에 연결한 통합 검사도 최종 `PASS`, checks346, nativeAuth=true, syntheticCleanup=true로 종료했다. 익명 별칭·비공개 제외, 일반 회원 마스킹, 작성자 본인 입력, 신청·최종 동의 전 제한, 양쪽 확정 당사자의 실명/주소 공개, 취소 후 신청자의 재마스킹, 삭제/없는 공고404, 잘못된 토큰/헤더에 익명 fallback 없음이 검증 범위다.
