# 격리 로컬 환경 준비

> 현재 기준: [정책.md](../../../../정책.md) · 문서 기준일: 2026-10-05

prepare_database.py 의 정식 SQL 목록·현재 HEAD 해시·pending 제안을 확인하고 중복 버전/사본을 거절한다. 원본 .env 와 다른 실행 환경은 보존하고 임시 검증 폴더만 사용한다. 준비 복사 성공과 실제 DB 재생은 별도 판정한다.

## 환경 준비·운영 전환

실행 전 실제 프로젝트·브랜치·미커밋·migration 목록과 적용대상 SHA를 확인한다. 고정된 과거 개수나 원격상태를 현재 사실로 재사용하지 않는다. 기존자료를 초기화하지 않고 합성검사는 격리환경에서 명시된 식별자로 생성·정리한다.

원격 구조·함수·권한·스케줄 drift, 백업과 DB/Storage 복구, 비밀주입·호스트·재시작·최소권한을 준비한다. 완료예약 RPC·실행기 READY·기한경과복구·기존cron전환을 한 계획으로 다루고 cron해제만 먼저 하지 않는다. 일일00:01 등록과 행사/요약 분리실행도 실제검증이 필요하다.

원격 변경은 구체적 목록·영향·복구안·검증 결과를 갖춘 별도 실행범위로 다룬다. 문서 동기화가 DB/외부API/배포·커밋·푸시 승인을 뜻하지 않는다.

## 확인할 범위

현재 정책에 맞춘 코드·SQL 적합성, 실제 Auth/DB/HTTP, 브라우저, 공급사, 운영 배포를 각각 확인합니다. 이번 작업은 문서만 갱신했으며 이 기능의 실행 검증을 수행하지 않았습니다. 필요한 변경은 담당별 허용 경로에서 진행하고 기존 코드·SQL·실제 자료를 변경하는 승인은 별도로 확인합니다.
