# TourAPI 최소 실조회·전송 방식 검증

2026-09-29 민규 10차 하네스 lane C. 기준 `ff9c14fec069dc03b575cfd33d9deb62625fd924`. 수정 파일은 `tools/local/check_tour_api.py`, `tests/functions/minkyu/test_tour_api.py`, 이 문서로 한정했다.

## 결과

**실제 공식 HTTPS 조회 PASS: HTTP 200, 공급사 코드 `0000`, 반환 1건, 빈 결과 아님.** 현재 저장된 키 원문을 URL 쿼리 값으로 한 번 직렬화한 전송이 유효함을 확인했다. `TOUR_API_KEY_FORMAT=unknown`은 그대로 보존했고 사용자 입력 파일은 수정하지 않았다. 발급 화면의 encoded/decoded 구분을 자동 판정했다는 뜻은 아니다.

실키 요청은 총 2회였다. 첫 요청은 HTTP 200을 받았으나 검사기가 정상 코드를 `00`만 허용해 `PROVIDER_ERROR/UNKNOWN`으로 보고했다. 응답 원문은 저장하지 않아 최초 응답의 실제 코드·본문은 사후 확인할 수 없다. 공식 매뉴얼의 `0000` 예시를 확인하고 파서를 보완한 뒤, 같은 원문·직렬화·날짜·건수로 명시적 재검증 1회를 수행해 위 PASS를 얻었다. 인코딩 전환이나 자동 재시도는 없었다.

```json
{"provider":"tour-api","serialization":"RAW_INPUT_URLENCODE_ONCE","key_format_detection":"NOT_RUN","config_modified":false,"status":"PASS","http_status":200,"provider_code":"0000","returned_count":1,"empty":false,"connection_check":"RUN","input_key_format":"unknown"}
```

## 공식 요청 근거

[공공데이터포털의 한국관광공사 국문 관광정보 서비스](https://www.data.go.kr/data/15101578/openapi.do) 원본 HTML에 포함된 Swagger를 확인했다. 웹 텍스트 추출에서는 빠졌던 상세 계약이 원본 HTML에 있었다.

- host는 `apis.data.go.kr/B551011/KorService2`, schemes에 HTTPS가 포함된다. 사용한 경로는 GET `/searchFestival2`다.
- 필수 query는 `serviceKey`, `MobileOS`, `MobileApp`, `eventStartDate`다. `eventEndDate`, `numOfRows`, `pageNo`, `_type`도 공식 인수다. 서비스키 예시는 URL Encode를 명시한다.
- 이번 요청은 `MobileOS=WEB`, `MobileApp=YumidangValidation`, 시작/종료일 `20260929`, `numOfRows=1`, `pageNo=1`, `_type=json`을 사용했다. 추가 페이지나 상세 조회는 하지 않았다.

포털에 연결된 [공식 참고 매뉴얼 ZIP](https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=FILE_000000003603931&fileDetailSn=1)의 `한국관광공사_개방데이터_활용매뉴얼(국문)_v4.4.docx`에서 정상 응답 예시 `resultCode=0000`, `resultMsg=OK`를 확인했다. 같은 문서의 공통 코드표에는 `00=NORMAL_CODE`도 있다. 검사기는 이 두 코드와 응답 자료형·반환 건수를 함께 검증한다. 다운로드 제한 확인은 `needCaptcha=false`였으며 문서는 메모리에서만 열람했다.

## 검사 도구와 재현

기본 실행은 `NOT_RUN`이며 입력 파일을 읽지 않는다. 실제 요청에는 세 인수 `--run --raw-input --env-file`을 모두 명시해야 한다.

```sh
python3 -B tests/functions/minkyu/test_tour_api.py
python3 -B tools/local/check_tour_api.py
# 실제 재검증이 필요한 때만 실행한다. 날짜는 원하는 최소 하루로 지정한다.
python3 -B tools/local/check_tour_api.py --run --raw-input --env-file /Users/minkyu/Documents/GitHub/yumidang/.env --event-date 20260929
```

기존 `check_api_env.py`의 읽기 전용 dotenv parser를 사용하고 파일을 실행하지 않는다. 키는 `urlencode`에 값으로 한 번 전달하며 %, +, / 등의 모양을 보고 사전 decode·형식 추정을 하지 않는다. 키가 포함된 URL은 curl 명령행 인수가 아닌 stdin config에 전달한다. `/usr/bin/curl -q`로 사용자 curl 설정을 배제하고 기본 TLS 검증을 유지한다. 외부 redirect, HTTP 전환, proxy 환경 상속, 자동 재시도는 없다. 연결 제한 10초, 요청 제한 20초, 전체 읽기 제한 23초와 본문 64KiB 상한을 적용한다. 본문은 메모리에서만 검증하며 URL·키·응답 원문·공급사 오류 문장은 출력하지 않는다.

## 종현 연결 요청

현재 저장된 키 원문을 쿼리 값으로 한 번 직렬화해 공식 HTTPS 행사 목록을 조회하는 전송 방식은 실제 검증됐다. 기존 행사 transport를 이 방식으로 연결하는 데 발급 형식에 대한 추가 추측이나 자동 fallback은 필요하지 않다. 다만 현재 공통 config의 `unknown`을 일반적인 자동 판정 성공으로 바꾸지 말고, **이번 입력에 대해 검증된 전송 방식**을 명시적으로 조립한다. 공통 설정 계약 변경이 필요하면 민규에게 요청한다.

기존 키를 decode한 뒤 다시 보내거나 이미 직렬화한 문자열을 이중 직렬화하지 않는다. HTTP 200만으로 성공 처리하지 말고 정상 코드와 응답 자료형을 확인한다. 반환된 행사의 요금·공개 권한·중복·행사 모드 정규화는 종현의 기존 계약을 따른다. 이번 조회로 무료라고 추정하거나 행사 동기화 전체 완료를 주장하지 않는다. 키를 교체하면 해당 새 입력의 전송 유효성은 별도로 확인한다.
