## 1. 원 완료기준과 현재 기준 문서

[Notion WBS6.1](https://app.notion.com/p/2eea6def75f88245b5dd810ae8e7117f)을 직접 조회했다. 최종 편집 `2026-10-14T12:24:27.163Z`, QA 공통 담당 민규·종현·유미, 우선순위 P0, 선행 작업 후보1.4다. 명시 완료기준은 다음과 같다.

- TC·검증환경·합성/회원통합/실기기 구분
- 위 조건을 확인한 검증 기록 또는 증빙 링크를 연결한다.

아래 정의·사례·기존 증거 연결이 이 문서의 범위다. 모든 사례의 실행 성공, 실제 회원·기기·운영 검증 완료, 팀 최종 합의를 이 정의 Task의 추가 완료조건으로 만들지 않는다. 그 결과는 후속 실행 기록에 남긴다. Notion 원문도 코드/합성 검사와 출시 전체 TC 합의·최신 실행 증빙 완료를 구분한다.

최신 사용자 답변과 [정책](../../../../정책.md)을 먼저 적용하고 [USERFLOW](../../../planning/design/USERFLOW.md)의 화면 흐름에 연결한다. 확인한 정책 SHA256은 `b58c74cce4dc71718bfd45e3249d0ca8fa42b2cf6e9fca47b936584233ef386f`, USERFLOW는 `91cf8148eb77d5b739d60c25190f63be1f45ce0ed56b3cf29a3bf74b7fbfa2fc`다. AI 계정별320만 토큰·등록 계정 합산 기준은 현재 정책을 따른다. USERFLOW/시안의 예시가 서버 계약·실제 비용 검증을 대체하지 않는다.

## 2. 상태·환경·담당의 공통 정의

| 표기 | 사용할 조건 | 확대할 수 없는 범위 |
|---|---|---|

환경은 O=오프라인 단위/모형, L=새 격리 로컬 실제 Auth·HTTP·DB/RPC+합성 자료, R=승인된 실제 회원/공급사 통합, D=Android 독립 설치 실기기, P=승인 운영으로 구분한다. R·D·P는 각각 별도 단계다. Expo Go·브라우저 예시·APK 빌드 성공을 D의 설치/독립실행·R의 서버 통합 완료와 동일시하지 않는다. Apple 계정·iPhone 배포 보류는 유지한다.

담당 약어는 M=민규(BE·AI·서버 실행/원자료), J=종현(FE·UX/UI·앱 인증/상태 소비·빌드/기기 기록), Y=유미(UT 관찰·PM/출시 협업)다. QA 판정은3인 공통이지만 한 파일은 현재 ownership의 단독 담당만 수정한다. 아래 J/Y는 후속 확인 책임 정의이며 산출물 수령·실행 완료를 뜻하지 않는다. [협업 규칙](../../README.md)과 [전체44개 acceptance](2026-10-19-minkyu-full-scope.json)를 따른다.
