## 첫 작업 결정

현재 첫 후보는 **[2.4] UT 시나리오와 판정 기준 설계**다. 카탈로그의 현재 상태·담당·Notion 링크를 확인하며 재개 시점 변경과 선행 조건에 따라 다음 독립 미완료를 선택한다.

[WBS 전체 작업과 담당/상태](2026-10-14-wbs-task-catalog.md)에서 본인 담당을 필터링하고 해당 Notion 페이지 본문·우선순위·선행 작업과 실제 파일 증거를 읽는다. 완료 항목을 시작 목록에 다시 넣지 않는다. 공동 담당 항목은 산출물과 수정 경로를 나눠 같은 파일 동시 편집을 피한다.

WBS의 PM/브랜딩/지원/UT 미완료 중 독립 문서 작업을 선택한다. UT 시나리오·합성 자료 기반 점검표는 docs/planning/ut/에, PM/브랜딩/지원 초안과 의사결정 후보는 자기 요청 폴더에 작업 ID를 포함한 새 문서로 작성한다. 실제 회원 UT는 HOLD를 유지한다. 정책·PRD의 공통 파일은 민규 관리이고 화면 설계는 종현 관리이므로 직접 편집 대신 구체적인 변경안을 연결한다. 팀 검토 사항을 임의 확정하거나 외부 홍보/메시지/게시를 실행하지 않는다.

현재 전체 백엔드 마지막 명시 기준79%(22/28)는 이번 인계 작성으로 늘리지 않는다. 실제 진행 보고에는 선택한 WBS ID·파일·검증·조건·다음 작업을 남긴다. Notion 완료 상태만으로 실제 구현/운영 완료를 판정하지 않는다. 공통 시작 절차의 실회원·공급사·운영·외부 전송·커밋/푸시 경계를 그대로 적용한다.
