# 민규 Play 계정·출시 실행 준비 — 2026-10-19

대상 WBS8.19·8.22·8.23·8.25. 민규 담당 전체44개에 포함하며 담당 제외·완료로 처리하지 않는다. 현재 단계는 공식 조건 확인·실제 계정 읽기와 제출 근거 연결이다. 계정/앱 생성·결제·업로드·신청·심사 제출·공개를 실행하지 않았다.

## 확인한 공식 조건

2026-10-19에 [개인 개발자 테스트 공식 안내](https://support.google.com/googleplay/android-developer/answer/14151465?hl=ko)를 재조회했다. 2023-11-13 이후 생성된 개인 계정은 최소12명이14일 연속 참여를 선택한 비공개 테스트를 충족한 뒤 프로덕션 접근을 신청해야 한다. 내부 테스트는 이 비공개 테스트를 대신하지 않는다. 신청 시 테스트 참여·피드백·수정 내용·앱과 출시 준비 근거를 답해야 한다. 민규 계정이 개인 유형임은 실제 Console에서 확인했다. 생성일과 유미당 앱별 Console 요건을 확인하지 못했으므로12명14일 적용 여부는 미확인이다.

[기기 인증 공식 안내](https://support.google.com/googleplay/android-developer/answer/14316361?hl=ko)는 새 개인 계정에서 실제 Android 기기 접근 확인을 요구한다. 계정 소유자가 Console 홈의 요구를 확인하고 모바일 Console 앱에서 검증한다. 이번 작업에서 기기 인증을 완료했다고 표시하지 않는다.

[버전 준비·출시 공식 안내](https://support.google.com/googleplay/android-developer/answer/9859348?hl=ko)에 따라 트랙 권한·앱 설정·서명·App Bundle·등록정보/검토자료를 준비하고 마지막 실제 제출·공개를 구분한다. 종현의 앱 빌드/서명 근거와 유미의 출시 판단을 민규가 임의 대체하지 않는다.

## 접근 시도와 한계

연결 브라우저 inventory에 제어 가능한 브라우저 탭은0개였다. 설치된 Chrome의 현재 화면 읽기를 시도했으나 자동 승인 검토가 ‘현재 탭의 사적 콘텐츠 노출 가능성·해당 화면 읽기 승인 부재’를 이유로 거절했다. 거절 후 다른 경로로 현재 화면을 읽거나 우회하지 않았다. Play Console 계정의 사실을 추측하지 않고 공식 문서 확인과 서버 독립 작업을 계속한다. 실제 Console 읽기는 Play Console 해당 계정 화면만을 대상으로 한 명시적 허용이 필요하다.

이 문서는8.19 또는 제출/공개 완료 증거가 아니다. 전체 담당 잔여는 [44개 대조표](2026-10-19-minkyu-full-scope.md)에 유지한다.

## 사용자 허용 후 실제 계정 확인

사용자가 ‘Play Console 해당 화면 읽기 허용’을 명시해 같은 날 전용 새 탭으로 해당 Console을 읽었다. 계정 선택→홈→계정 관리→개발자 계정→내 정보까지 조회했다. 계정 유형은 개인, 소유자는 민규로 표시됐다. 연락처 이메일·전화와 개발자 공개 이메일의 인증 완료 표시를 확인했다. 이메일/전화/법적 주소 원문은 이 문서에 복사하지 않는다.

계정 홈 Play 앱 표에는 기존 다른 앱1개만 보였고 유미당은 없었다. 그 앱의 이름·자료·프로덕션 실적을 조회하거나 유미당 근거로 재사용하지 않았다. 홈에서 기기 확인 미완료 경고가 보이지 않았다는 사실만으로 기기 인증 완료를 단정하지 않는다. 생성일은 조회 화면에 표시되지 않았으며, 유미당의 앱별 비공개 테스트 요구·신청 상태는 앱이 보이지 않아 미확인이다. 계정 생성일 또는 앱 존재를 추측하거나 새 앱을 만들지 않았다.

내 정보 화면의 변경사항 저장/취소 버튼은 비활성 상태였다. 편집·저장·결제 프로필 진입·신규 앱 생성·권한 변경·업로드·신청·제출·공개0이다. 초기 화면 읽기 자동 거절은 이후 명시 허용으로 해소됐으며, 더 넓은 권한으로 확장하지 않았다. 남은8.19조건은 생성 시점·신원/기기 요건의 정확한 상태와 유미당 앱별 Console 요구다.

## 추가 계정 화면 읽기

허용된 동일 Console의 계정 관리와 Android 개발자 인증 화면을 읽었다. Android 개발자 인증의 패키지 목록에는 다른 기존 앱 1개만 표시되고 유미당은 없었다. 해당 다른 앱의 패키지·키 상세를 열지 않았다. ID 탭에는 개발자 계정에서 가져온 법적 이름·주소가 표시되지만 별도의 신원 인증 완료 배지·계정 생성일·실제 기기 확인 결과는 표시되지 않았다. 따라서 이 화면만으로 신원·기기 검증 완료나 12명14일 조건 비적용을 단정하지 않는다. 개인정보 원문은 이 기록에 복사하지 않았다. 패키지 등록·편집·저장·제출·권한 변경은0이다.
