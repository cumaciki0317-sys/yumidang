# KOPIS 공개 안내의 추가 근거 — 2026-10-14

전체 **79%(22/28)** 유지. 검토된29개 파일의 커밋 승인 답변을 기다리는 동안 공개 설명 페이지를 읽었다. 해당29개와 SHA는 변경하지 않았다. 이 문서는 그 커밋 목록에 포함되지 않는 별도 조사 기록이다. 공급사 데이터 API·키·DB·Auth·VM·외부 메시지·커밋·푸시는 실행하지 않았다.

## 새로 구분한 근거

[KOPIS 공식 이용가이드](https://kopis.or.kr/mob/cs/kopisGuide.do)의 예매상황판 설명은 예매일 기준, 티켓판매수 순위1~50위, 연계기관 자료의 매일 갱신을 안내한다. 따라서 공개 화면의 순위 기준과 일일 갱신 설명은 공식 근거가 있다. 티켓판매액 순위나 공연 상연일 기준으로 바꾸어 설명하지 않는다. 이전의 포괄적인 “갱신 근거 미확인”은 API의 구체적인 갱신 시각/지연·응답 계약 미확인으로 좁혀 기록한다.

이 설명은 공개 화면에 대한 근거다. Open API boxoffice에 임의의 최근7일 요청이 실제 반영되는지, basedate와 요청 범위가 일치하는지, 동률·0건·오류 처리, 갱신 시각/지연을 입증하지 않는다. 공개 화면 설명을 실제 API 응답 증거로 대신하여 저장/공개 보류를 해제하지 않는다. 다음 실행의 확인 항목은 API 기간/순위/0건/갱신 계약이며, 공개 안내의 일일 갱신 여부를 다시 미확인으로 두지 않는다.

[서울 공식 FAQ](https://data.seoul.go.kr/together/notice/faqList.do?bbsCd=10002&ditcCd=FAQ02&seq=d47bc57aea53d6c6ab244c05a6eb2259)는 기본 API 주소를 HTTP8088로 설명하고 서비스별 주소 확인을 요구한다. 이번 공개 조회에서 aiViewCulture의 공식 HTTPS 데이터 주소를 새로 확보하지 못했다. J02의 HTTPS 활성화 조건과 수집 보류는 유지한다. HTTPS 설명 페이지 접속 성공은 데이터 API TLS 지원의 증거가 아니다.

## 다음 작업

로컬 커밋 승인 도착 후 검토된29개만 고정하고 이미 승인된 새 합성 검증을 진행한다. 이번 근거 확인은 J01/J06/J07/J08/J09의 실제 연결 검증을 대체하지 않는다. J03 수집 활성화에는 위 API 근거와 실제 실행 경계가 여전히 필요하다. 승인 질문을 반복하거나 무응답을 승인으로 처리하지 않는다.
