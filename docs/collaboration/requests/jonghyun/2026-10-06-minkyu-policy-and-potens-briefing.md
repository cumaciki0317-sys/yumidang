# 민규 전달 문구: 신고 정책과 포텐스닷 계정 전환

아래 문구는 사용자가 직접 전달할 텍스트다. 외부로 발송하지 않았다.

> 신고·이의 정책 두 가지 확정했어.
>
> ① 신고 설명·캡처·증거는 이의 절차 포함 최종 종결 후90일에 삭제하되, 신고자가 선택한 ‘내 화면에서 숨기기’는 본인이 해제할 때까지 유지해. 숨김에 필요한 최소 식별 기록만 신고 자료와 별도로 남겨줘. 차단이나 운영자의 전체 공개 제한·제재와는 별개야. 실제 연결 전에는 기존처럼 숨김 선택을 보류해.
>
> ② 취소 외 제재의7일 이의 기간은 당사자가 앱에서 판정·사유·이의 방법을 확인할 수 있도록 안내가 성공적으로 제공된 서버 시각부터 시작해. 처음 읽은 시각이나 푸시·메일 발송 시각은 기준이 아니야. 안내 제공 실패 때는 기산하지 않고, 마감 시각도 함께 표시해줘. 취소 이의24시간은 그대로야.
>
> 포텐스닷 팀원 계정 사용은 동의 받았고, 모델은 claude-5-sonnet이야. 계정별 한국시간 하루320만 토큰, 전체 예산은 등록 계정별 상한의 합계로 정했어.320만이 공급사 화면80%를 보장하는 건 아니고 측정에 따른 초기 운영 상한이야. 전송 전 예약에서 계정 예산이 부족하면 다음 계정을 선택하고, 전체 예산이 부족하면 중단해. 한국시간 자정에 새 일자로 전환하되 미정산 예약은 원래 계정·일자로 유지해.
>
> 종현 쪽 계정 선택·예약·정산 포트와 단위 검사14개는 준비됐어. 민규 쪽에서 서버 다중 키 설정과 계정별/전체 예산의 원자 예약·정산 DB/RPC를 연결해줘야 해. 회원 하루20회는 유지하고 내부 호출·계정 전환으로 중복 차감하지 않아야 해. 현재 단일 키 설정만 지원하므로 키를 여러 개 적는 것만으로 전환되진 않아. 실제 키 등록·운영 연결을 진행하려고 하며, 등록 순서는 유미 → 종현 → 민규 → 성호으로 정했고, 로컬 서버에서 먼저 연결·검증한 뒤 운영 서버에 적용할 거야. 네 계정 등록 시 전체 일일 상한은1,280만 토큰이야. 실제 키 등록과 공통 계약 연결이 남아 있어. 개인정보 조건·출력 상한 확인 전 실제 회원 AI 호출 보류는 유지해.
>

## 현재 실행 요청과 연결 순서

사용자가 실제 키 등록·운영 연결 진행을 요청했다. 이는 기존 정책상의 실제 회원 원문 전송 보류를 해제하거나 민규 소유 파일 편집을 종현에게 재배정한 답변이 아니다.

1. 사용자 답변1A·2A: 유미 → 종현 → 민규 → 성호 순서로, 로컬 서버에서 먼저 연결·검증한 뒤 운영 서버에 적용한다. 등록할 네 계정과 순서는 확정됐다. 네 계정을 모두 등록하면 전체 일일 상한은1,280만 토큰이다. 실제 키는 채팅·인수인계·Git에 넣지 않는다.
2. 민규가 공통 설정과 서버 비밀 저장 형식을 지원하고 계정별/전체 예산의 원자 예약·정산 DB/RPC를 제공한다.
3. 해당 형식에 실제 키를 등록하고 종현 담당 런타임을 연결한다. 기존 승인·개인정보·출력 상한 차단을 유지한다.
4. 합성 데이터로 실제 계정 선택·동시성·응답 유실·전체 소진·자정 경계를 검증한다. 개인정보 조건 등이 준비된 뒤 회원 요청 검증을 진행한다.

이번 확인에서는 키값을 출력하거나 변경하지 않았고 외부 API 호출·배포도 하지 않았다. 원본 폴더와 종현 clone 모두 공통 설정은 단일 키 로더이며, 다중 계정 예약 계약은 확인되지 않았다.
