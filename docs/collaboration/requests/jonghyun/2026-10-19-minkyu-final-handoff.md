## 최신 후속: 후기 AI 선택 동의·KOPIS 호출 계속

사용자가 후기 AI를 가입 시 선택으로 변경했습니다. [최신 결정](2026-10-19-ai-optional-signup-decision.md)이 이전 가입 필수 의도보다 우선합니다. 세 항목/기본 미선택/전체 동의/독립 철회는 유지하며 미동의 회원의 가입·일반 동행을 막지 마세요. 정책 문서와 실제 기존 RPC·UI·DB는 별개이므로 통합 시 이 차이를 확인해 주세요.

## 행사 UX 최종 확정 인계

사용자 작성본과 후속3개 모두 A 승인에 따른 [행사 UX 최종 확정 기준](2026-10-20-event-ux-approved-spec.md)이 이전 매핑 검토안의 화면 추천·작성 일정 겹침 강제보다 우선합니다. 일반 작성은 행사영역 맨 아래, 행사 상세 진입은 맨 위입니다. 행사 검색을 동행 일정으로 자동 축소하거나 겹침을 강제하지 않고 달력에 행사 날짜만 강조합니다. 직접 입력은 공고 전용이며 공통 목록/독립 상세/공용화 검수 없이 행사명 필수·장소명/공개 행사주소 선택입니다. 이미지 미제공·실패는 글만 표시합니다.

서버 통합 시 아래 의존성을 확인해 주세요. 현재 계약·검증 결과만으로 신규 UX가 지원된다고 표시하면 안 됩니다.

- UUID 행사 연결만 받는 기존 입력에 공고 전용 직접입력 구조·검증·조회 연결이 필요합니다. 연결 삭제는 기존 API의 명시 null이며 키 생략(기존 유지)과 구분합니다.
- 기간 겹침 강제와 작성용 자동 기간 축소를 제거하되 종료/공식취소/연기 일정 미정/비표출/핵심 충돌의 새 연결 제한은 유지합니다. 등록 직전 서버 저장 상태 확인 실패는 글 보존·재시도 또는 사용자가 연결 삭제 후 등록입니다.
- 취소 여부 미제공과 오류/손상/해석 실패를 구분하고, 비표출 시 내부 ID를 보존하면서 공개 원천 정보를 숨기는 안전 DTO가 필요합니다. 기존 eventId가 있으면 linkedEvent 전체를 요구하는 앱 parser도 함께 바꿔야 합니다. 재표출은 명시 상태/공개 조건/최신 자료 검증 뒤 복원합니다.
- 확실한 행사 단위 공식 공통 ID/정확한 공식 상세 링크 등 동일 개최 근거가 있는 원천만 대표 카드·상세·공고로 통합합니다. 기존 canonical 저장 함수는 이 기능의 완료 근거가 아닙니다. 원천 ID·공고 관계·근거·통합/분리 이력 보존, 근거 부족은 출처별 유지·상시 수동검수 없음. 먼저 검증된 공개 원천 대표 유지·빈 필드만 출처를 남겨 보완·대표 비표출 시 다른 공개 원천 전환·핵심충돌은 안내 및 새 연결 제한입니다. 실제 연결 근거가 없어 초기 통합0건이어도 추정 병합하지 않습니다.
- 관련 공고는 전체 상태·등록 최신순/모집중 필터/10개 더보기와 기존 차단·숨김·비로그인 권한을 재사용합니다. 작성자의 행사 교체·삭제·직접입력 실질 변경은 핵심조건 변경이며 확정 후 행사 변경의 상대 수락 계약 확장이 필요합니다. 원천 자동 갱신과 구분합니다.
- 확인된 취소·연기·변경 일정은 작성자와 진행중 동행 확정 상대에게 앱 안 알림, 같은 변화 중복방지·새푸시 없음입니다. 기관별 핵심 정보 충돌은 기존 약속을 자동 변경/취소하지 않습니다.
