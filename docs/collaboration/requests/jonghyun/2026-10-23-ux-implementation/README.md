출시 대상 **Android 앱을 우선하고 웹은 보조 확인**으로 사용한다. 너비320dp·글자200%에서 실제 키보드 가림을 추가로 발견했다. 화면 좌표를 실측하는 방식으로 보완한 뒤 제목·하단 입력·다음 버튼, 행사 검색/직접 입력, 대화 입력/보내기를 재검증했다. [작은 화면 기록](compact-qa.md)과 [N15~N19](android-runtime/results.json)에 실패·중간 보정·최종 결과를 구분했다.

화면 크기·글자·TalkBack·필기·회전 설정은 [시작 전 값과 정확히 일치](android-runtime/compact-restored-settings.json)하도록 원복했고 전용 에뮬레이터·Metro를 종료했다. 실제 서버 계약 연결 후 회귀와 최종 디자인·출시 설치본 검증은 별도 잔여다. 모든 방향·키보드·기기 조합을 이번 작업의 새 필수 조건으로 추가하지 않는다.

## 남은 일·다음 담당

[요구사항별 최종 대조](final-requirement-audit.md)에서 서버 대기로 잘못 묶였던 본인 후기 제출 안내1건을 찾아 보완했다. 최종 통합 합성 회귀 **174/174**, 타입·변경 제품 파일 lint·Android Hermes 번들 생성이 통과했다. 이 새 사유 분기는 실제 RemoteReview TSX를 합성 실행한 근거이며 Android 기기·실제 서버에서 새로 확인했다고 주장하지 않는다. 위170건·Android 작은 화면 기록은 당시 소스/관찰 범위로 보존한다.

- 종현: Android 대표 환경411dp/320dp의 관찰 범위를 [기기 기록](android-runtime/results.json)에 남겼다. 서버 계약 연결 후 앱 재검증, 최종 디자인 및 별도 출시 설치본 QA가 남아 있다. 예시 모드 전체를 서버 모드와 동일하게 개편했다고 보지 않는다.
- 민규: [서버 후속](server-followup.md)의 후기 동의 3종 독립 조회/변경, 행사와 공고의 ID 관계 조회, 후기 불가 사유·직접 입력 행사 저장 등 기존 연결 과제.
- 유미: 실제 UT와 결과에 따른 개선 판단. 참고 앱과 디자인 MD를 통한 최종 스타일은 후속 단계다.
- 공동: 출시 판단·실회원 통합·운영 검증. 실회원 원문 외부 전송 HOLD 유지.

현재 로컬 구현·자체 검증이 끝난 부분과 남은 독립 기기 QA·연동 대기를 TASK 본문에 나눠 남긴다. 사용자 선택만 기다리던 `팀 검토 필요`를 최종 완료로 바꾸지 않는다. 종현 혼자 진행할 QA가 남은 TASK는 `작업 중`으로 관리한다.
