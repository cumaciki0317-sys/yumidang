## 이미 승인된 연동 경계

후기 동의3종, 행사 ID 관계 조회, 직접 입력 행사 저장, AI 이용 가능 상태와 후기의 추가 사유는 `server-followup.md`에 구분한다. 제공된 계약이 있는 사례까지 서버 대기로 묶지 않는다.

Android 실제 로그인은 별도2순위 작업의 남은 연결이다. 현재 root `_layout.tsx`는 웹에서만 연결을 설치하고 native 로그인 화면은 준비 안내를 표시한다. 기반 clone의 `2026-10-21-app-foundation/README.md`와 `minkyu-handoff.md`에 사용자가 **native 인증은 BE 연동 대기**로 선택한 기록이 있다. 이를 새 정책 미결정으로 되돌리거나 웹 Origin 계약을 앱에서 우회하지 않는다. 운영 URL·native 안전 복귀/교환·세션 저장 계약이 확인되면 종현의 앱 포트를 연결한다.

## 완료 판단

승인한 화면 구조와 로컬 클라이언트 보완, 대표 Android 관찰은 실제 서버·출시용 설치본·실회원 완료와 구분한다. 최종 시각 디자인은 사용자가 추후 레퍼런스/디자인 MD로 진행하기로 했다. 외부 선행 계약이나 사용자 자료 없이 새 정책·역할·출시 허용을 임의 결정하지 않는다. 커밋·푸시·병합·배포도 이번 범위에 포함하지 않는다.

이번 대조에서 발견한 Q07 소비 누락은 보완 후 통합 합성174/174·타입·변경 파일 lint·Android 번들 생성으로 확인했다. 기존 버튼의 실제 렌더 경로에서 재조회·약속 복귀와 재제출0회를 검사했다. 본인 후기 원문은 새로 노출하지 않는다. 화면 복사나 서버 권한·DB 변경은 하지 않았다.
