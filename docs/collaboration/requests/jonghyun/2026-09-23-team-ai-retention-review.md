# 팀 검토 안건: 외부 AI 원문 보관 기준

상태: **미정 / 팀 검토 대기**. 2026-09-23 종현의 최신 지시로 이전 “종현님이 정한 미보관 요구” 자체를 포함해 재검토한다. 원문 미보관을 필수로 확정하거나, 보관을 허용한 것으로 해석하지 않는다. 이 문서는 로컬 검토 자료이며 팀원에게 외부 메시지를 보내지 않았다.

## 유지되는 확정 정책

유미당 서버는 현재 탐색 대화만 요청 메모리에서 처리하고 AI 대화 이력을 저장하지 않는다. 오류·사용량 로그에도 대화·후기 원문과 민감 정보를 기록하지 않는다. 후기 원천 저장소와 공개 적격 후기 요약 정책은 기존 계약을 따른다.

## 확인된 정보와 미확인 정보

- 사용자 제공: 포텐스닷은 Claude 기반이다. 무료 제공 종료는 2027년 6월경이라는 사용자 추정이다.
- 사용자 제공 [API 안내](2026-09-23-potens-api-reference.md): Bearer 인증, /api/chat·/api/chat-stream, prompt/model, 모델 식별자 목록과 기본 claude-4-6-sonnet. 키를 제외한 규격만 기록했다.
- 미확인: 실제 응답/사용량/오류 구조, 모델의 실제 대응·계정별 가용성, 계정 API 사용 자격·한도·무료 종료일. 유미당의 최종 모델은 미정이다.
- 미확인: 포텐스닷 자체의 원문 보관·학습 이용·위탁 처리 조건, 실제 모델 제공사 계약이 포텐스닷 경유 요청에 적용되는 범위.
- 제공사 일반 자료에서 보관 예외가 확인되어도 우리 계정에 그대로 적용된다고 확정하지 않는다. 학습 미사용·원문 미보관·캐시/메타데이터 보관은 구분한다. [조사 자료](2026-09-23-ai-cost-and-retention.md).

## 팀이 결정할 항목

1. 외부 AI에 대화·후기 원문 미보관을 필수로 요구할지. 대화와 후기의 요구가 같은지도 검토한다.
2. 보관을 허용한다면 목적·기간·접근 범위·삭제 조건을 어디까지 허용할지. 법률·안전 관련 예외의 수용 범위도 결정한다.
3. 결정한 기준을 포텐스닷 및 실제 모델 제공사의 해당 계정·API·기능이 충족하는지 어떤 문서/설정으로 확인할지.
4. 사용할 제공사·모델과 대체 경로. 호출 예산·운영 한도는 별도 기존 미정 항목이며 보관 검토만으로 승인되지 않는다.

결론을 내면 결정 내용·검토 근거·적용 제공사/계정/API/모델·결정 참조를 기록하고 종현 계약과 민규 공통 문서를 동기화한다. 이 문서에는 API 키·비밀번호·실제 대화/후기 원문을 넣지 않는다.

## 구현 영향

- 모델 연결은 제공사별 `retentionReview: {status:"pending"}` 상태를 지원한다. pending 또는 결정 참조가 없는 경우 원문 전송·예산 예약 전에 `RETENTION_REVIEW_PENDING`으로 차단한다.
- 검토가 끝난 서버 구성만 `{status:"approved", decisionId:"팀 결정 참조"}`를 제공한다. 이는 팀의 기준 검토 완료 표시이며 자동 ZDR 인증 또는 클라이언트 승인 입력이 아니다.
- 기존 `zeroRetentionVerified` 필수 조건은 현재 미정 상태와 충돌하므로 제거했다. 실제 외부 제공사는 연결하지 않았다. 테스트의 승인 참조는 합성값으로 실제 계정 승인을 뜻하지 않는다.
- 외부 정책에 의존하지 않는 검색·행사·모델 독립 처리·원문 없는 지표 작업은 계속한다.

## 민규에게 필요한 동기화

담당: 민규. 대상: PLAN.md·PLAN_상세설계.md·공통 환경/제공사 활성화 설정 중 관련 기록. 외부 원문 미보관을 확정 조건으로 적어 둔 곳이 있으면 이 미정 상태를 반영하고, 서버 대화 이력·원문 로그 미저장과 구분해 주기 바란다. 팀 결정 전 종현이 공통 파일을 변경하거나 실제 API 연결을 활성화하지 않는다.
