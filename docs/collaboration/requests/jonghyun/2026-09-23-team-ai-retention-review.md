# 팀 검토 안건: 외부 AI 원문 보관·전송 기준

상태: **미정 / 팀 검토 대기**. 현재 기준은 [정책.md의 AI 공개 조건](../../../../정책.md#ai-search)과 [보관 기준](../../../../정책.md#retention)이다. 실제 회원 탐색 대화·공개 적격 후기의 외부 전송은 공급사의 입력·응답 보관 조건을 확인하고 사용자 확인을 받기 전까지 보류한다. 원문 미보관을 공급사가 보장한다고 가정하거나 보관을 허용한 것으로 해석하지 않는다. 이 문서는 로컬 검토 자료다.

## 유지되는 확정 정책

- 현재 탐색 대화는 화면 메모리에서만 유지하고 탐색 종료·새 탐색·로그아웃 시 정리한다. 서비스 서버의 대화 이력·오류·사용량 로그에는 대화·후기 원문과 민감 정보를 저장하지 않는다.
- 공개 텍스트 후기 3개 이상 요약 정책과 외부 원문 전송 승인은 별개다. 회원 간 1:1 채팅은 AI 입력으로 사용하지 않는다.
- 입력 개인정보 발견 시 전송 중단·수정 안내, 출력 발견 시 응답 숨김·재시도 안내를 적용한다. 정상 공개 장소와 비공개 만남 정보는 구분한다. 탐지 정확도·범주·재시도 한도는 팀 검토다.
- AI 첫 이용 직전 전송 항목·목적·공급사·서버 미저장·확인된 외부 보관 조건·거절 방법을 안내하고 확인받으며 이후 열람과 조건 변경 시 재안내를 제공한다. 이 동작만으로 법적 요건 충족을 단정하지 않는다.
- 공급사·모델은 포텐스닷 LLM/Sonnet 5(`claude-5-sonnet`)로 정해졌다. 대체 공급사·모델을 임의 활성화하지 않는다.
- 추가 지출 0원 계정 근거를 확인한 뒤 합성 10회 평가를 준비한다. 합성 입력 평가와 실제 회원 전송 허용은 별개다.

## 확인 자료와 미확인 조건

[9월 29일 공급사 조사·최소 호출 기록](../minkyu/2026-09-29-provider-api-review.md)과 [9월 30일 구현·검증 기록](2026-09-30-jonghyun-integration-handoff.md)은 당시 증거다. 최소 응답 성공이 학습 미사용·입출력 미보관·실제 모델 식별·계정 한도 검증을 대신하지 않는다. 사용자 추정인 무료 종료일을 확정일로 쓰지 않는다.

포텐스닷 자체와 실제 모델 제공사 각각의 보관·학습 이용·접근·위탁 처리·삭제·예외 조건 및 우리 계정/API/기능 적용 범위를 확인한다. 학습 미사용, 원문 보관, 캐시와 메타데이터 보관을 구분한다. [초기 비용·보관 조사](2026-09-23-ai-cost-and-retention.md)의 과거 일반 가격과 설명은 현재 계정 계약의 증거가 아니다.

## 팀이 검토할 항목

1. 탐색 대화와 공개 적격 후기 각각에 필요한 외부 보관 조건, 허용 목적·기간·접근·삭제 범위 및 법률·안전 예외.
2. 해당 조건을 입증할 계약·공급사 답변·계정 설정과 API/기능 적용 범위. 조건 충족 여부는 사실 확인이며 사용자가 성공으로 선택할 항목이 아니다.
3. 검토 결과를 이용 안내에 정확히 반영하고 실제 회원 전송에 대한 사용자 확인을 받는 절차. 불명확하면 전송 보류를 유지한다.
4. 미충족 시 기능 비활성 또는 합성 전용 유지 등 후속 범위. 대체 모델·공급사·추가 과금은 이 검토만으로 승인하지 않는다.

결론과 근거·계정/API/모델·결정 참조를 남기고 정책·계약·설정을 함께 갱신한다. API 키·비밀번호·실제 대화/후기 원문을 이 문서에 넣지 않는다.

## 구현·연결 확인

기존 `retentionReview: {status:"pending"}` 차단을 유지한다. pending 또는 결정 참조 부재 시 원문 전송·예산 예약 전 `RETENTION_REVIEW_PENDING`으로 차단해야 한다. `{status:"approved", decisionId:"결정 참조"}`는 실제 검토·사용자 확인에 근거한 서버 구성만 제공한다. 자동 ZDR 인증이나 클라이언트 승인 입력으로 취급하지 않는다. 합성 테스트의 승인 참조를 실제 계정 승인으로 복사하지 않는다.

보관 조건과 무관한 일반 검색·행사·모델 독립 처리 준비는 계속할 수 있다. 최초 공급사 어댑터 개발을 반복하기보다 이미 구현된 어댑터와 실제 계정 조건의 미확인 부분을 점검한다. 이번 문서 갱신은 외부 제공사 활성화나 원격 설정 변경이 아니다.
