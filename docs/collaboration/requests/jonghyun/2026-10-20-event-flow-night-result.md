# 행사 검색·연결·직접 입력 흐름 결과

2026-10-20 / 종현 / 파일명 night는 시작 당시 작업명이며, 사용자 정정 후2번 야간 TASK는 중단하고1번 기능흐름만 마무리했다.

## 1번에서 완료한 클라이언트 범위

- 실서비스 선택창은 일정 선입력 없이 조회 가능한 예정·진행 중 행사 전체에서 키워드 검색·초기화·10개 더보기를 제공한다. 날짜를 자동 필터로 보내지 않고 기간 겹침을 강제하지 않는다.0건/실패를 구분한다.
- API 행사 선택/변경/삭제와 직접 입력을 서로 배타적으로 연결한다. 일반 작성은 행사 영역 하단, 행사 상세 진입은 상단이며 만남 일정은 바꾸지 않는다.
- 직접 입력은 행사명 필수·장소/공개 행사장 주소 선택, 기존 주소 검색·공개 확인·개인정보 검사를 재사용한다. 프리뷰에서는 공고에만 저장하고 공용 행사 목록이나 별도 행사 상세를 만들지 않는다.
- 초안 복원값을 검증하고, 삭제/교체 시 상대 연결값을 제거한다. 프리뷰는 기존 기기7일 저장, 실서비스는 현재 세션 메모리 보관이라는 실제 범위로 안내를 구분한다. 서비스 영속 초안 지원 완료를 뜻하지 않는다.
- 익명 행사 상세의 로그인 복귀 의도를 고정된 작성 경로에 보존한다. 실제 OAuth/신규가입 콜백 검증은 별도다.
- 실서비스 직접 입력 저장 계약이 없어 등록은 준비 중 안내와 함께 차단하며 입력을 유지하고 수정/삭제할 수 있다. 소개글로 합쳐 보내는 우회는 하지 않는다.

## 담당과 남은 의존성

직접 입력 실제 저장·수정 API/DB/공개 권한·공고 검색 연결은 민규 담당이다. 종현은 준비된 계약의 요청/응답·실패·등록 후 상세 연결을 소비하고 실제 서버 통합을 검증한다. 기존 API 행사 연결의 서버 기간 검사가 예전 조건인지도 민규가 확인해야 한다. 서버 미지원 상태를 클라이언트에서 우회하거나 완료라고 표시하지 않는다.
