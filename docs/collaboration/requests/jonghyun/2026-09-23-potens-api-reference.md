# 포텐스닷 API 안내 — 키를 제외한 연결 준비 자료

상태: 2026-09-23 **사용자 제공 안내 수령**. 실제 API 호출·계정 승인·모델 품질·응답 검증은 수행하지 않았다. 아래는 전달받은 안내의 요약이며 공개 공식 문서나 실제 계정 확인 결과로 확대하지 않는다. 실제 DB·외부 API 연결은 사용자 지시로 대기한다.

## 안내에서 확인한 호출 규격

| 항목 | 사용자 제공 안내 |
|---|---|
| 기본 주소 | `https://ai.potens.ai` |
| 완성 응답 | `POST /api/chat`, JSON으로 한 번에 반환 |
| 스트리밍 | `POST /api/chat-stream`, SSE의 data 줄에 JSON 이벤트 반환 |
| 인증 | `Authorization: Bearer <서버 환경에서 주입할 키>` |
| 요청 | JSON의 `prompt`, `model` 필드 |
| 완성 응답 필드 | `message`, `token_usage`. 실제 값의 타입과 하위 필드 예제는 아직 없음 |
| 스트리밍 이벤트 | `type`이 `text`, `reasoning`, `done`. 종료 이벤트에 token_usage 포함 |
| 안내의 기본 모델 식별자 | `claude-4-6-sonnet`. 유미당의 최종 모델 선정으로 간주하지 않음 |
| 안내의 지원 모델 식별자 | `claude-4-6-sonnet`, `claude-5-sonnet`, `claude-4-5-sonnet`, `claude-4-5-haiku`, `claude-4-8-opus`, `claude-5-opus` 등. 실제 계정별 가용성과 모델 대응은 미검증 |
| 인증 오류 | 401/403 시 키·승인 상태 확인. `User is not approved`는 계정 승인 필요라는 안내 |
| 일일 한도 | 요금제와 동일한 일일 사용 한도, 마이페이지 상단에서 확인. 숫자와 갱신 시각은 미확인 |

사용자가 제공한 예제에 인증 키로 보이는 값이 포함되어 실제 발급 키라면 폐기·재발급하도록 안내했다. 해당 값을 이 파일·코드·환경 설정에 복사하지 않았고 호출에도 사용하지 않았다. 새 키는 대화에 보내지 않고 실제 연결 재개 후 정해진 비밀값 관리 경로로 주입한다.

## 실제 어댑터 구현 전에 필요한 자료

1. 개인정보·키가 없는 성공 응답 예제: message의 타입, token_usage의 입력/출력 토큰 필드와 단위.
2. 오류 응답 규격: 일일 한도 소진과 일반 요청 제한/장애를 구분할 기계 판독 코드. 모든 429를 일일 한도로 처리하지 않는다.
3. 최대 입력 길이·최대 출력 제어 필드·구조화 JSON 출력 지원 여부. 현재 ModelPort의 system/input/maxOutputTokens를 어떻게 연결할지 확인하며, 안내에 없는 필드를 임의로 전송하지 않는다.
4. 실제 계정의 API 이용 가능 여부·일일 한도·갱신 기준·무료 API 포함 여부·정확한 무료 종료일.
5. 유미당에서 사용할 모델, 대체 모델, 승인된 개발·검증 예산.
6. 포텐스닷 및 실제 모델 제공사의 보관/학습/캐시 조건. 서비스의 미보관 요구 자체는 [팀 검토용 미정](2026-09-23-team-ai-retention-review.md)이다.

API 어댑터는 종현이 담당하고 인증 키의 서버 환경 주입·공통 실행 환경은 민규와 협업한다. 이 안내 수령이나 우편번호 공급사 확정은 실제 API 연결 재개를 뜻하지 않는다.
