행사 API 정보는 어디에 쓰이나요?

행사 자체의 정보와 회원이 작성하는 동행 정보를 구분합니다. 다음은 정책·IA·USERFLOW 기준의 사용 위치입니다.

화면필요한 행사 정보하는 일과 경계
S00 홈행사명·기간·진행 상태·대표 이미지(있을 때)이번 주 신규 중 미종료 행사를 보여주고 S09-2/S09-3으로 연결합니다. API 실패와 행사 없음은 구분합니다.
S09-2 행사 목록제목·기간·분류/장르·지역/장소·이미지·요금·출처목록·필터·진행 중 포함·과거 조회·작성용 선택에 사용합니다. KOPIS 순위는 별도 영역이며 현재 공개 보류입니다.
S09-3 행사 상세명칭·기간·장소·요금·운영시간·소개·출처·공식 링크. 관람대상/출연진 등은 추가 연결 시행사 정보와 관련 동행 공고를 연결합니다. 관련 공고는 자체 DB 정보입니다. 종료 행사는 볼 수 있지만 새 모집에 연결하지 않습니다.
S03·S04 공고 작성·확인선택 행사 ID·행사명·기간·행사장 장소 후보행사를 연결하고 동행 일정과 겹치는지 확인합니다. 행사 선택만으로 작성한 동행 일정이나 상세 만남 지점을 덮어쓰지 않습니다.
S02 공고 상세연결 행사명·요약·행사 상세 이동연결된 행사 영역에는 API 정보가 들어갑니다. 동행 날짜·희망 상대·모집/확정 상태·상세 만남 지점은 회원·공고 데이터입니다. S01/S09의 공고 카드와 검색에서도 연결 행사명을 사용할 수 있습니다.
S20 AI 탐색행사명·기간·장소/지역·분류·요금·공개 소개실제로 수집된 행사 검색과 행사 카드에 씁니다. 행사 카드는 S09-3, 동행 카드는 S02로 이동하며 행사만 있는 것을 신청 가능한 동행으로 표시하지 않습니다.
