O1 · 선택 필요

공개할 실제 운영 주체와 이름

문서 근거: 정책.md 13장: 정식 운영자명은 게시 전에 준비한다. 공개 메일과 대표 유미는 이미 확정했다.

무엇을 정하나요?

유미당은 서비스 이름이고, 실제로 서비스를 운영하고 문의·삭제 요청을 책임지는 개인 또는 사업자의 명칭은 별개입니다. 대표 유미라는 역할 배정만으로 실제 정식 이름을 알 수는 없습니다.

예시

개인 운영이면 “유미당 / 운영자: [실제 전체 이름] / 담당: 대표 유미” 형태의 초안을 만들 수 있습니다. 실제 등록된 사업자가 있다면 그 사업자의 정식 명칭으로 바꿉니다. 이름은 제가 지어 넣지 않습니다.

주의할 차이와 적용 조건

어떤 표기가 필요한지는 이후 공식 고지 요건 확인에서 검증합니다. 이 선택만으로 법적 고지 충족이나 사업자 등록 사실을 인정하지 않습니다. A·B를 고르면 아래에 실제 공개 명칭도 적어 주세요.

O2 · 선택 필요

메일 삭제 요청에 처음 답하는 목표 시간

문서 근거: 정책.md 13장: 앱 밖 삭제 요청을 공개 메일로 받는다. 일반 신고의 첫 확인 목표는 영업일 2일이며 삭제 요청의 별도 목표 시간은 아직 미정이다.

무엇을 정하나요?

첫 답변은 접수 확인, 필요한 최소 본인 확인 방법, 예상 일정을 알려주는 단계입니다. 이 답변을 보냈다고 삭제가 끝난 것은 아닙니다. 유미 혼자 처리할 수 있는 목표와 사용자 대기 시간을 함께 고려해야 합니다.

예시

공휴일 없는 금요일 17시에 도착한 요청에 A안을 적용하면 다음 화요일 18시까지 첫 답변하는 목표입니다. 신분증을 무조건 요구하는 새 규칙은 만들지 않고 필요한 최소 확인 방법을 별도로 적용합니다.

주의할 차이와 적용 조건

A/B/C 공통으로 한국시간 평일 09~18시, 토·일 및 대한민국 공휴일 제외, 도착 다음 영업일부터 N영업일째 18시까지로 정의하는 운영 제안입니다. 기존 신고 목표의 영업일 계산까지 이 카드로 바꾸지는 않습니다. 법정 기한·현재 보장 중인 서비스가 아니라 출시 전 검증할 목표입니다.

O3 · 선택 필요

본인 확인 후 수동 삭제 요청의 처리·결과 안내 목표

문서 근거: 정책.md 13장: 활성 프로필·사진은 탈퇴 처리 때 즉시 삭제. 별도 보관·백업은 구분 안내하며, 앱 밖 메일 삭제의 처리 시간은 미정이다.

무엇을 정하나요?

메일을 받은 시점과 본인 확인을 끝낸 시점은 다릅니다. 이 목표는 확인된 수동 요청에 대해 기존 탈퇴·삭제 절차를 진행하고 결과와 남은 범위를 안내하는 기한입니다.

예시

월요일에 본인 확인이 끝나면 A안에서는 공휴일이 없는 목요일 18시까지 처리 결과를 안내하는 목표입니다. 탈퇴 처리가 월요일에 실행되면 활성 프로필·사진은 그때 즉시 삭제해야 합니다. 목요일까지 활성본을 남겨 둬도 된다는 뜻이 아닙니다.

주의할 차이와 적용 조건

A/B/C의 영업일 계산은 O2와 같은 정의입니다. 진행 중 확정 동행, 정해진 별도 보관, 백업 만료, 외부 AI 사본 삭제 미확인은 이유·남은 범위·다음 안내일을 구분합니다. 기한 전에 지연과 새 예정일을 안내하며 미확인 사본까지 모두 삭제됐다고 표시하지 않습니다. 이 숫자는 법정 기한이나 활성 자료 삭제 유예가 아닙니다.

O4 · 선택 필요

제재·경고·연속취소의 최소 연결 기록을 언제 지울까

문서 근거: 정책.md 6·13장: 동일 네이버 재가입 시 제재 승계, 경고 이력 유지, 상세 증거는 종결 기준 90일. 최소 연결 기록의 종료 조건·보관 근거는 미확정이다.

무엇을 정하나요?

신고 캡처나 채팅 원문이 아니라 동일 계정임을 연결하는 최소 식별값, 유효한 경고·제재 상태와 필요한 시각·계산 상태가 대상입니다. 이를 지우면 나중에 같은 사람이 재가입해도 과거 경고를 연결하지 못할 수 있습니다. 영구 제재를 자동 만료시키는 것은 이미 정한 정책과 충돌하므로 세 안 모두 유효 영구 제재는 예외로 둡니다.

예시

종현에게 유효한 경고가 있는 상태에서 탈퇴했다가 4년 뒤 돌아오는 경우: A는 경고를 승계합니다. B는 적용 기간이 끝났다면 그 옛 경고를 승계하지 않습니다. C는 그 시점이 더 빠릅니다. 어느 안이든 유효한 영구 제재는 탈퇴나 시간이 지났다는 이유로 풀리지 않습니다.

주의할 차이와 적용 조건

아래는 보관을 허용한다는 법률 판단이 아닌 제품 선택입니다. A는 최소 기록이 장기간 남는 부담이 있고, B/C는 일정 기간 후 경고 승계가 끊어지는 정책 변경입니다. 상세 증거 90일 파기·일반 프로필 삭제와 구분합니다. 원문·사진·신고 캡처를 최소 연결 기록에 넣지 않습니다. 최종 무효 판정의 제재 기여는 즉시 제거하며 필요한 무효·정정 감사 기록은 별도 기준을 따릅니다.
