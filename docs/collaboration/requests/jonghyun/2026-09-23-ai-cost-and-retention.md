# AI 대체 후보 비용·보관 조건 확인 자료

확인일: 2026-09-23. **가격 계산용 후보이며 공급사·모델 선정이나 실제 품질 평가가 아니다.** 실제 API 호출·과금은 하지 않았다. 포텐스닷이 Claude 기반이라는 내용은 사용자 제공 정보이며, 모델 식별자·기본 호출 방식은 이후 받은 [사용자 제공 안내](2026-09-23-potens-api-reference.md)에 별도 기록했다. 실제 계정의 모델 가용성·응답·조건은 검증하지 않았다. 포텐스닷을 우선 연결 대상으로 유지하며 무료 API 포함 여부·지원 모델·일일 한도·보관 조건·종료일은 미확인이다. 2027년 6월경 종료는 사용자 추정이다.

## 가정과 비용

탐색 1회의 모델 호출을 모두 합쳐 입력 4,000/출력 600토큰, 요약 1대상의 묶음·최종 합성을 모두 합쳐 입력 10,000/출력 1,500토큰이라고 **가정**한다. 출력에는 과금 대상 추론 토큰도 포함한다고 가정한다. 실제 한국어 토큰 수·대화 길이·후기 수·재시도·품질·속도는 미측정이다.

공식 일반 처리 단가 기준 계산식: `(입력 토큰×입력 단가 + 출력 토큰×출력 단가) / 1,000,000`. 캐시 할인은 계산하지 않았다. 환전·세금·도구·추가 재시도·서버 비용은 제외하므로 아래는 지출 상한이 아니다.

| 가격 비교 후보 | 입력/출력 USD·백만 토큰 | 탐색 100회 | 탐색 1,000회 | 요약 100대상 | 요약 1,000대상 |
|---|---:|---:|---:|---:|---:|
| GPT-6 Luna | 0.10 / 0.50 | $0.07 | $0.70 | $0.175 | $1.75 |
| GPT-6 Sol | 2 / 10 | $1.40 | $14 | $3.50 | $35 |
| Claude Haiku 4.5 | 1 / 5 | $0.70 | $7 | $1.75 | $17.50 |
| Claude Sonnet 5 | 2 / 10 | $1.40 | $14 | $3.50 | $35 |

[OpenAI 공식 가격](https://developers.openai.com/api/docs/pricing), [Anthropic 공식 가격](https://platform.claude.com/docs/en/about-claude/pricing).

OpenAI 신규 캐시 쓰기 입력 단가는 기본 입력의 1.25배다. 같은 가정에서 전체 입력이 쓰기 단가 대상이면 Luna 탐색 1,000회 $0.80/요약 1,000대상 $2.00, Sol은 $16/$40이다. 실제 적격 기능과 사용량에 따라 달라지며 가격만으로 팀의 보관 기준을 대신 결정하지 않는다. [공식 모델 가격](https://developers.openai.com/api/docs/models/gpt-6-luna).

예시 개발 묶음 **탐색 1,000회+요약 100대상**은 위 기본 단가에서 Luna $0.875, Sol $17.50, Haiku $8.75, Sonnet $17.50이다. OpenAI 전체 입력 캐시 쓰기 가정이면 Luna $1.00/Sol $20.00이다. 같은 사용량이라도 추가 재시도·대화 증가·요약 분할 증가로 비용이 늘 수 있다. 원화 환율은 확인하지 않았으므로 USD로 남긴다. 개발·검증 예산의 금액/기간은 최신 사용자 답변에 따라 **미정·팀 검토**다. 실제 호출 예산은 승인되지 않았다.

## 보관 관련 조사 자료 — 서비스의 요구 여부는 미정

- **OpenAI:** 학습 미사용과 기본 로그 보관은 별개다. 조직/프로젝트별 ZDR 승인과 실제 사용하는 API·모델·기능의 적격 여부가 필요하며 `store:false`만으로 미보관이 보장되지 않는다. 특정 고객/모델에 대한 사전 고지 후 예외적인 보관 정책 변경 가능성도 있다. [데이터 제어](https://developers.openai.com/api/docs/guides/your-data).
- **Anthropic:** 조직별 ZDR 계약·활성화 및 기능별 적용 확인이 필요하다. Messages API, Batch/Files/코드 실행을 같은 보관 조건으로 취급하지 않는다. 법률·안전 시스템 탐지 예외에서는 ZDR에도 입력/출력을 보관할 수 있다고 명시되어 있다. [API 보관 조건과 예외](https://platform.claude.com/docs/en/manage-claude/api-and-data-retention).
- 계산용 캐시/스키마의 보관과 원문 보관을 구분해 확인한다. 원문을 JSON Schema enum/const나 사용자 추적 필드에 넣지 않는다.
- 포텐스닷을 거치면 중간 제공사와 실제 모델 공급사 양쪽을 확인한다. 공개 사이트의 모델명은 API 지원 모델의 증거가 아니다.

**현재 적용 기준:** 2026-09-23 최신 사용자 지시에 따라 기존 “종현님이 정한 외부 AI 원문 미보관 요구” 자체와 예외 허용 범위를 **미정·팀 검토**로 바꿨다. 필수 미보관 또는 보관 허용 중 어느 쪽도 확정하지 않는다. [팀 검토 문서](2026-09-23-team-ai-retention-review.md)에 별도 정리했다. 유미당 서버의 AI 대화 이력·원문 로그 미저장은 유지하며, 팀의 기준과 계정 조건이 확인될 때까지 실제 제공사는 미활성 상태다. 아래 제공사 자료는 팀의 판단 자료이지 확정 서비스 정책이 아니다.

## 다음 결정

1. 팀이 외부 원문 미보관 요구의 필요 여부·허용 보관 범위·예외 처리 기준을 검토. 현재 사용자에게 같은 선택을 다시 요구하지 않음.
2. 포텐스닷 기본 호출 안내는 수령했다. 실제 성공/사용량/일일 한도 오류 응답·계정 조건과 보관 옵션을 추가 확인한다. 비밀키는 문서·대화·저장소에 붙이지 않음.
3. 실제 사용할 모델과 검증용 예산의 금액·기간은 팀 검토 후 선택. 예산은 사용자가 미정·팀 검토로 남겼다. 품질·속도는 같은 합성 사례로 평가.
4. 승인된 설정으로 입력/출력/재시도/동시성/예약액 계산을 고정하고 실제 호출을 별도 검증.
