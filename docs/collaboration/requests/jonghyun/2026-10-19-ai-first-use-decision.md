# AI 탐색 첫 사용 동의 확정

> 이 기록 이후의 선택·적용 상태는 [전체 문서 동기화 현황](2026-10-19-document-sync-summary.md)과 현재 정책.md·PRD·IA·USERFLOW가 우선한다. 아래 당시 미정·문서 미반영 표시는 현재 미정 목록으로 재사용하지 않는다.
사용자 확정: “AI 탐색은 첫 사용 시 동의받고, 거절하면 일반 검색 유지 ㄱㄱ”.

- IA·USERFLOW의 가입 필수 탐색 동의·첫 팝업 미제공 문구를 이번 선택으로 변경했다.
- 첫 사용 안내 → 동의 후 실행 조건 확인 / 거절 시 일반 검색. 동의 전 모델 처리·전송을 시작하지 않는다.
- 일반 동행·계정 유지, 공급사 조건 확인·회원 원문 외부 전송 보류 등 기존 실행 경계를 유지한다.
- 후기 요약은 아직 미확정이다. 열람자의 기능 이용, 프로필 대상자의 요약 노출, 원문 작성자의 데이터 처리 동의는 서로 다르다. 사용자의 양자택일 질문을 어느 한쪽 승인으로 처리하지 않았다.
- 민규 후속 요청: 정책.md·PRD에서 AI 탐색의 가입 필수 제품 의도를 첫 사용 동의로 동기화할 것. 후기 요약은 별도 결정 전 변경하지 말 것. 이전 인계의 R30 미확정 중 탐색 부분은 이 기록으로 갱신한다.
- 문서 반영이며 클라이언트·서버 동의 저장·차단 구현이나 운영 활성화 완료가 아니다. 정책.md·PRD·코드·Notion 수정, 커밋·푸시·배포는 수행하지 않았다.
