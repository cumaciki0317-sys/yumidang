### C01 · 현재 무료 MVP와 제외 기능

- 정적 대조: **부분 구현** / 다음 담당: 종현 / WBS 1.2, 6.1
- 정책: 여성 성인 회원을 위한 무료 1:1 동행 서비스다. 결제, 계좌·이메일 인증, 친구, 외부 캘린더, 관리자 행사 등록은 현재 범위에서 제외한다.

- 다음 작업: 서비스 목록·상세와 서버에서 유료 데이터가 노출되지 않는지 확인한다. 제외한 기능으로 이동하거나 실행할 수 있는 경로도 함께 검사한다.

### C03 · 사진 필수·가입 완료·사진 업로드

- 정적 대조: **부분 구현** / 다음 담당: 종현 / WBS 1.2, 6.1
- 정책: 10MB 이하의 JPG·JPEG·PNG 프로필 사진이 필수다. 사진 선택만으로 가입되지 않는다. 가입 완료 안내 팝업을 확인하면 현재 접근 가능한 보존 목적 화면으로 복귀한다. 행사 연결 작성도 여기에 포함하며, 복귀할 수 없으면 홈으로 이동한다.
- 구현 확인: 프리뷰는 사진 검사와 가입 완료 팝업을 제공하지만 확인 뒤 S00 홈으로 고정 이동하여 보존한 목적 화면으로 복귀하는 예외가 빠져 있다. 서비스는 사진 검사(validateOriginalPhoto), Storage 업로드, 가입 완료 요청(session.complete) 순으로 처리한다. 서버의 ready 응답 뒤에는 authDestination으로 바로 이동하므로 완료 안내 팝업이 없다. 실제 Storage 업로드 성공은 미확인이다.
- 다음 작업: 서비스의 가입 완료 안내 팝업과 현재 접근 가능한 목적 화면 복귀를 연결한다. 중복 요청, 응답 유실, 사진 처리 실패와 실제 Storage 업로드를 검증한다.
- 해결 후 기준: 사진 선택만으로 가입되지 않아야 한다. 검증된 ready 응답 뒤 안내를 확인하고, 접근 가능한 목적 화면으로 복귀해야 한다. 목적 화면이 없거나 접근할 수 없으면 홈으로 이동해야 한다.

### C06 · 연속 취소·정정·제재 안내 소비

- 정적 대조: **연동 대기** / 다음 담당: 민규 / WBS 1.2, 6.1
