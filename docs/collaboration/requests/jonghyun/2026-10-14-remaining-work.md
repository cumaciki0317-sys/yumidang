## 담당 밖 조건과 이미 승인된 사항

- 두 지원 도구 `tools/local/run_database_tests.py`, `tests/integration/jonghyun/isolated_ai_contracts.py`는 이전 주기에서 원복/민규 복귀를 완료했다. 이번 승인으로 두 경로만 다시 종현에 한시 배정했고 지원 패치를 준비했다. 현재 원복 대기가 아니라 최신 소스 고정·실제 실행 준비 단계다. 이번 검증/새 자원 정리 후 원 바이트와 민규 담당을 다시 복구한다.
- 민규 Auth/AI24·자연 자정·기존 Storage39 전체 복원·운영 배포 준비12개 예외는 종현 잔여 구현으로 가져오지 않는다. 종현 새 합성 Storage 검사와 민규 전체 복원은 다른 범위다.
- 실제 화면 소비는 기존 화면 담당 경계다. 성호에게 신규 배정/화면 수정 요청을 만들지 않는다. 실회원 HOLD·회원 원문 공급사 전송 조건·운영 적용 조건은 유지한다.
- 종현 VM 재시작/새 합성 대상 생성·검증·정리는 이미 승인됐다. AI 정상 결과 평가, 기존 답변 평가 방향, 운영 담당 일반 탈퇴+영수증 별도 보존 선택도 수용됐다. 기존 승인을 반복 요청하지 않는다.
- 이전27개는 로컬 커밋 완료다. 이후 신규 작업본은 별도 미커밋이며, 검토 목록이 고정되기 전 이전 승인으로 자동 커밋하지 않는다.
