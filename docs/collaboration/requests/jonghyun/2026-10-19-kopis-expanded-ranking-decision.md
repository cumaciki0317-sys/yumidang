# KOPIS 최신 확정: A안·14분류·최근7일 유지

사용자는 A안을 승인하고 전체 공연(기본), 연극, 뮤지컬, 클래식, 국악, 대중음악, 무용, 대중무용, 서커스/마술, 복합, 아동, 대학로, 내한, 축제 전체를 요청했다. 이어 일일 집계가 basedate 문제를 해결하지 못하면 최근7일을 유지하라고 확정했다.

KOPIS 순위 선택은 전체 공연(기본), 연극, 뮤지컬, 클래식, 국악, 대중음악, 무용, 대중무용, 서커스/마술, 복합, 아동, 대학로, 내한, 축제의 14항목이다. 표시명은 서양음악(클래식)→클래식, 한국음악(국악)→국악, 무용(서양/한국무용)→무용으로 바꾸되 원천 코드·원래 분류는 보존한다. 아동·대학로·내한·축제는 장르와 구분되는 공식 특성·지역 조건을 따른다.

집계는 어제까지 최근7일, 갱신은 매일이다. 분류마다 공식 사이트에 표시된 실제 기간·공식 분류/지역·정렬 기준과 API 공연ID·순위·순서가 일치한 Top10만 공개한다. basedate가 없어도 이 대조를 통과한 목록은 공개할 수 있으나 API 내부 집계 기간을 증명했다고 안내하지 않는다. 요청 날짜만으로 기간을 확정하거나 일간 순위를 합산한 자체 주간 순위를 만들지 않는다. 동률은 공식 표시 순서 그대로 유지하고 10개 미만이면 검증한 개수만 표시한다.

출처·실제 확인 기간·확인 시각을 표시한다. 갱신 실패 시 마지막 검증 목록의 기존 기간을 그대로 유지하고 갱신 지연을 안내하며 최신 날짜로 바꾸지 않는다. 최초 미검증·미지원 분류는 공식 사이트 링크를 제공하고 자체 순위로 채우지 않는다. 분류별 성공·실패를 독립 관리한다. 현재 API 매핑·자동 대조·저장·서버 응답 구현과 운영 검증은 별도이며 이 정책 변경만으로 연동 완료로 표시하지 않는다.

일간 순위 숫자·점수를 더해 주간 공식 순위를 만드는 방식은 채택하지 않았다. 공식 일별 예매액/건수를 합산하는 것도 별도 데이터·산식·자체순위 정책 선택이 필요하며 현재 공식 순위의 대체로 승인하지 않았다.

현재 매핑 증거는 [분류 매핑](2026-10-19-kopis-expanded-category-mapping.md)을 따른다. 대중무용 코드가 순위/일반웹에서 다르고 내한·축제 전용 boxoffice API 매핑은 미확인이므로 추정 코드를 넣지 않는다. 미검증 분류는 A안의 최초 공식링크 대체를 따른다. 소유권 정책은 그대로 두고 사용자의 전체 문서 동기화 예외 승인 범위에서 공통 문서도 동기화했다. 코드·DB·서버 응답·운영 공개는 변경하지 않았다.
