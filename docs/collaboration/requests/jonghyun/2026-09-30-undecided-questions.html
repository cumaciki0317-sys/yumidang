미정사항 결정표 — 13개 질문

민규·팀과 논의하려던 정책·후속 확인을 사용자가 직접 결정할 수 있게 질문으로 풀었습니다. 각 질문에 A(추천)·B·C·D(직접 작성) 네 가지가 있습니다. 다 고른 뒤 아래 “답변 전체 복사”를 눌러 대화에 붙여 넣으세요. 모르겠거나 팀과 먼저 상의할 항목은 D에 “팀 논의”라고 적거나 비워 두면 됩니다.

비워 둔 질문은 “미응답”으로 복사되며 승인으로 처리하지 않습니다. 이 페이지는 아무 데도 전송하지 않습니다. 이미 정한 것(C 의미 비교, 정렬, 24시간 주기, 포텐스닷 Sonnet 5, 추가 지출 0원·합성 입력만, 일부 결과 표시, 링크 없는 행사 카드, 성향 20개·40자, KOPIS HTTPS)은 다시 묻지 않습니다.
