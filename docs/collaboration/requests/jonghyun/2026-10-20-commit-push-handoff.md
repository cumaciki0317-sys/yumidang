## 원문 증거의 공백 검사 구분

일반 소스·문서는 diff 공백 검사를 통과했다. 저장한 unified diff 패치의 빈 문맥행(` `) 및 수정 전 실패 원로그2개의 진단 공백은 Git diff 검사의 trailing-whitespace 대상으로 나타난다. 패치 적용 문맥·원본 실패 증거를 훼손하지 않도록 이 증거 파일들은 바이트 그대로 보존했다. 누적 공통 문서 패치는 HEAD index 기준 `git apply --check --cached`를 통과했다. 소유권 hook은 정상 적용하며 체크 설정/actor를 바꾸지 않는다.
