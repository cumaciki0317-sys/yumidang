# 민규에게 전달할 직접 입력 행사 서버 연결

2026-10-20 / 종현. 사용자가 담당 확인을 요청했고 서버는 민규·클라이언트는 종현으로 구분했다. 외부 메시지는 보내지 않았다.

## 민규 담당

- 공고 전용 직접 입력 행사 저장/수정/조회 API·DB와 권한/개인정보 검사. 행사명 필수·장소/공개 행사장 주소 선택, API eventId와 직접 입력은 동시 연결 불가. 원천 행사 테이블/공용 행사 목록/독립 상세를 생성하지 않는다.
- 공개 행사장 주소와 확정 당사자만 보는 만남 상세 위치를 분리한다. 직접 입력 행사명에 대한 공고 검색 지원도 서버 계약에 반영한다.
- 행사 교체/삭제/직접 입력 실질 변경을 핵심 조건 변경으로 처리하고 기존 동의/확정 변경 절차와 연결한다.
- API 행사 선택 시 만남 일정 겹침을 필수로 검증하는 기존 서버 규칙 제거 여부 확인. 종료·취소·비표출/핵심충돌 제한은 유지한다. 날짜 겹침 비강제는 기존 확정 동행끼리의 일정 충돌 제한을 제거하는 것이 아니다.

## 종현 구현 상태

검색·선택·변경·삭제·직접 입력/주소확인·초안보존·프리뷰 공고전용 저장과 상세표시를 구현했다. 서비스 직접입력 등록은 계약 미지원 때문에 명시 차단하고 입력을 유지한다. 새 계약이 준비되면 정식 API에 연결하고 실패/재시도/등록 후 상세 응답을 검증한다. 프리뷰 local post.manualEvent는 제안용 앱 모델이며 서버 DTO로 이미 지원된다고 간주하지 않는다.

전체 lint/typecheck·20회귀·실제 웹프리뷰14항목·웹export PASS. 실제 서버 저장/권한/회원/OAuth/외부API/기기/운영은 NOT_RUN이다.
