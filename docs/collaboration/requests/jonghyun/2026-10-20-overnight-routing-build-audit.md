## 확인한 사실

- [WBS 카탈로그](../minkyu/2026-10-14-wbs-task-catalog.md)는 **2026-10-14 스냅샷**이다. 오늘 live Notion을 조회하거나 변경하지 않았다. 아래 번호는 작업 연결을 위한 것이며 현재 상태·우선순위를 실시간 확정한 것이 아니다.
- `apps/mobile/src/state.tsx`의 화면 ID 라우트23개에 대응하는 `src/app` 실제 파일이 모두 있다. 탭·상세·작성·로그인·콜백·가입 진입의 파일 존재 확인이며 딥링크 실기기 성공을 뜻하지 않는다.
- `scheme: yumidang` 설정과 앱 아이콘 파일을 확인했다. iOS bundle identifier·Android package·EAS project ID·EAS 프로필은 구성돼 있지 않다. 승인된 발급값을 임의 생성하거나 실제 계정에 연결하지 않았다.
- `MemberConnection`은 현재 웹에만 검토된 설정을 받아 세션·사진·신고 캡처 포트를 설치한다. native 인증/콜백 어댑터 설치는 없다. 웹 origin·PKCE 검사를 native 인증 완료로 재사용하지 않는다.
- 웹 access/refresh token은 메모리 전용이다. `restore`는 살아 있는 어댑터 메모리의 토큰과 가입 상태를 확인하며 브라우저 전체 새로고침 후 자동로그인 복구는 제공하지 않는다.
- 공개/회원 목록 훅은 세션 epoch·AbortController·화면 focus를 확인하여 이전 계정·떠난 화면의 늦은 응답을 반영하지 않도록 구성돼 있다. 입력·ID·상태를 검증한 서버 성공만 반영하는 기존 연결을 재작성하지 않는다. 실제 서버의 자격·권한 집행과 별도다.
- 서비스 모드 초안은 세션 epoch를 확인하는 메모리 전용이다. 미리보기 AsyncStorage의 초안/최근검색7일 정책과 다르다. 앱 재시작 후 서비스 초안 복구가 구현돼 있다고 보고하지 않는다.

## 내일 UX 확인 순서

1. 일반 작성은 행사영역 하단, 행사 상세 진입은 상단인지 확인한다.
2. 행사 날짜와 다른 동행 날짜도 입력·선택 가능하고 달력에는 참고 범위만 강조되는지 확인한다.
3. 직접입력은 공고 안에만 표시되고, 이미지 미제공/실패는 빈 영역 없이 글만 보이는지 확인한다.
4. 취소·연기·비표출·정보 미제공·조회 실패를 혼동하지 않는지 확인한다.
5. 실제 서버에 아직 없는 기능을 모형의 성공으로 설명하지 않는지 확인하고, 화면 수정/서버 의존성/유미 UT를 나눈다.
