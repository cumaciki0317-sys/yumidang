## AI 중단 후 보내기 버튼의 차단·해제 범위

- A — 서버 기준 유지 + 차단·해제 확인 수단을 민규와 먼저 연결(추천). 예: 한도 소진 후 다시 눌러도 서버가 거절하며, 안내·입력·일반 탐색은 유지한다. 이후 서버가 준비한 이용 가능 상태로 버튼을 제어한다. 정확하지만 화면에서 재요청 자체를 막는 개선은 후속이다.
- B — 현재 화면에서만 AI 전송 잠금. 예: 일일 한도·동의 필요 응답을 받으면 새 대화로도 풀리지 않고 화면을 나갔다 돌아올 때만 다시 시도한다. 중복 거절을 줄이지만 재진입이 실제 한도 복구를 뜻하지는 않는다. 동시 요청·일시 장애는 이 잠금에 포함하지 않는다.
- C — 이번에 민규의 이용 가능 상태 API까지 연결한 뒤 버튼 잠금·해제를 완성. 다른 기기 요청 종료·자정 한도 초기화·재동의를 서버 기준으로 반영할 수 있다. 민규 작업과 계약 합의가 필요하며 이번 종현 단독 범위를 확대한다.
- D — 기타: 직접 작성.
