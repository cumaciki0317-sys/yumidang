- [최종 확정 명세](2026-10-20-event-ux-approved-spec.md)

일반 작성은 행사 영역 하단·행사 상세 진입은 상단, 일정 겹침 강제/자동 검색 축소 없음·달력 날짜 강조다. 직접 입력은 공고 전용, 공식 동일 개최 근거가 확실한 원천만 통합, 원천별 공개 조건과 핵심 충돌 제한을 적용한다. 처음 제시한 추천안이나 원본 선택표에 남아 있는 날짜 자동 축소를 현행 정책으로 사용하지 않는다.

민규·유미 담당을 포함한 모든 관련 문서 동기화는 사용자 명시 승인 범위다. 예외는 문서에 한정하고 actor·ownership·hook·서버 코드/DB·운영·커밋/푸시를 변경하지 않는다.
