## 검사와 승인 예외

[이번 하네스](2026-09-30-jonghyun-integration-harness.json)에 최초 해시·정확한 커밋별 경로·독립 검토 역할을 기록했다.

- **PASS:** 독립 범위 검토. 초기 167개가 기존 승인·하네스·인계에 포함된다. 알려진 미확인 제품 변경은 없다.
- **PASS:** 비밀정보 검사. 실제 `.env` 비밀값과 공유 파일의 일치 0건, 독립 토큰 패턴 검사도 노출을 발견하지 못했다. `.env`는 계속 Git 제외다. 비밀값은 출력·기록하지 않았다.
- **정적 소유권 예외:** 첫 정책 커밋은 `--actor jonghyun --staged`가 민규 경로 24개를 거절한다. 이는 [기존 후기 정책 승인](2026-09-29-review-policy-harness.json)의 정확한 36개 경로 안이며 사용자·민규의 명시 경계 예외를 적용했다. 통상 소유권 PASS로 꾸미지 않는다. 이후 구현 102개는 jonghyun 검사 PASS다.
- **공백 검사:** 코드·일반 문서는 PASS. 기존 `claude-scheduled-jobs-index.diff`의 빈 문맥행 공백과 끝 빈 행은 유효한 unified diff의 원본 근거이므로 보존했다. 이 파일의 기준 해시와 역적용 결과를 확인했다. 과거 실패 근거 `repro-lease.log`의 빈 진단행 2개도 원본 해시를 유지했다.
- 소유권 정책·hook·작업자 설정을 바꾸거나 `--no-verify`를 사용하지 않았다. 원래 로컬 actor/hooks 설정과 기본 pre-commit은 없었으며 그 상태를 유지했다.

## 민규가 이어받을 때

종현 브랜치를 민규 브랜치로 병합하는 것은 **Git 소스 통합**이다. 제안 SQL 5개는 여전히 `requests/jonghyun/2026-09-29-claude-proposed-sql/`에 있고 정식 마이그레이션으로 채택하지 않았다. 이번 커밋으로 정식 이력에 들어간 기존 후기 정책 SQL까지는 28개이며, 제안 5개 적용 시 33개인 로컬 검증과 구분한다.

민규 허용 목록·환경·공통 HTTP 연결, 기존 service-api 타입 오류·gateway CORS 문제, 팀의 비용·보관·품질·운영 결정은 남아 있다. 실제 AI 호출은 추가 지출 0원 근거 전까지, 회원 원문 전송은 보관 답변과 사용자 확인 전까지 진행하지 않는다. 운영값 제안은 확정값이 아니다.

로컬 DB는 이전 검증 종료 때 28개로 복구하고 합성 자료 0건·Supabase/전용 Colima 정지를 확인했다. 이번 커밋 작업에서는 DB를 켜거나 바꾸지 않았다.
