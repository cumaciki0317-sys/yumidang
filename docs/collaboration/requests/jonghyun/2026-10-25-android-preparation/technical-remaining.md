# 현재 남은 기술 작업 — UX/UI 제외

사용자 최신 지시에 따라 UX/UI는 사용자가 나중에 진행한다. 진행 중이던 최근검색어 삭제 UI 검사는 명령 완료 결과만 회수했다. 재실행 후 삭제 유지 여부는 실행하지 않았으며 전체 저장검증 완료로 처리하지 않는다.

|영역|완료 근거|다음 선행 조건|
|---|---|---|
|행사/회원/AI FE 소비|event/member-ai 기록과 합성 회귀|민규 service-api 배포·실제환경/인증/Storage/검사 활성 인계. 사용자 지시로 실제연동 건너뜀 유지|
|Native 인증|기존 포트/계약 차이 및 인계8종 정리|민규 native callback·교환·수명 인계 후 앱 연결. 실제회원 HOLD 유지|
|Android 내부 APK|패치 APK 빌드·서명·manifest·설치·cold restart 증거|내부 예시 검증은 확보. 실제회원/스토어 완료 아님|
|Router 보안|공식0.5.1 앱별칭·compiled 모듈19벡터·APK소스맵|CLI 도구 의존성 잔여. 호환안 없는 major 변경이나 위험 수용을 임의 결정하지 않음|
|운영 AAB/Play|기존Play앱 없음 사용자확인|운영 package ID·키관리주체·Console 권한 결정. 기존 dev.yumidang.validation은 검증전용|
|공유 인계|WBS 관련 Task에 결과/미실행 기록|현재 event+Android 변경은 미커밋·미푸시. 이전 회원브랜치 승인 재사용 안 함|

새 UX/UI 개선을 기술 잔여로 바꿔 진행하지 않는다. 폴더에 남은 기존 화면 변경은 이미 수행한 행사통합분이며 이번 범위 제외를 이유로 되돌리지 않는다.
