# 미정사항 — 민규·팀 확인·처리 목록 (종현 범위, 2026-09-30)

사용자가 확정한 결정은 [설계 결정 표](../../../../260929_종현담당_PLAN.md)(1절)로 옮겼다. 이 문서에는 **민규·팀이 알아야 하거나 직접 처리해야 할 것만** 남긴다. 구현 상세는 [인계 문서](2026-09-29-claude-implementation-handoff.md), 민규 작업 목록은 [변경 요청 R1~R7](2026-09-29-claude-minkyu-requests.md)을 본다.

## 1. 팀이 처리할 것

| # | 할 일 | 누가 | 왜 필요한가 | 끝나면 |
|---|---|---|---|---|
| T1 | **포텐스닷에 한 줄 문의: “API로 보낸 입력·응답을 보관하나요? 보관한다면 기간은?”** | 팀 | 포텐스닷 보안 문서에 “학습에 쓰지 않음·타사 미배포”는 있으나 **보관 기간은 없다**(2026-09-30 확인). 실제 회원 대화·후기를 보내려면 이 답이 필요하다 | 답변을 이 문서에 기록 → 사용자 확인 후 실제 입력 허용. 그 전까지 가상 입력만 |
| T2 | **포텐스닷 마이페이지의 요금제·일일 한도·API 무료 포함 여부 화면 공유(키가 안 보이게)** | 계정 보유자 | “추가 지출 0원” 근거. 없으면 실제 AI 호출을 하지 않는다 | Claude가 가상 사례로 10번만 호출해 첫 결과표 작성 |
| T3 | **첫 결과표 사람 검토(2명 이상)** | 팀 | 요약·AI 설명이 괜찮은지 사례별 적절/부적절 판정. 자동 규칙은 계속 적용 | 판정을 보고 품질 기준 확정 → 요약·설명 켜기 |
| T4 | **KOPIS에 문의: ① HTTPS(`https://kopis.or.kr`) 공식 지원 여부 ② 공연 상세 페이지 공식 링크 규칙** | 팀 | 공식 가이드는 HTTP만 표기. 현재 HTTPS로 동작 중이며 상세 링크 없이 표시 | 답변 기록. 인증서 만료(2026-12-13) 전 HTTPS 재확인 |
| T5 | **운영 한도·AI 예산 원장 제안값 표 검토·확정** | 민규·팀 | 모든 운영 숫자는 기본값 없이 환경값으로만 받는다. Claude가 보수 제안값 표(항목별 이유)를 [운영값 제안](2026-09-30-operational-values-proposal.md)으로 작성 | 확정값을 환경에 입력 |

## 2. 민규가 처리할 것

| # | 할 일 | 비고 |
|---|---|---|
| M1 | **일일 실행 예약 등록: 매일 00:01 (Asia/Seoul)** → `POST /functions/v1/scheduled-jobs/daily` | 사용자 결정. 날짜 경계(00:00) 혼동을 피해 00:01. 같은 날 두 번 실행돼도 중복 없음 |
| M2 | **AI 예산 원장 운영**: 기간마다 새 원장으로 교체, 이전 원장은 기록 보존 | 교체 주기·한도 제안은 T5 문서. 중단된 호출 예약은 ‘사용함’으로 남는 보수 처리라 교체가 필요 |
| M3 | **공개 프로필(S14) 응답에 성향(관심사·대화 방식·MBTI) 추가** | 사용자 결정. 성향 전용 조회는 그대로 유지 |
| M4 | [변경 요청](2026-09-29-claude-minkyu-requests.md) R1~R7: 제안 SQL 채택, DB 호출 허용 목록, 공개 행사 조회·성향 저장 HTTP 경로, 함수 등록·환경값, 계약 문서 동기화, `routes.ts` 타입 오류, 게이트웨이 CORS | 반영 전까지 새 AI·요약·행사 기능은 실제 서버에서 꺼져 있다 |
| M5 | 운영 환경에 Kakao 키를 넣을 때 장소 검색 1회 확인 | 예전 403은 이번 환경에서 재현되지 않음. 다시 403이면 오류 유형 기록 |
| M6 | 건별 자동 완료 실행기의 상주 호스트·DB 연결·운영 전환 일정 | 기존 미정 |

## 3. 참고(결정됐지만 운영에 영향)

- 행사 두 번째 공급사는 **TourAPI**로 연결한다. 발급 키 형식은 두 방식 모두 정상 확인(인코딩 대상 문자 없음) → `TOUR_API_KEY_FORMAT=decoded`. 운영 환경에도 같은 값 입력 필요.
- 행사 필터는 제공처 원문 값(예: “연극 · KOPIS”)을 그대로 쓰고, 공급사가 많아지면 앱 분류 대응표를 한 겹 추가한다.
- 서울 열린데이터는 HTTPS가 없어 연결하지 않는다(필요해지면 HTTPS 지원 문의).
