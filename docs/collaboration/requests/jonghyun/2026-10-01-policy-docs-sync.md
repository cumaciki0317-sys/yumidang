첫 채팅으로 신청을 성립시키는 대안, 최근 검색·임시저장·목록의 수치, AI 결과 처리 세부, 노쇼·분쟁·운영·보관·추후 유료 정책은 답변의 팀 검토 상태를 유지했다. 추가로 사용자가 결정해야 할 새 충돌은 발견하지 못했다.

## 재검토 결과와 한계

현재 문서의 로컬 파일·제목 연결과 변경 공백 검사는 통과했다. 순수 과거 기록 한 곳(`2026-09-29-search-policy-correction.md` 34행)에 삭제된 추가 요구 원문을 가리키는 링크가 남는다. 현재 작업 진입점으로 사용하지 않으며 당시 원본은 기준 커밋의 Git 이력으로 확인한다. 역사적 원문을 최신 정책으로 덮어쓰지 않았다.

파일별 보존 해시·78개 대조·현재 구현 차이와 검사 범위는 [검토 결과](2026-10-01-policy-docs-review.json)에 있다. 실행 기능·DB 재생·외부 공급사·원격 배포는 검사하지 않았다. 네이버 연결, 숫자 나이·연결 행사 검색, 동의·선제 후기, 공식 순위와 개인정보 탐지는 실제 구현과 별도 대조가 필요하며 과거 PASS를 새 정책의 구현 완료 근거로 삼지 않는다.
