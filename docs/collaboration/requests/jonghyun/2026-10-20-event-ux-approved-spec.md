# 행사 UX 최종 확정 기준

2026-10-20 / 종현 / 사용자 작성본12개 및 후속 F01·F02·F03 모두 A 명시 승인. 현재 문서는 제품 설계 확정이며 코드·DB·배포 완료와 다르다.

## 최종 결정

### 작성·검색·직접 입력

- 일반 공고 작성은 행사 영역을 맨 아래, 행사 상세의 이 행사로 동행 구하기에서 시작하면 맨 위에 둔다. 행사 연결은 선택이다.
- 행사 선택은 만남 일정과의 겹침을 강제하지 않는다. 만남 날짜가 달라도 연결 가능하고 행사 검색도 동행 일정으로 자동 축소하지 않는다. 달력에서 연결 행사의 진행 날짜를 색으로 표시하되 사용자 선택/작성 일정을 자동 변경하지 않는다. 기존 확정 약속끼리의 일정 충돌 제한은 유지한다.
- 일반 행사 기본 목록은 이번 주 신규 중 미종료, 진행 중 포함 선택·과거 조회 유지. 검색은 실제 조회 가능한 전체 기간에서 찾고 범위를 표시한다. 작성용은 연결 가능한 예정·진행 중 전체에서 검색·탐색,10개씩 더보기. 0건과 조회 실패를 구분하고0건에 조건 변경/직접 입력 제공.
- 직접 입력은 행사명 필수, 장소명·공개 행사장 주소 선택. 주소는 기존 장소·주소 검색으로 선택하고 공개 확인·개인 주소 금지 안내·기존 의심정보 검사를 적용한다. 찾지 못하면 행사 주소 생략 가능. 공고 자체의 필수 약속 장소는 별개다.
- 직접 입력은 공고 안에만 표시하고 공통 행사 목록·독립 행사 상세·검수 후 공용화 절차를 만들지 않는다. 개인 취미 공연·외부 원데이클래스도 가능. 별도 행사 기간·이미지·요금 입력은 받지 않고 필요하면 공고 소개에 작성한다.
- 연결 카드 버튼은 변경·삭제. 삭제는 해당 공고의 행사 연결만 제거하고 원천 행사는 삭제하지 않는다.

### 카드·상세·관계

- 행사명은 목록 최대2줄·말줄임, 상세 전체. 카드 순서는 대표 이미지(있을 때)→분류·상태→이름→기간→지역·행사장→요금. 대표 이미지는 전체가 보이게 자르지 않고, 없거나 로딩 실패면 영역 자체를 생략해 글만 표시한다.
- 날짜는 하루 YYYY.MM.DD, 같은 해 기간 YYYY.MM.DD ~ MM.DD, 연도 경계 YYYY.MM.DD ~ YYYY.MM.DD. 진행 중·예정·종료는 기간 상태이며 개장·잔여석·예약 가능 보장이 아니다.
- 장소는 카드에 지역·행사장, 상세에 공개 행사장 전체 주소. 상세주소를 행사장명으로 오인하지 않는다. 공고 목록 공개 지역은 동까지이며 공개 행사장 주소와 확정 당사자만 보는 상세 만남 지점은 별도다.
- 요금은 명시 무료/명확한 단일 금액/요금 상세 확인/요금 정보 없음. 빈값을 무료로 표시하지 않고 상세에 원래 안내를 표시한다. 외부 입장료와 무료1:1 동행은 별개다.
- 분류는 명확한 대응만 통일해 클래식·국악·무용을 사용하고 세부 분류 없으면 행사 등 넓은 이름. TourAPI에서 실제 수신된 관광타입15 전체(축제6·공연10·행사4)를 포함한다. 시설타입14로 확대하지 않는다.
- 행사 상세 순서: 명칭·분류·상태→이미지→기간·시간·장소·공개 주소·요금→소개→제공된 추가 관람 안내→유효한 공식/예매 링크→연결 공고. 기본 정보 누락은 안내, 선택 부가 정보는 없으면 생략.
- 연결 공고는 내부 행사 관계로 조회해 전체 상태·등록 최신순 기본, 모집 중 필터,10개씩 더보기. 삭제/차단/본인 숨김/비로그인 개인정보 등 기존 권한 유지.0건이면 아직 이 행사에 등록된 동행 공고가 없어요 안내.
- 행사 상세에서 이 행사로 동행 구하기는 해당 행사를 미리 연결한다. 비로그인은 로그인/가입 완료 후 원래 행사 연결 작성으로 복귀하고 현재 연결 가능 상태를 확인한다. 미완료/취소 로그인은 작성 권한을 주지 않는다.
- 공고 상세에는 연결 행사 종류·이름·행사기간·행사장·이미지(있을 때)와 행사 정보 보기. 직접 입력은 별도 상세로 이동하지 않는다. 행사 연결 없으면 영역 생략.

### 원천 상태·등록·변경

- 새 연결은 예정/진행 중 가능, 종료/공식취소 불가, 연기 일정 미정 불가, 변경 일정 확인 뒤 조건에 맞으면 가능. 공식 취소 시 취소된 행사예요 안내. 확인된 비표출은 새 선택에서 제외한다.
- 취소·연기는 의미가 검증된 공식 원천 값만 표시한다. 취소·연기·원천 일정 변경으로 기존 동행을 자동 취소/변경하지 않는다. 단순 검색 누락은 취소/삭제/비표출의 근거가 아니다.
- 취소 여부 미제공은 별도 보존하고 정상 수집·유효 기간 등 기본 조건을 충족하면 연결 허용. 공식 정상 개최 확인으로 표시하지 않고 개최 여부는 공식 안내 확인을 안내한다. API 오류·손상·상태 해석 실패를 미제공으로 바꿔 허용하지 않는다.
- 등록 직전 우리 서버의 최신 연결 가능 상태 확인. 확인 실패 시 입력을 보존하고 다시 확인 또는 사용자가 행사 연결 삭제 후 등록 가능. 선택 행사 자동 삭제·외부API 매 등록 직접호출 없음.
- 작성자의 행사 교체·삭제·직접 입력 행사명/장소의 실질 변경은 핵심 조건 변경. 확정 전 기존 알림·최종 동의 무효화/재요청, 확정 후 기존 상대 수락 절차 적용. 수락 전 기존 약속 유지. 기관 자동 갱신은 작성자의 변경과 구분한다.
- 확인된 취소·연기·변경 일정은 연결 공고 작성자와 진행 중 동행의 확정 상대에게 앱 안 알림. 동일 변화 중복 방지. 단순 조회자/종료 동행 전체 알림·새푸시 도입은 하지 않는다.
- 비표출 A: 연결된 행사 정보를 현재 제공할 수 없어요 / 행사 취소를 의미하지는 않아요 안내 카드로 대체. 해당 원천의 행사명·이미지·설명·주소와 상세 이동 숨김. 공고·약속·내부 연결 보존. 직접 입력에는 적용하지 않는다.
- 재표출은 명시 상태/공개 조건과 최신 자료를 검증한 뒤 자동 복원. 종료된 행사도 기존 공고 과거 열람은 가능하나 새 연결은 막는다. 취소/연기 상태가 남으면 그 안내를 유지한다.

### 동일 행사 통합 — F02 A·F03 A

- 행사 단위의 공식 공통 식별자·정확한 공식 행사 상세 링크 등 확실한 근거로 동일 개최 단위임을 확인할 수 있는 원천들만 통합해 대표 카드·상세·연결 공고를 제공한다. 공통 기관 홈페이지·제목/날짜/장소 유사성만으로 합치지 않는다. 근거 부족이면 출처별 유지한다. 상시 수동 검수 업무는 만들지 않는다.
- 모든 provider+sourceId, 원천별 공고 관계·통합 근거·통합/분리 기록을 보존한다. 기존 링크·공고를 잃지 않고 통합을 되돌릴 수 있어야 한다. 실제 공통 식별 근거 확보는 별도이며 초기 통합 건수가0이어도 검증 없이 묶지 않는다.
- 먼저 통합 검증을 통과한 공개 원천을 대표로 유지하고, 비어 있는 항목만 다른 검증된 공개 원천으로 보완하며 필드별 출처를 남긴다. 대표가 비표출이면 그 값을 재사용하지 않고 다른 유효 공개 원천으로 전환한다.
- 비표출된 원천 자료만 숨기고 다른 유효 공개 원천은 유지한다. 공개 원천이 하나도 없으면 기존 비표출A 안내 카드. 기간·장소·취소/연기 등 핵심 충돌은 기관별 정보가 달라 확인이 필요해요 안내와 새 연결 제한, 기존 약속 유지. 조용히 원천 값을 혼합하거나 미제공을 정상으로 조작하지 않는다.
- KOPIS 공식 순위는 일반 행사 통합과 별개다. 집계기간 대조·공식 분류별 Top10 목표를 변경하거나 공급사 순위를 합치지 않는다.

## 구현·운영 경계

- 이번 문서 전체 동기화는 사용자 명시 예외 승인으로 민규·유미 담당 문서도 포함한다. HEAD 소유권 검사 거절을 통과라고 바꾸지 않고 actor/ownership/hook은 변경하지 않는다. 예외는 문서뿐이며 서버코드·DB·운영·커밋·푸시로 확대하지 않는다.
- 종현: FE/UXUI/클라이언트 소비·빌드 준비. 민규: 서버 저장·공개 DTO·기간 필수 검사 변경·원천 상태·동일 행사 통합·핵심조건 변경계약·알림. 유미: UT. 모형/합성 검증과 실제 서버 연결·실회원/운영 검증을 구분한다.
- 서울 HTTPS 및 일일 수집은 민규 인계. KOPIS 기간대조는 결과 후 판단하며 기타 데이터·화면 개발과 독립 진행. 신규 실회원/원문전송/배포/추가결제/외부메시지는 실행하지 않는다.
