# 후기 요약 가입 필수 동의 세 항목 확정

> 이 기록 이후의 선택·적용 상태는 [전체 문서 동기화 현황](2026-10-19-document-sync-summary.md)과 현재 정책.md·PRD·IA·USERFLOW가 우선한다. 아래 당시 미정·문서 미반영 표시는 현재 미정 목록으로 재사용하지 않는다.
2026-10-19 사용자 확정: 요약 열람과 내 프로필 요약 생성·노출에 이어, 원문 처리도 “가입 시 필수 동의 + 후기 작성 시 짧은 재안내”로 승인했다.

## 가입 화면

별도 체크 세 개, 기본 미선택, 짧은 안내와 자세히 보기로 구성한다.

가입 약관 상단에 `전체 동의`를 제공한다. 선택하면 같은 화면의 모든 개별 동의 항목이 선택되고, 해제하면 모두 해제된다. 개별 항목을 해제하면 전체 동의도 해제 상태가 되며, 모든 개별 항목을 선택하면 전체 동의가 선택된다. 개별 동의와 자세히 보기는 유지하고 기본값은 모두 미선택이다. AI 탐색 첫 사용 동의는 가입 화면의 전체 동의에 포함하지 않는다.

- [필수] AI 후기 요약 열람에 동의합니다
- [필수] 내 프로필의 AI 후기 요약 생성·노출에 동의합니다
- [필수] 내가 작성한 후기를 상대방 프로필의 AI 후기 요약 생성에 사용하는 데 동의합니다

실제 전송 항목·공급사·보관 조건은 상세 안내에서 설명해야 한다. 위 문구가 구체적인 정보 설명을 대신하지 않는다.

## 후기 작성 화면

“작성한 후기는 상대방의 AI 후기 요약에 활용돼요”를 짧게 안내한다. 매번 별도 동의 체크를 반복하지 않는다.

예: 종현이 유미에게 쓴 후기를 활용하려면 종현의 원문 처리 동의와 유미의 프로필 요약 생성·노출 동의를 구분해 확인한다. 이를 읽는 회원의 요약 열람 동의도 별도 상태다.

## 반영과 남은 결정

IA·USERFLOW에 반영했다. AI 탐색은 첫 사용 동의·거절 시 일반 검색 유지다. 철회 시 기존 후기·요약의 처리는 아래 내용으로 확정했다. 기존 회원 적용은 아직 미확정이다. 이미 명시된 새 전송 중단·계정/일반 동행 유지 등 기본 철회 방향을 폐기한 것은 아니다.

민규 후속 요청: 정책.md·PRD의 후기 요약 동의를 위 세 항목과 작성 시 재안내로 동기화할 것. 이전 인계의 두 항목 확정·원문 처리 미정 표시는 이 기록으로 갱신한다.

이번 작업은 문서 동기화다. 기존 법적 적합성 확인 전 실제 가입 차단·회원 원문 외부 전송 보류를 유지한다. 동의 UI·서버 저장 구현 완료를 뜻하지 않는다. 정책.md·PRD·코드·Notion은 직접 수정하지 않았으며 커밋·푸시·배포는 없다.

## 철회 구체 처리 — 사용자 확정

세 동의를 독립적으로 철회하고 계정·일반 동행을 유지한다. 일반 후기 원문·별점·당도는 AI 동의 철회만으로 삭제하거나 변경하지 않는다. 일반 후기 삭제·숨김·무효 정책은 별도 적용한다.

- 열람 동의 철회: 본인의 요약 열람만 중단한다. 다른 회원에게 보이는 본인 요약·본인이 작성한 후기의 활용 허용은 별도 동의가 유지되는 한 자동 철회하지 않는다.
- 내 프로필 생성·노출 철회: 본인 프로필 요약을 숨기고 신규 생성·갱신을 중단한다. 다른 회원 요약 열람과 본인이 타인에게 쓴 후기의 활용은 별도 동의 상태를 따른다.
- 원문 처리 철회: 본인이 쓴 모든 기존·향후 후기를 AI 요약 재료에서 제외한다. 해당 후기를 사용한 기존 요약은 우선 숨기고 남은 허용 자료만으로 재생성 가능한 경우 교체한 뒤 공개한다. 남은 자료가 없거나 적격성·전송 조건이 미확인이면 요약을 계속 숨긴다. AI용 원문 복제본·외부 사본·관련 생성물의 필요한 삭제를 추적하고 확인 전 삭제 완료로 표시하지 않는다.

사용자의 “ㄱㄱ” 답변으로 위 세분화 처리를 확정해 IA·USERFLOW에 반영했다. 다른 동의는 자동 철회하지 않으며 재생성은 남은 자료의 활용 동의·대상자의 생성/노출 동의·기존 공개 조건과 실행 조건을 모두 충족할 때만 가능하다. 실패·적격성 미확인 시 숨김을 유지한다. 공급사의 실제 삭제 지원·보관 조건은 이 제품 선택만으로 확인된 것이 아니다.

민규 후속 요청: 정책.md·PRD·서버 계약에도 이 세분화 처리를 동기화할 것. 일반 후기 저장 원문과 AI 처리용 복제본을 구분하고 영향받은 요약 추적·숨김·재생성·외부 삭제 확인을 구현 검증할 것. 이번 작업은 문서 반영이며 해당 코드·운영 처리의 구현 완료가 아니다.
