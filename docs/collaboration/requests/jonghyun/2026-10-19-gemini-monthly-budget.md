# Gemini 월 실제 청구 한도 요청과 설정 상태

사용자 확정: 월 한도 50,000원은 선충전·정액 결제가 아니라 실제 사용한 만큼만 지불하되 최대 월50,000원까지의 지출 제한이다. 선결제·자동 충전·초과 청구 허용으로 해석하지 않는다. 사용자가 선택한 기존 결제계정은 My Billing Account이며 통화KRW·활성 상태를 읽기 확인했다.

## 실제 상태 — 결제 연결·한도 등록 완료

사용자가 “한도 등록, 결제 연결 ㄱㄱ”라고 추가 승인한 뒤 테스트 프로젝트를 My Billing Account에 연결했고 billingEnabled:true를 확인했다. 선결제·충전·자동충전은 하지 않았다.

- 범위: 테스트 프로젝트 `yumidang-jh-test-261019`의 Gemini API 서비스만. 다른 프로젝트나 전체 결제계정 한도를 바꾸지 않았다.
- 한도: 원화50,000원·MONTH·크레딧 제외 총 예상 사용비용 기준의 사용중단 예산.
- 실제 Google 조회: HTTP200, `spendCap.outputState:CONFIGURED`, `amount.specifiedAmount.currencyCode:KRW`, `units:50000` 확인.
- 알림:50%/80%/100%, 즉25,000원/40,000원/50,000원. 프로젝트 수신자 안내 활성화.
- 알림 전용 예산이 아니라 사용중단 spendCap을 등록했다. 실제 초과 상황을 만들기 위해 비용을 발생시키는 테스트는 하지 않았다.
- 예산 리소스와 검증 응답: [JSON 기록](2026-10-19-gemini-budget-result.json).
- 생성 호출·실회원 데이터 전송·앱/서버 어댑터 활성화는 하지 않았다.

결제 연결 전 요청은 HTTP400으로 실패했으나, 연결 후 같은 한도 등록과 재조회는 성공했다. 현재 적용 상태는 성공 응답이 우선하며 당시 거부를 현재 실패 상태로 사용하지 않는다.

## 공식 기능의 한계

[Cloud Billing spend cap](https://docs.cloud.google.com/billing/docs/how-to/budgets-spend-caps)은 Gemini 단일프로젝트/서비스별 사용중단 예산을 지원한다. [공식 API 예제](https://docs.cloud.google.com/billing/docs/how-to/budget-api-spend-cap)대로 월·크레딧 제외·50/80/100%알림·프로젝트수신·CONFIGURED를 요청했다.

[Gemini 청구 안내](https://ai.google.dev/gemini-api/docs/billing)는 집계 약10분 지연·진행 중/장기 요청 초과 가능성을 설명한다. 사용중단 예산도 최종 실제 청구액50,000원 이하를 단독으로 보장하지 않는다. 세금 포함 여부도 이번에 확인되지 않았다. 원화 계정이므로 임의 달러 환산은 하지 않았다. 신규 선불을 요구하면 사용자 후불 지출 제한 요청으로 선불을 승인했다고 해석하지 않는다.

## 실제 운영 차단에 필요한 연결

민규 담당의 기존 예산 포트는 토큰/기술단위 원장이며 원화 월 지출차단이 아니다. Gemini 요금·입력/출력/추론·도구비용의 최대치를 산정하고, 확정비용+미정산예약+다음호출 최대비용을 원자적으로 검사하는 별도 화폐 예산 연결이 필요하다. 응답유실·타임아웃은 예약을0으로 돌리지 않는다. 가격/사용량/원장 확인 실패는 안전 중단하며 직접키·로컬·AIStudio 등 우회 경로도 통제해야 한다. 세금·요금·최종 청구 범위 확인 전 임의로4만원 등의 하위값을 확정하지 않는다. 이번 작업에서 서버 코드·RPC·운영 환경은 바꾸지 않았다.

## 테스트 뒤 대표 계정 전환 — 사용자 방향

종현 본인 Google 계정의 테스트가 정상적으로 끝나면 대표 유미 계정으로 전환할 예정이라는 사용자 답변을 기록한다. 테스트 프로젝트를 곧바로 운영 프로젝트로 간주하지 않는다. 전환 방식은 대표 소유 프로젝트/키 또는 프로젝트 소유권 이전 중 실제 계정·권한·운영 경계를 확인해 정한다. 지금 유미 계정 로그인이나 결제 접근을 수행하지 않았다.

전환 시 확인 항목: 유미 소유권·키/서비스계정·Gemini 제한, 선택 결제계정·KRW한도 재설정, 실제 생성/오류/한도·동의 데이터 전송 검증, 종현 쪽 유료 호출 중단·새 연결 성공 확인 후 이전 키 정리, 최종 비용 대조. 월5만원의 전체 범위를 임의로 두 계정 각각5만원으로 늘리지 않는다. Google 결제계정을 바꾸면 기존 cap이 삭제/재설정될 수 있으므로 새 계정에서 확인한다. 실제 유료활성화·운영 전환 완료는 별도 증거가 필요하다.
