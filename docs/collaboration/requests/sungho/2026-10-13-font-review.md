# 화면별 폰트 후속 점검

작성자 sungho · 2026-10-13

## 사용자 요청

전체 점검 결과를 기억하고, 이후 각 화면 작업을 시작할 때 해당 폰트 개선 항목을 추가로 안내한다. 전체 화면 일괄 변경은 요청받지 않았다. 다음 작업은 기존 순서의 S09-2 조건 초기화·예시 정렬 보완이다.

## 점검 범위와 기준

업로드 HTML/CSS 소스 기준이며 루트 16px에서 환산했다. 실제 브라우저 전체 상태·확대·줄바꿈 검증은 미실시. 주요 정보 14px, 보조 정보 12px는 이번 UX 제안이며 접근성 규격의 절대 최소값으로 단정하지 않는다. 디자인시스템의 입력/탭 14px와 기존 제목·주요 버튼을 존중한다. 적용 시 320/390px와 텍스트 확대에서 잘림을 확인한다.

| 화면 | 후속 안내 항목 |
|---|---|
| 홈 | 카테고리/더보기 10.9~11.3→12px, 날짜·시간12.8→14px, 행사 보조정보 약11.7→12px |
| 둘러보기 S01 | 검색13.2/필터12→14px 검토, 일정·지역12.8→14px, 작성자11.7→14px, 배지·당도·시각·프로필 링크10.1~10.9→12px |
| 공고 상세 S02 | 본문13.2→14px, 모듈제목13.2→15~16px 검토, 이름11.7→14px, 조건 라벨12/일반 값14px, 작은 보조12px. 강조 일시·지역16px 유지. 340px 이하 제목12/배지9.75 축소 규칙 개선 |
| 행사 목록 S09-2 | 설명11.29→12px, 일정11.29/장소12.05→14px, 관련 링크11.29→12px 이상, 순위탭13.19→14px 검토 |
| 행사 상세 S09-3 | 정보값13.19/운영시간12.05→14px, 출처·상태·당도·링크10.14~10.90→12px, 프로필명11.67→14px |
| 로그인 S05 | 안내13→14px, 하단 안내11→12px. 주요 버튼16 유지 |
| 가입 S06 | 공개정보 안내11→12px, 중요한 설명13→14px. 본문/입력14·주요 버튼16 유지 |
| 나 S13 | 남은 내 공고 상대정보10~12px, 당도 설명11px, 통계 라벨11px 점검. 이름14·보조12px 제안 |

## 이미 적용한 S13

안전·계정 메뉴14px(구역 제목13 유지), 보낸 신청 공고명14/보조12px, 프로필 메뉴14px, 일정 카드 상태·상단 날짜12/날짜시간14px. 공고명 약15.1/후기 버튼14 유지.

## 작업 경계

원본 ZIP·실제 앱·백엔드 변경 없음. 각 화면 편집 전에 sungho 소유권 검사. 개별 둘러보기/상세와 연결판은 현재 같은 CSS이나 향후 변경 시 양쪽 반영 여부를 확인한다. 프리뷰 전용 컨트롤과 실제 제품 안내를 구분한다.
