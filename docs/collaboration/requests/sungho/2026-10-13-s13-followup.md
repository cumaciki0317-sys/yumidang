# S13 장면 데이터 정합성 보완

작성자 sungho · 2026-10-13

사용자의 다음 작업 요청에 따라 성호 원본 시안의 완료 횟수·확정 상대 이름을 보완했다. actor sungho, sungho/ui-design. 수정 전 소유권 검사 통과. 단순 장면 데이터 수정으로 주 작업자만 편집했다.

## 변경

- `apps/mobile/design/sungho/html/extracted/유미당-나-S13-소스/views.json`: 완료 카드가 하나 있는 me·host의 세 탭 모두 완료 배지와 요약 숫자를 1로 맞췄다. peer는 완료 0회를 유지한다.
- host의 받은 신청 중 `동행 확정` 항목만 `김민지 님의 신청`으로 표시한다. 다른 상태의 이름을 일괄 교체하지 않았다.
- 같은 폴더의 `유미당-나-S13.html`을 기존 build.py로 재생성했다. 디자인·CSS·탭 동작·당도 15는 유지했다. 완료 횟수만으로 당도를 올리지 않는다.
- ZIP 원본과 실제 앱 코드는 수정하지 않았다.

## 검증

- 기존 test-ui.cjs: 12개 고정 보기의 모의 DOM 검사 통과. 게스트 정보 비표시·탭·후기 버튼 예시 유지 확인.
- 브라우저 390px: 회원 3명의 세 탭을 각각 전환해 me/host 완료 1, peer 완료 0, 당도 15, host 확정 상대 전체 이름을 확인했다. 비로그인 전환 시 회원 요약이 없어지는 것도 확인했다.
- 앱 lint/typecheck는 기존에 확인한 npm 미설치로 실행하지 못했다. 이번 변경은 JSON 및 생성 HTML이며 실제 회원 상태·서버 구현 검증은 아니다.

커밋·푸시는 하지 않았다. 다음 예정 작업은 행사 목록(S09-2)의 초기화·예시 정렬 보완이다.
