# S13 디자인시스템 기반 재구성

작성자 sungho · 2026-10-13

사용자가 제공 디자인시스템을 참고한 S13 재생성을 요청했다. 기존 정책·세 탭·고정 장면 데이터는 유지하고 screen.css와 생성 HTML을 수정했다. 편집 전 sungho 소유권 검사 통과. 주 작업자 단독 수정, ux_review 에이전트는 디자인시스템을 읽기 전용으로 검토했다.

## 기준과 반영

참조는 제공 디자인시스템의 guide.md, tokens.css, components.css, components.html이다. CSS 전체를 앱에 붙이지 않고 필요한 토큰과 화면 관찰값을 S13 스타일에 반영했다.

- 당도는 큰 보라색 면 대신 흰색 요약 카드로 구성하고 점수를 오른쪽에 배치했다. 설명·완료 횟수·통계는 모두 유지했다.
- 동행 카드에 기존 canonical.css의 글라스 재질을 적용했다. 프로필·당도·메뉴에는 글라스를 확대하지 않았다.
- 세 탭은 44px 최소 높이, 14px/700 글자, 2px 밑줄 규격을 반영했다.
- 본문 여백 약17.52px, 카드 여백 약14.86px, 카드 간격 약11.43px을 둘러보기 기준에서 가져왔다.
- 하단 메뉴 높이·좌우 여백·바닥 여백·아이콘 크기를 공통 토큰에 맞췄다.
- 완료 횟수·이름 보완은 유지했다. 원본 ZIP·서비스 상태·API·실제 앱은 수정하지 않았다.
