# S02 비로그인 작성자 박스 수정

작성자 sungho · 2026-10-13

## 범위와 변경

사용자의 다음 작업 요청에 따라 1차 검토의 최우선 항목을 처리했다. actor sungho, sungho/ui-design. 편집 전 대상 8개 경로의 소유권 검사 통과. 주 작업자만 파일을 수정했고 review_browse_detail 에이전트는 빌드 구조를 읽기 전용으로 검토했다.

비로그인은 작성자 박스 렌더를 먼저 분기해 사진·이름·나이·당도를 생성하지 않는다. 중립 모자이크 자리표시자와 `동행인은 로그인 후 확인할 수 있어요`만 표시한다. 로그인 안내의 접근성 이름과 S05 목적지를 유지했다. 로그인 회원의 기존 프로필 렌더와 연결본의 메시지·뒤로가기 코드는 보존했다.

수정 경로는 `apps/mobile/design/sungho/html/extracted/` 기준:

- `유미당-공고상세-소스/yumidang-listing-detail/`의 detail.js, detail.css, index.template.html.txt
- `유미당-공고상세-소스/유미당-공고상세.html`
- `유미당-공고탐색-공고상세-연결-소스/yumidang-browse-detail-connected/detail/`의 detail.js, detail.css, index.template.html.txt
- 같은 연결 패키지의 index.html

연결본은 index.html에 인라인된 YD_DETAIL_HTML 문자열까지 갱신했다. 원본 ZIP은 보존했다. 빌드 스크립트의 부수적 ZIP 생성이나 소스 전체 동기화는 실행하지 않았다. 실제 회원 데이터·API·인증은 변경하지 않았다. 합성 fixture는 시안 안에 남아 있으므로 운영 데이터 접근 통제를 구현한 결과로 해석하지 않는다.

## 검증

- Node 렌더 검사: 단독/연결본 각각 31개 장면 통과. 비로그인 렌더에 필수 안내 존재, 프로필 사진 경로·마스킹 이름·당도 메타·blur 클래스 없음 확인.
- 브라우저: 320/390/430px × 미확정 로그인/확정/취소/비로그인 12개 조합 확인. 박스 가로 넘침 없음. 확정은 전체 이름, 취소는 재마스킹, 비로그인은 이미지 0개와 안내만 표시.
- 연결본: guest=1로 둘러보기 카드에서 상세 진입하여 새 중립 박스와 로그인 안내를 확인.
- JavaScript 구문 검사 통과. 앱 lint/typecheck는 앞선 홈 작업에서 npm 미설치로 실행 불가를 확인했으며 이번에도 앱 의존성을 설치하지 않았다.

이번 완료 범위는 시안의 비로그인 박스다. 실제 서비스 적용은 종현 담당 화면에서 별도 연결·검증해야 한다. 이전 검토의 S13 데이터 정합성, 행사 초기화·정렬, 카드 정보, 활동 제한 안내는 별도 후속 항목으로 남는다. 커밋·푸시는 하지 않았다.
