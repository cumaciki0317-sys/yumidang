유미는 안내문·피드백 양식·인수인계 작성을 승인했다. 이번에는 기존 `yumi/batch-release-readiness`에서 유미 소유3문서만 새로 작성했다. 문서 독립 준비와 실제 베타·설치·모집·수집·UT 실행을 구분한다.
