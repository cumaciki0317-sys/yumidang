# WBS 8.5 — 출시 단계별 콘텐츠 실행 계획 초안

## 최신 승인·Notion 반영 — 2026-10-18 KST

유미가 B02 결과 추천안 1로 본 실행표 문서 결과와 Notion 반영을 승인했다. Notion 8.5는 문서 범위 최종 완료로 반영·재조회했다. 실제 출시·모집·게시·일정 확정은 완료가 아니다.

이하 작성 시점의 검토 대기·Notion 미수정 안내는 초기 기록이며 최신 상태는 이 절을 따른다. P1·담당·기존 구조를 유지했고 Commit·Push·게시·다음 Batch 실행은 하지 않았다.

작성일: 2026-10-18 KST · 유미 단독 · P1 · B02 문서 검토 대기

## 1. 목적·완료 기준

[Notion 8.5](https://app.notion.com/p/bf144227a435834487bb0130ec8c7955)의 결과는 날짜 미정인 단계별 실행표다. 소재·담당·검수·게시 조건·측정 항목을 연결하고 실제 출시 의존성을 구분한다. 7.5 출시 판단은 실제 공개·출시 홍보의 조건이며 초안 준비를 일괄 차단하지 않는다.

이번 승인 범위는 문서 작성·검증이다. 게시 일정·출시일·예산·조회/가입 목표·참여자 수를 확정하지 않는다. 콘텐츠 계획 완료와 실행 완료를 구분한다.

## 4. 작업 순서·협의와 보류

1. P-01의 [첫 원고](wbs-8-8-first-posts.md)와 [영상 준비](wbs-8-7-video-brief.md)를 한 소재로 작성한다.
2. 유미가 원고를 검토한다. 8.2 팀 검토로 문구가 바뀌면 원고·대본을 함께 대조한다.
3. 영상 편집 전에 종현 2.11의 편집 원본·버전·사용 예시·사용 자산 권리를 확인한다. 대본 준비는 병행할 수 있다.
4. 게시 전 유미가 채널·최종 버전·사용 권리·개인정보 미포함·CTA·목적지·공개 시점을 확인하고 승인한다. 8.12에서 실행·기록한다.
5. 관찰 조건을 승인받고 8.18에서 실제 반응을 기록한다. 가입/신청 연결은 8.3 담당 확인 전 성과로 계산하지 않는다.

권리 불명·개인정보 노출·출시 오인·경로 불명·정책 충돌은 해당 원고/실행을 보류한다. 해결 전 외부로 보내거나 게시하지 않는다. 현재 자료로 만들 수 있는 독자 원고 준비는 계속한다. 베타 모집·공개 안내는 그 단계의 조건을 충족할 때만 별도 검토한다.

## 5. 검증·개별 인수인계

- 수행: 5개 단계의 소재·산출물·역할·실행 조건·측정/누락·미정 일정을 연결했다.
- 문서 검증 기준: 각 행에 게시 조건과 측정 한계가 있고 출시일·효과·모집 수를 만들지 않았는지 확인. 단계 전환은 실제 증빙을 요구한다.
- 산출물: 본 문서. B02 검증 결과·변경 경계는 [Batch 인수인계](batch-content-preparation-handoff.md)에 기록한다.
- 완료 판정: 실행표 초안 작성·검증 후 유미 검토 대기. 실행·게시·출시 판단 완료를 뜻하지 않음.
- Notion 변경안: 결과 검토 후 문서 범위 완료 여부를 유미에게 제시. 현재 대기 유지, 이번 실행에서 Notion 미수정.
- 후속 담당: 유미/Codex 원고 검토, 종현 템플릿·기능 사실 확인 필요, 민규/종현 계측·실제 공개 조건 확인 필요. 외부 연락 미실행.
