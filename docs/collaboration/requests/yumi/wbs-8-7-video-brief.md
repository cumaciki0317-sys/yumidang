# WBS 8.7 — 첫 세로 영상 사전 준비

## 최신 승인·Notion 반영 — 2026-10-18 KST

유미가 사전 준비 결과를 Notion 작업 중으로 기록하는 안을 승인했고 반영·재조회했다. 대본 채택·템플릿 확인·실제 영상·채널 변형·재생 검수는 대기다. 원고 작성만으로 전체 완료 처리하지 않았다.

이하 작성 시점의 검토 대기·Notion 미수정 안내는 초기 기록이며 최신 상태는 이 절을 따른다. P1·담당·기존 구조를 유지했고 Commit·Push·게시·다음 Batch 실행은 하지 않았다.

작성일: 2026-10-18 KST · 유미 단독 · P1 · 대본 V-01 · 실제 영상 미제작

## 1. 승인 범위·완료 구분

[Notion 8.7](https://app.notion.com/p/78d44227a43583a3800d81b2a3644078)의 전체 완료 조건은 원본 영상 1개·채널별 변형·모바일 자막 검수·자료 출처다. **이번 B02는 대본·4장면 구성·자막 초안까지만** 승인받았다. Markdown 대본을 실제 영상 산출물로 세지 않는다.

입력: [8.8 원고 v1](wbs-8-8-first-posts.md), [8.4 첫 소재](wbs-8-4-content-pillars.md), [8.9 검수 흐름](wbs-8-9-ai-content-workflow.md). 첫 소재는 ‘가고 싶은데 함께 갈 사람이 없었던 순간’, 두 이용 상황과 대표·설명 문구를 유지한다.

## 2. 4장면 대본·자막 초안

실존 인물의 경험·인터뷰·후기가 아닌 가상 설명이다. 4장면은 제작 제안이지 플랫폼 규격이 아니다. 권리 확인 전 실제 사진·행사 포스터·앱 화면·로고·폰트 파일·배경음·합성 음성을 넣지 않는다. 아래 화면은 향후 직접 만들 문자·단순 도형의 제안이며 이번에 이미지/영상을 생성하지 않았다.

| 장면 | 화면 구성 제안 | 자막·내레이션 초안 | 시각·개인정보 경계 |
|---|---|---|---|
| 1 문제 | 단색 배경에 두 문장이 차례로 나타남 | 가고 싶은 곳은 있는데, 함께 갈 사람과 시간이 안 맞을 때. | 실제 장소·달력·메시지 캡처 없음. ‘상황 예시’ 표시 |
| 2 공감 | 직접 만든 추상적인 일정 칸과 두 점. 구체 날짜·지도 없음 | 혼자 해도 좋지만, 누군가와 함께하고 싶은 순간도 있죠. | 기존 앱 화면처럼 꾸미지 않음. 사람 사진·프로필·닉네임 없음 |
| 3 소개 | 문자 중심 소개. ‘준비 중’을 같은 화면에 표시 | 같이 하고 싶은 순간, 유미당. 취향과 일정이 맞는 여성 동행을 찾아보세요. | 텍스트 브랜드명만. 로고 파일·타사 UI 미사용 |
| 4 다음 행동 | 대상·준비 상태와 저장 요청을 충분히 읽히게 배치 | 만 19세 이상 여성을 위한 무료 1:1 동행 서비스 준비 중. 소식을 다시 볼 수 있도록 저장해두세요. | 확인된 저장 기능일 때만 채택. 설치·가입 링크·QR 미추가 |

내레이션은 읽을 문장 제안이며 실제 녹음/음성 생성이 아니다. 무음 자막형을 후속 제작의 우선 후보로 두지만 파일 제작 방식·폰트·화면 규격·길이는 템플릿 확인 후 정한다. 실제 발화·자막 읽기 시간을 검수하지 않았으므로 재생 초수를 임의 확정하지 않는다.

## 3. 채널 변형의 준비

| 채널 | 공통으로 유지 | 후속 확인·변형 | 현재 상태 |
|---|---|---|---|
| Instagram Reels | 4장면·대표/설명·준비 중·같은 주장 | 2.11 템플릿, 자막/버튼 겹침, I-01 캡션·저장 지원 | 영상 파일 없음 |
| TikTok | 같은 주제·개인정보 미포함·성사 보장 없음 | 템플릿과 실제 표시 영역, K-01 캡션·저장 지원 | 영상 파일 없음 |

플랫폼 권장 규격·영상 길이·음원 사용 가능 범위를 이번 문서가 보증하지 않는다. 계정/도구의 실제 상업적 이용 조건·각 채널 표시를 제작 때 확인한다. 한 플랫폼 음원을 다른 채널로 옮겨도 된다고 가정하지 않는다.

## 4. 종현 2.11 협의안 — 미전달

[현재 2.11](https://app.notion.com/p/ef944227a43583b996ee819d1d3fa8bf)은 계획 조사 시 종현 담당·대기였다. 8.7 원문에 남은 옛 선행 링크는 조회 불가여서 현재 TASK를 검색해 확인했으며 원문 링크는 수정하지 않았다.

로컬에는 앱 HTML·PNG·와이어프레임·로고가 있지만 재사용 영상/게시물 편집 템플릿의 가용 버전·사용 예시·유미 검수는 이번 검색으로 확인하지 못했다. 템플릿이 없다고 단정하지 않는다.

- 확인 질문: 사용할 편집 원본·버전·사용 예시와 자막 영역은 무엇인가?
- 확인 질문: 포함된 폰트·로고·이미지·음원 등의 상업적 SNS·변형·채널 간 이용 권리 근거는 있는가?
- 확인 질문: 실제 앱 화면이 필요하다면 합성 화면인지·기능 버전과 공개 범위가 확인됐는가?
- 막히는 작업: 실제 템플릿 편집·렌더링·모바일 자막/채널별 파일 검수.
- 계속할 작업: 현재 대본·원고의 문장·주장·자료 미사용 검토.

팀원 파일은 수정하지 않고 연락·납기 확정·업무 수락을 실행하지 않았다. 요청 내용은 B02 공통 인수인계에서도 추적한다.

## 5. 실제 제작 전·후 확인 기준

- 제작 전: 유미 대본 채택, 종현 템플릿 확인, 자산 권리·개인정보 검수 통과, 도구·추가 비용·생성/편집 범위 승인.
- 제작 후: 원본과 두 채널 파일의 제목·자막·잘림·읽기 속도·준비 상태·색 대비·정보 노출·썸네일·메타데이터를 재생해 검수.
- 자료 권리·초상/음성 동의·폰트·음원 조건 중 하나라도 미확인이면 해당 자산 제외 또는 제작 보류. 무료·AI 생성·출처 표시만으로 통과시키지 않음.
- 게시 전: 8.12에서 최종 파일·문구·권리 근거·채널·시점·CTA를 별도 승인. 대본 승인이나 파일 제작 완료를 게시 승인으로 바꾸지 않음.
