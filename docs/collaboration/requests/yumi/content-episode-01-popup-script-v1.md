# EP-01 팝업 — 제작용 상세 원고 후보 v1

작성일: 2026-10-20 KST · 작성/담당: 유미 · 연결: 8.7/8.8 · 문구 검토용·영상 미제작·미게시

## 1. 이번 작업의 목표와 승인

유미는 ‘친구들 일정 맞추다 끝난 팝업’을 첫 상세화 후보로 선택했다. 기존 [에피소드 시리즈](content-episode-series-v1.md)의 줄거리와 브랜드 방향을 이어받아 장면별 자막·Threads 반말 글·Instagram/TikTok 공통 설명을 다듬는다. 이 문서가 완성되면 유미는 실제 사용할 말투를 읽고 채택/수정할 수 있다.

30분은 사용자가 지금 작업할 수 있다고 밝힌 시간 범위이며 실제 사람의 제작 공수 실측이나 영상 길이가 아니다. 이번에는 영상/음성/이미지 생성·도구 설치/구매·계정 개설·게시·팀 연락·Notion·Commit·Push·PR을 실행하지 않는다. 기존 8.7/8.8은 앞선 Notion 조회에서 작업 중이며 이 문서로 최종 완료 처리하지 않는다.

## 2. 영상 한 편이 전달할 내용

- 상황: 함께 가고 싶은 친구와 일정이 맞지 않아 팝업 방문 기회를 놓치는 **가상 상황 예시**.
- 전달할 공감: 친한 친구와 취향이 맞아도 활동 가능한 날까지 같지는 않을 수 있음.
- 서비스 연결: 같은 날 같은 활동이 하고 싶은 한 사람을 찾는 서비스의 준비 방향.
- 확인할 가설: 이 상황에 공감하는지. 공감이 실제 낯선 사람과의 동행 의향·가입·성사로 이어진다는 근거는 아직 없다.
- 반대 가능성: 혼자 가면 충분함, 지인과 다음 기회를 기다리는 편이 좋음. 이 반응도 배제하지 않는다.

문구는 이번에 새로 구성했으며 실제 인터뷰·고객 후기·창업자의 경험을 인용하지 않았다. 행사명·상표·실존 인물·일시·주소·메시지 원문을 넣지 않는다. 유미당이 실제로 동행을 성사시킨 장면이나 티켓/입장을 보장하는 장면도 만들지 않는다.

## 3. Instagram·TikTok 공통 영상 대본

영상 본편은 두 채널에 사용할 공통 원본 한 편으로 준비한다. 표는 촬영/생성 결과가 아니라 편집자가 읽을 텍스트 설계다. 장면 초수·총길이·폰트·음원·도구·화면 비율은 미확정이며 실제 템플릿·읽기 시간 확인 후 정한다. 음성은 필수로 넣지 않고 무음 자막형을 우선 검토할 후보로 둔다.

| 장면 | 화면에 넣을 자막 | 직접 구성할 화면 후보 | 검토할 점 |
|---|---|---|---|
| 1. 첫 문장 | 친구들 일정 맞추다<br>팝업이 끝나버림. | 단색 배경에 문장 등장, ‘가상 상황 예시’ 표시 | 실제 경험·성공 후기로 오인되지 않는가 |
| 2. 일정 불일치 | 이날은 안 되고,<br>저날도 안 되고. | 구체 날짜 없는 일정 칸들이 엇갈림 → 가상의 ‘행사 종료’ 표식 | 실제 달력·메신저·포스터 UI를 복제하지 않는가 |
| 3. 함께할 한 사람 | 같은 날, 같은 팝업에<br>가고 싶은 한 사람이 있다면? | 두 추상 도형과 문장만 표시. 실제 매칭/만남 결과는 표시하지 않음 | 즉시 연결·항상 상대가 있음·동행 성사를 약속하지 않는가 |
| 4. 브랜드와 준비 상태 | 아래 4-A·4-B 두 카드로 순서대로 제시 | 문자 중심으로 브랜드·대상·준비 중·다음 행동 표시 | 한 화면에 과도하게 넣지 않고 실제 재생 시 읽기 시간을 확인할 수 있는가 |

### 4-A — 브랜드 카드 원고

```text
같이 하고 싶은 순간, 유미당
취향과 일정이 맞는 여성 동행을 찾아보세요.
```

### 4-B — 준비 상태·다음 행동 카드 원고

```text
만 19세 이상 여성을 위한
무료 1:1 동행 서비스 준비 중

다음 소식이 궁금하다면 저장해두세요.
```

가상 상황 표시는 장면 1에 읽히도록 넣고 장면 2~3의 연출도 실제 고객 기록과 구분한다. 장면 4-A·4-B는 같은 마지막 장면 안에서 두 카드로 나눈 제안이며 장면 수 자체가 제작 완료 증거는 아니다. ‘준비 중’을 생략한 별도 클립으로 공개하지 않는다.

저장 요청은 기존 CTA 후보 하나를 유지했다. 실제 계정의 지원 기능을 확인하기 전 게시본으로 확정하지 않는다. 지원하지 않는다고 댓글/DM/다른 행동으로 임의 대체하지 않는다. 저장을 가입·신청·수요 검증으로 세지 않는다.

## 4. Threads 원고 — TH-EP-01 상세 후보 v1

아래 블록이 검토할 완전한 본문이다. 상황은 반말로, 이미 선택된 대표/설명 문구는 그대로 유지한다. 개인 사연 제출·댓글/DM 모집 요청과 외부 링크는 넣지 않았다.

```text
친구들 일정 맞추다 팝업이 끝나버림.
(가상 상황 예시)

이날은 안 되고, 저날도 안 되고.
친구랑 취향이 맞아도
일정까지 맞추는 건 또 다른 문제잖아.

같은 날, 같은 팝업에 가고 싶은
한 사람이 있다면 어떨까?

그런 순간을 떠올리며 유미당을 준비하고 있어.
유미는 You + Me, 너와 나라는 뜻이야.

같이 하고 싶은 순간, 유미당
취향과 일정이 맞는 여성 동행을 찾아보세요.
만 19세 이상 여성을 위한 무료 1:1 동행 서비스 준비 중.

다음 소식이 궁금하면 저장해둬.
```

시리즈의 일반 활동 표현을 이번 팝업 장면으로 구체화했다. 첫 문장·불편·한 사람이라는 초점을 영상과 맞추고 이름 유래는 Threads 본문에 남겼다. 반말과 첫 문장의 효과는 가설이며 아직 고객 반응으로 검증하지 않았다. 플랫폼 실제 길이/표시·저장 지원은 미검증이다.

## 5. Instagram·TikTok 공통 게시 설명 — CAP-EP-01 v1

두 채널의 초반 설명을 같은 문구로 검토해 원고 수를 불필요하게 늘리지 않는다. 플랫폼 실제 화면에서 줄바꿈·표지·자막 가림·지원 기능을 확인하면 필요한 수정만 별도 버전으로 기록한다.

```text
친구랑 일정 맞추다, 가고 싶던 팝업을 놓치는 순간.
(가상 상황 예시)

취향이 맞아도 일정까지 맞는 건 또 다른 일이니까.

같이 하고 싶은 순간, 유미당

만 19세 이상 여성 · 무료 1:1 동행 · 서비스 준비 중
다음 소식이 궁금하다면 저장해두세요.
```

해시태그·음원·실제 팝업 홍보·행사 링크·가입/설치 URL·즉시 만남 요청은 포함하지 않았다. 이 설명으로 행사·브랜드와의 협업 관계를 주장하지 않는다.

## 6. 제작 전 전달할 자료와 확인 경계

종현에게 실제 편집을 요청할 때는 본 문서 버전·공통 대본·캡션을 전달할 후보로 둔다. 사용할 편집 원본·예시·표지/자막 영역, 포함 자산의 권리를 기존 2.11에서 확인해야 한다. 이번에는 요청 메시지를 보내거나 새 기한을 배정하지 않았다.

- 원본은 편집 도구에서 보관하고 플랫폼 워터마크가 붙은 다운로드본을 공통 원본으로 삼지 않는 방향이다. 실제 도구·내보내기 검증은 미실행이다.
- 사진·음악·폰트·템플릿·AI 생성물 등은 선택 시 [8.9](wbs-8-9-ai-content-workflow.md)의 권리·개인정보 검수와 플랫폼별 이용 조건을 확인한다. 한 채널 음원의 사용 권한을 다른 채널에 자동 적용하지 않는다.
- 현재는 외부 미디어·실회원 자료·실제 SNS 계정/메신저 캡처를 사용하지 않았다. 독자 문구 작성만으로 모든 저작권/상표 위험의 부재를 보장하지 않는다.
- 실제 제작 전에 도구·자산·비용·생성/편집 범위와 필요한 AI 표시를 확인하고 해당 승인을 받는다. 유미의 문구 채택도 제작/게시 승인을 대신하지 않는다.
- 실제 제작 후 원본과 두 채널 파일을 재생해 자막·읽기 속도·잘림·준비 상태·표지·메타데이터를 검수한다. 파일 검수 전 8.7 완료로 처리하지 않는다.
- 게시와 반응은 기존 8.12/8.18에서 추적한다. 같은 영상의 플랫폼별 결과는 따로 기록하고, 원천 지표·기간·정의가 다르면 직접 비교하지 않는다. 기존 8.4 EXP-01과 에피소드 상황 탐색을 혼동하지 않는다.
