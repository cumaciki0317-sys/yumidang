## 1. 지금 사용할 수 있는 범위

이 문서는 안내문을 준비한 결과다. 실제 베타 모집·설치·가입·동행·피드백 수집을 시작하는 안내가 아니다. 아래 확정 전 항목을 실제 근거로 채우고, 유미가 배포 범위를 승인한 뒤 참여자용 부분만 전달한다.

현재 main의 [Android 관찰 기록](../jonghyun/2026-10-23-ux-implementation/app-qa-followup.md)은 예시 환경·Expo Go/번들 관찰과 실제 서버·출시용 독립 설치본·실회원 QA를 구분한다. 해당 기록의 성공을 이 안내의 실제 설치 성공으로 승계하지 않는다. 아직 main에 통합되지 않은 다른 브랜치를 가져오거나 그 구현을 제공 중이라고 안내하지 않는다.

## 3. 참여자에게 전달할 안내 — 검토용

> 아래는 아직 보내지 않은 초안입니다. 실제 설치 링크·버전·참여 조건·제출 경로·지원 준비를 확인하기 전에는 전달하지 않습니다. 내부 확인표와 이 경고는 배포본에 섞지 않고, 확정된 내용으로 별도 최종 검토합니다.

### 유미당을 처음 써보는 분께

같이 하고 싶은 순간, 유미당.

유미당은 만 19세 이상 여성을 위한 1:1 동행 서비스입니다. 이번에 안내받은 범위에서 사용해보고, 이해하기 어렵거나 예상과 다르게 동작한 부분을 알려주세요. 동행 성사나 상대의 신원·안전을 보장하지 않습니다.

### ① 설치 전 안내를 확인해요

전달받은 참여 조건과 기기 조건, 설치할 앱 버전을 확인해주세요. 설치는 최종 안내에 적힌 확인된 경로를 이용해주세요. 링크가 열리지 않거나 다른 앱·버전이 보이면 진행을 멈추고 문의해주세요.

설치 경로·버전·지원 조건은 현재 확인 중입니다. 이 초안만으로 설치를 시도하지 마세요.

### ② 로그인·가입 안내를 따라가요

서비스의 가입 기준은 여성·만 19세 이상이며 네이버 계정을 사용합니다. 필요한 정보가 확인되지 않으면 가입이 보류될 수 있어요. 화면의 안내를 확인하고, 오류가 있다면 어느 단계에서 멈췄는지만 적어주세요.

오류 해결을 위해 비밀번호·인증번호·신분증·네이버 계정 정보를 피드백에 보내지 마세요. 다른 사람의 계정이나 사실과 다른 정보로 진행하지 마세요. 실제 가입 시험은 승인된 참여 범위가 안내된 뒤 진행합니다.

### ③ 안내받은 범위만 살펴봐요

안내받은 화면과 허용된 기능부터 살펴보세요. 화면의 설명을 이해하기 어렵거나 예상과 다르면, 어떤 단계였는지 간단히 적어주세요.

핵심은 **첫 메시지를 성공적으로 보내면 신청이 생성되고, 신청과 동행 확정은 다르다**는 점입니다. 작성자의 확정 요청을 신청자가 수락해야 확정됩니다. 실제 신청·확정·연락·만남은 별도로 안내받은 승인 범위에서만 진행해주세요. 확인을 위해 무작위 사용자에게 메시지를 보내거나 동행을 약속하지 마세요.

AI 기능은 별도로 안내받은 사용 범위와 화면의 동의·이용 가능 안내를 따라주세요. 이용할 수 없다고 표시되면 반복 전송하지 마세요. 기능이 보인다는 이유만으로 현재 참여 범위에 포함되는 것은 아닙니다.

### ④ 불편했던 부분을 짧게 기록해요

[피드백 양식](wbs-8-20-feedback-form.md)의 참여자용 부분에 앱 버전·발생 단계·기대했던 결과·실제 결과를 적으면 됩니다. 같은 문제가 다시 생기는지 확인할 수 있으면 적고, 재시도가 위험하거나 어렵다면 반복하지 않아도 됩니다.

스크린샷이나 영상은 필수가 아닙니다. 계정·얼굴·채팅·정확한 위치·다른 사람의 글이 포함되면 첨부하지 말고, 개인정보 없이 상황만 설명해주세요.

### ⑤ 확인된 경로로만 전달해요

피드백 제출 경로와 안내된 접수 범위를 확인한 뒤 전달해주세요. 현재 이 초안에는 제출 링크가 없습니다. 공개 댓글·팀 내부 Notion·GitHub에 개인정보나 원문 자료를 올리지 마세요.

## 4. 안내문 검증·사용 조건

- 첫 이용 설명은 기존 [8.14 첫 이용 안내](wbs-8-14-initial-post-guide.md)를 원본으로 재사용한다. 이번 문서에서는 신청/확정의 핵심만 연결하며 실제 화면과 대조해 배포본을 검수한다. AI 사용·동의·실회원 원문 전송 허용은 이 안내가 대신하지 않는다. 2.4·2.5 UT는 기존 앱 구현·QA 이후로 유지하며 이번 문서 작업으로 실행하지 않는다.
- 문서 작성 완료: 제품 기준·단계별 설명·미확인 설치/제출 정보·기존 안내 연결을 준비했다.
- 문서 검토 항목: 설치 전/후 순서, 첫 메시지 신청과 확정 구분, 개인정보 없는 피드백, 문의와 수집 경로 구분, 근거 없는 기능/기기 조건·날짜·약속 미추가.
- 실제 검증: 설치 링크·설치/로그인·기능 실행·제출/수신·모집 자료 검수는 모두 NOT_RUN이다. 자료 승인·접수처 준비와 실제 화면 대조가 끝나야 외부 전달용으로 사용할 수 있다.
- 후속 검토: 종현은 설치본/화면/기술 안내, 민규는 인증·서버·배포/접수 조건, 유미는 최종 문구·참여/공개 범위를 확인한다. 요청 발송·새 업무 배정은 이번에 하지 않았다.
