# WBS 8.2 — 브랜드 가치제안·포지셔닝 검토

작성일: 2026-10-17 KST · 담당: 유미 · 기존 P1 유지 · B01 문서 초안

## 1. 목적·완료 기준·현재 판정

[Notion 8.2](https://app.notion.com/p/18144227a43582edb1e4819e15e2a8bc)의 목표는 대상·문제·도움을 한 문장으로 설명하고 소개글·프로필 문구·짧은 제목을 같은 의미로 정리하는 것이다. 원문 완료 기준은 팀 검토 결론과 증거 링크이며, 종현의 시각 템플릿으로 전달하는 과정도 포함한다.

이 문서는 작성·자체 검토용 산출물이다. **팀 검토와 종현 전달은 대기**이며 실제 메시지 효과·고객 수요·경쟁 우위를 검증한 결과가 아니다. 문구 공개·SNS 수정·Notion 상태 변경은 승인하지 않는다.

### 최신 사용자 선택 — 2026-10-18 KST

[8.1 U-03](wbs-8-1-persona.md)의 최신 선택으로 대표 문구 M-1과 설명 M-1a를 변경했다. ‘유미’는 You + Me, ‘너와 나’라는 유미의 이름 설명이다. 내부 브랜드 설명에는 ‘You + Me, 너와 나. 함께하는 순간을 떠올리는 이름’이라는 해석을 붙일 수 있으나, 뒤 문장은 브랜드 해석이며 고객 반응 증거가 아니다. ‘당’의 어원을 추가로 만들지 않는다.

이름의 유래와 1:1 동행 방향이 연결된다는 설명은 가능하다. 고객이 이름만으로 서비스나 뜻을 이해한다는 주장은 확인하지 않았다. 이번 선택은 전체 팀 검토 완료·SNS 공개·실제 템플릿 적용 승인이 아니다.

## 3. 포지셔닝 가설

**내부 정의 후보:** 유미당은 함께할 활동이 있지만 지인과 시간·관심사가 맞지 않는 성인 여성이 활동 조건과 상대 정보를 살펴보고 대화 후 1:1 동행을 결정하도록 돕는 무료 동행 서비스다.

- 공통 고객 가설 P-A: 함께하고 싶은 활동에 맞는 여성 동행을 찾는 성인 여성.
- 계획형 S-P: 일정·활동을 미리 정하고 탐색. 문화활동·식사는 예시다.
- 즉흥형 S-N: 지금 함께할 사람을 찾는 상황. ‘지금이당’의 의미는 유미 확인, 실제 즉흥 수요·응답 속도는 미검증이다.
- 핵심 문제: PP-1 활동 기회·계획의 변화, PP-2 상대 판단 정보의 불확실성.
- 보완 문제: PP-3 필요한 대화·조율의 부담. 고객 전체의 문제 순위로 검증된 것은 아니다.
- 도움의 가설: 활동·조건 중심 탐색, 상대를 살펴보는 과정, 대화 후 결정이라는 흐름이 도움이 될 수 있다.

### 기존 대처와의 비교 — 경쟁 우위 주장 아님

| 기존 대처 | 기록·근거 | 유미당이 제안할 도움 | 남는 한계 |
|---|---|---|---|
| 지인에게 문의 | R-01 E-02·E-03 | 조건이 맞는 다른 동행을 탐색할 선택지 | 지인보다 신뢰·편의가 높다는 증거 없음 |
| 혼자 참여 | E-02, I-04의 전시 혼자 이용 | 함께하고 싶은 상황에서 선택지 제공 | 혼자 가기도 유효하며 대체해야 할 문제로 단정하지 않음 |
| 활동 미방문·포기 | E-01·E-02 | 가고 싶은 활동과 가능한 일정부터 탐색하도록 설명 | 서비스가 포기를 줄인다는 효과 미검증 |
| 식사 배달·지인 동행 | E-03 | 혼자 이용하기 어려운 식사의 동행 선택지 | 즉시 동행 수요나 배달 대비 선호를 입증하지 않음 |

다른 모임·동행 서비스의 기능·가격·시장점유율은 조사하지 않았다. 유일·최고·타사보다 안전하다는 표현은 사용하지 않는다.

## 5. 사용할 표현·과장 금지·교차 검토

| 검토 항목 | 사용할 표현·방향 | 피할 표현·이유 |
|---|---|---|
| 대상 | 성인 여성·여성 간 1:1 | 모든 연령·누구나 가입 등 자격과 불일치 |
| 비용 | 현재 무료 1:1 동행 | 유료 신청·결제·수익 보장 |
| 계획형·즉흥형 | 두 이용 상황을 함께 설명 | 문화활동만 핵심이거나 즉흥형이 더 인기라는 단정 |
| 지금이당 | 지금 하고 싶은 활동의 동행 탐색 | 즉시 매칭·몇 분 안에 만남·빠른 응답 보장 |
| 상대 판단 | 정보를 살펴보고 대화 후 결정 | 인증으로 안전 보장·검증된 사람만·무사고 |
| 위치·이름 | 관계에 따라 허용된 정보 확인 | 주변·반경·거리순 검색 제공, 항상 실명·상세 위치 공개 |
| 성과 | 도움의 가설·준비중 | 전환율 상승·동행 성사·인기·재사용 효과 단정 |

문서 검토 결과: B-01~06은 P-A와 두 상황을 일관되게 설명하고 M-1을 대표로 둔다. 신원·안전·거리 검색·새 인증·새 요금 정책을 추가하지 않는다. 신규 기능 구현과 화면 문구 교체는 하지 않았다.

## 6. 팀 검토·종현 인계 준비 — 미전달

외부 메시지는 발송하지 않았으며 아래는 유미가 검토할 요청안이다.

- 종현 검토: B-01~06이 현재 화면·시각 템플릿에서 담을 수 있는 길이인지, 준비중 표현과 실제 진입 경로가 맞는지 확인 요청.
- 유미 검토: 대상·문제·도움의 한 문장과 계획형·즉흥형 예시가 의도에 맞는지, M-2/M-3 및 신규 B 문구의 채택/수정/보류 판단.
- 기존 정책·기술 범위가 불명확하면 새로 확정하지 않고 해당 소유자에게 검토 항목으로 남김.

| 항목 | 상태 | 완료에 필요한 증거 |
|---|---|---|
| 문구·표현·근거표 작성 | 작성 완료·자체 검토 | 이 문서와 Batch 검증 기록 |
| 실제 고객의 메시지 반응 | 미검증 | R-04 별도 실행 결과 |
| 팀 검토·종현 전달 | 대기·미발송 | 검토자·대상 문구 버전·의견·결론·근거 링크 |
| 실제 템플릿 적용 | 미실행 | 종현 담당 후속 산출물. 이번 파일 변경 범위 밖 |

## 7. 개별 TASK 인수인계

- 실제 수행: 8.1의 고객상·고민 비중·대표 문구를 유지하며 포지셔닝 가설과 문구 변형·금지 표현·팀 검토 요청안을 작성했다.
- 결과·검증: 대상·문제·도움·준비 상태의 문구 일관성을 확인했다. 메시지 반응·시장 차별성·구현 효과를 입증하지 않았다.
- 유미 채택: 2026-10-18 KST M-1·M-1a 조합과 You + Me 이름 유래의 문서 반영 승인. B-03은 조합을 적용한 프로필 초안이며 나머지 B 문구·M-2/M-3 전체 채택으로 확대하지 않는다.
- 미완료: 팀 검토 결론·종현 전달, 나머지 신규 문구 채택. 따라서 Notion 변경안은 `대기 → 작업 중`이며 최종 완료 제안은 보류한다.
- 후속: 8.3·8.4는 이 문서를 잠정 입력으로 사용하며 팀 검토로 바뀌면 관련 정의·소재를 다시 대조한다.
- Git·Batch 검증·승인 경계: [B01 인수인계](batch-brand-strategy-handoff.md). 문서 작성 승인은 Notion·외부 게시·Commit·Push 승인과 별개다.
