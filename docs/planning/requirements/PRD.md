# 유미당 PRD — 사용자 정책 답변 반영

> 기준 파일: `유미당 와이어프레임.html`  
> 문서 기준일: 2026-10-03  
> 관련 문서: [정책](./정책.md) · [IA](./IA.md) · [USERFLOW](./USERFLOW.md)

## 1. 제품 개요

유미당은 여성·만 19세 이상 사용자가 무료 1:1 동행 공고의 첫 채팅으로 신청하고 대화·합의 후 작성자 확정 요청에 신청자가 수락하여 약속을 확정하는 서비스다. 2026-10-03까지의 사용자 정책·운영 확인 답변을 반영했고 이번 정책 확인 질문은 모두 해소되었다.

### 제품 목표

- 일정·장소·활동 조건이 맞는 동행 공고를 쉽게 찾고 작성하게 한다.
- 공고 신청과 최종 확정을 분리해 대화 후 결정할 수 있게 한다.
- 마스킹 이름·공개 지역에서 시작해 확정 당사자에게만 실명·상세 장소를 공개한다.
- 행사 탐색에서 관련 동행 공고와 새 모집으로 자연스럽게 연결한다.
- 완료·상호 평가·칭찬·후기로 다음 동행 선택에 필요한 신뢰 정보를 만든다.
- 자연어 AI 탐색을 제공하되 개인정보와 공개 권한을 우선한다.

### 비목표

- 신원·안전·만남 성공을 보증하지 않는다.
- 유료 동행·결제·정산·환불을 제공하지 않는다.
- 이메일·계좌 인증을 현재 가입 또는 신청의 필수 단계로 사용하지 않는다.
- AI가 신청·확정·결제·메시지 전송을 대신 실행하지 않는다.

## 2. 대상 사용자와 역할

### 대상

- 대한민국의 여성·만 19세 이상
- 전시, 공연, 축제, 맛집 등 일상 활동을 함께할 1:1 동행을 찾는 사용자

### 역할

| 역할 | 주요 행동 |
|---|---|
| 비로그인 방문자 | 공개 공고·행사 탐색, 로그인 진입 |
| 회원·신청자 | 프로필 관리, 공고 탐색·작성, 첫 채팅으로 신청, 대화·합의, 최종 동의 수락, 완료·평가 |
| 공고 작성자 | 공고 관리, 신청자 대화·거절·선택, 동행 확정 요청 |
| 확정 당사자 | 실명·상세 위치 확인, 약속 관리, 변경·취소·완료·평가 |
| 운영자 | 신고·제재·분쟁 운영. 구체 권한과 도구는 현 범위 밖 |

## 3. 제품 범위

현재 HTML에는 24개 화면이 있다. 변경 목표는 별도 신청 메시지 화면 S08을 제거한 23개 활성 화면이다. HTML 변경은 아직 반영되지 않았다.

| 영역 | 포함 기능 |
|---|---|
| 인증 | 네이버 로그인, 여성·성인 자격 확인, 신규 프로필 가입 |
| 탐색 | 홈, 공고 검색·필터·정렬, 카테고리 탐색 |
| 공고 | 작성, 장소·행사 연결, 확인, 등록, 상태 관리 |
| 매칭 | 신청 버튼→채팅, 첫 전송 시 신청 성립, 작성자 확정 요청→신청자 수락, 상호 합의 일정 변경 |
| 약속 | 상세 위치 공개, 시작 전 취소, 완료 확인, 상호 평가 |
| 행사 | 신규·진행 행사, 상세, 관련 공고, KOPIS Top 10 |

| 계정·안전 | 알림, 안심 수칙, 계정 상태·제재·탈퇴 |

## 4. 핵심 사용자 시나리오

1. 방문자는 홈·둘러보기·행사에서 공개 정보를 탐색한다.
2. 신청·작성·프로필·AI 이용 시 네이버로 로그인한다.
3. 신규 회원은 필수 사진과 선택 성향을 등록하고 가입을 완료한다.
4. 회원은 공고를 검색하거나 행사에서 관련 공고를 찾는다.
5. 신청 버튼으로 S11에 이동하고 첫 채팅 전송 성공 시 신청과 작성자 측 채팅방이 성립한다. 미전송 이탈은 미신청이다.
6. 서로 채팅·합의한 뒤 작성자가 확정 요청을 보내고 신청자가 수락하면 확정한다.
7. 확정 당사자는 실명과 상세 만남 위치를 확인한다. 변경은 양쪽 누구나 제안하고 상대 수락·충돌 확인 후 반영한다.
8. 종료 후 완료를 확인하고 평가를 제출한다.
9. 공개 가능한 후기와 칭찬이 프로필에 반영된다.

## 5. 기능 요구사항

### FR-1. 로그인·가입

- FR-1.1 네이버 로그인을 유일한 현재 로그인 수단으로 제공한다.
- FR-1.2 이름·성별·생일·출생연도로 여성·만 19세 이상 자격을 확인한다.
- FR-1.3 필수 정보 누락, 자격 불충족, 연동 실패를 서로 다른 상태로 안내한다.
- FR-1.4 신규 회원은 프로필 사진을 필수로 등록해야 한다.
- FR-1.5 관심사·대화 방식·MBTI는 선택이며 비워둘 수 있다.
- FR-1.6 가입 완료는 명시적 버튼과 완료 팝업 확인으로 끝난다.
- FR-1.7 기존 회원은 로그인 전 목적 화면으로 복귀한다.
- FR-1.8 자격 확인은 네이버 인증정보만 사용한다. 소셜 계정당 1개 계정이며 계정 간 기록 이전은 제공하지 않는다.

### FR-2. 홈·탐색

- FR-2.1 홈은 신규 행사, 다가오는 약속, 카테고리 순으로 제공한다.
- FR-2.2 공고 검색 대상은 제목·등록 장소명·등록 주소·연결 행사명이다.
- FR-2.3 카테고리, 시도 지역, 일정, 작성자 만 나이 19~99세, 모집 상태 필터를 제공한다.
- FR-2.4 등록일 최신순과 시작일 빠른순 정렬을 제공한다.
- FR-2.5 비로그인은 일정·나이 상세 필터가 아닌 전체 범위를 사용한다.
- FR-2.6 결과 없음, 조회 실패, 권한 제한을 구분한다.
- FR-2.7 기본 목록은 모든 모집 상태를 노출하고 모집 중 필터 활성화 시 모집 중 공고만 노출한다. 삭제 공고는 비노출이다.

### FR-3. 공고 작성·등록

- FR-3.1 카테고리, 제목, 소개, 장소, 시작·종료 일시를 필수로 받는다.
- FR-3.2 모집 마감과 행사 연결은 선택으로 제공한다.
- FR-3.3 장소명 검색과 주소 검색을 분리하고 상세 만남 지점을 별도 입력한다.
- FR-3.4 행사 선택은 작성 일정과 입력값을 임의로 덮어쓰지 않는다.
- FR-3.5 개인정보·상세 위치 노출을 감지하면 등록 전 차단하고 수정·오탐 문의를 제공한다.
- FR-3.6 작성 중 이탈 시 같은 기기 임시저장과 복구를 안내한다.
- FR-3.7 등록 실패 시 입력을 유지하고 재시도한다.
- FR-3.8 성공 시 별도 완료 화면 없이 생성된 공고 상세로 이동한다.
- FR-3.9 모든 공고는 무료 1:1이며 금액·결제 입력을 제공하지 않는다.

### FR-4. 공고 상세·관리

- FR-4.1 관계와 상태에 따라 신청, 기존 채팅, 작성자 관리, 약속 상세 행동을 분기한다.
- FR-4.2 수동 마감은 새 신청만 차단하고 기존 신청·채팅을 보존한다.
- FR-4.3 핵심 조건 변경을 신청자에게 알리고 기존 최종 동의를 무효화하며 새 조건으로 재요청한다.
- FR-4.4 확정 당사자와 제3자의 실명·상세 위치 공개를 구분한다.
- FR-4.5 확정 전 삭제와 확정 후 취소를 별도 절차로 처리한다.

### FR-5. 신청·채팅·확정

- FR-5.1 별도 신청 메시지 화면 S08을 제거하고 신청 버튼 클릭 시 S11로 이동한다.
- FR-5.2 신청 일정 충돌은 경고하되 신청은 허용한다.
- FR-5.3 첫 채팅 전송 성공 시에만 신청을 성립시키고 작성자에게 채팅을 전달하며 작성자 측 1:1 채팅방을 생성한다. 미전송 이탈·전송 실패는 미신청이며 작성자 알림도 없다.
- FR-5.4 본인 철회 후 1분간 재신청 불가, 이후 횟수 제한 없이 허용한다. 작성자 거절 후에는 같은 공고 재신청을 차단한다.
- FR-5.5 대화·합의 후 작성자가 확정 요청을 보내고 신청자가 수락하면 확정한다. 한 번에 한 명에게 요청하며 요청 철회 후 다른 상대에게 요청한다.
- FR-5.6 확정 요청은 요청 +6시간과 시작 시각 중 빠른 때 만료된다. 만료 시 신청·채팅은 유지하고 미확정 상태로 돌아간다.
- FR-5.7 최종 확정 직전 권한·공고 조건·정원·일정 충돌을 재확인한다.
- FR-5.8 신청자 수락 후 동행을 확정하고 실명·상세 위치와 약속을 제공한다.
- FR-5.9 메시지 실패 시 재전송하고 종료 대화는 읽기 전용으로 보존한다.
- FR-5.10 대화방 나가기는 본인 목록에서만 숨긴다.
- FR-5.11 재신청은 동일 공고·상대 채팅방을 재사용하고 새 메시지 전송 성공 시 성립한다.
- FR-5.12 한 명 확정 시 다른 신청은 모집 종료·채팅 읽기 전용으로 전환한다. 확정 취소 후 작성자가 모집 재개하면 이전 유효 신청·채팅을 자동 복원하고 알린다. 거절·본인 철회 신청은 복원하지 않는다.

### FR-6. 확정 후 변경·취소

- FR-6.1 양쪽 누구나 확정 후 일정·장소 변경을 제안하고 상대 수락·충돌 확인 후 반영한다.
- FR-6.2 변경 제안은 제안 +6시간·기존 시작·새 시작 시각 중 가장 빠른 때 만료된다. 거절·철회·미응답이면 기존 약속을 유지한다.
- FR-6.3 확정 전 철회, 시작 전 취소, 시작 후 중단·불발 신고를 구분한다.
- FR-6.4 취소 시 상대에게 알리고 실명·상세 위치를 즉시 다시 숨긴다.
- FR-6.5 기존 대화는 읽기 전용으로 보존한다.

### FR-7. 완료·평가

- FR-7.1 예상 종료 후 본인 완료 확인을 제공한다.
- FR-7.2 양쪽 확인 또는 종료 +24시간에 실제 완료 처리한다.
- FR-7.3 취소·노쇼는 자동 완료에서 제외, 신고·분쟁 검토 중에는 보류한다. 정상 동행 인정 시 원래 종료 +24시간이 지났으면 즉시 완료하고 미경과면 원래 시각을 유지한다.
- FR-7.4 본인 확인 후 상대 확인 전에도 비공개 후기 선제출을 허용한다.
- FR-7.5 경험·별점은 필수, 한마디는 선택으로 받는다.
- FR-7.6 좋아요일 때만 공식 칭찬을 최대 3개 선택한다.
- FR-7.7 제출 성공 후 수정·중복 제출을 막는다.
- FR-7.8 후기 기한은 실제 완료 +7일이다.
- FR-7.9 실제 완료 후 양쪽 제출은 즉시, 한쪽 제출은 7일 작성 기한 종료 시 공개한다.
- FR-7.10 실제 완료 시 완료 횟수, 후기 공개 시점에 당도·칭찬을 반영한다.
- FR-7.11 검토 중 리뷰 작성·기한·공개를 보류한다. 실제 완료 전에는 기한을 시작하지 않으며 검토 후 처음 완료되면 그때부터 7일을 제공한다. 이미 완료였다면 남은 기간 재개·최소 24시간 보장, 양쪽 제출 시 검토 종료 후 공개, 한쪽 제출 시 재개 기한 종료 후 공개다.
- FR-7.12 탈퇴 후 상대방은 남은 기한까지 작성 가능하며 탈퇴 회원 표시와 기존 공개 후기 익명 유지를 제공한다.

### FR-8. 행사

- FR-8.1 홈과 일반 목록에서 이번 주 신규 행사를 제공한다.
- FR-8.2 진행 중 포함, 기간, 지역, 유형, 공연 하위 장르 탐색을 제공한다.
- FR-8.3 작성용 선택은 진행 중·예정 및 작성 일정과 겹치는 행사를 제공한다.
- FR-8.4 종료 행사 상세는 볼 수 있으나 새 모집은 차단한다.
- FR-8.5 행사 상세에서 관련 공고 또는 행사 기반 모집으로 연결한다.
- FR-8.6 공식 KOPIS 전국 공연 Top 10과 뮤지컬 Top 10을 분리 제공한다.
- FR-8.7 최근 7일·매일 갱신·출처·갱신 시각을 표시하고 미수신 시 추정치로 대체하지 않는다.
- FR-8.8 출시부터 KOPIS·TourAPI·서울 열린데이터를 실제 연동한다. 실제 확보한 유형·지역의 데이터만 노출한다.

### FR-9. 프로필·후기

- FR-9.1 관계에 따라 마스킹 이름과 실명을 구분한다.
- FR-9.2 사진, 만 나이, 성향, 현재 당도, 칭찬 차트, 후기 원문을 제공한다.
- FR-9.3 사진 저장 실패 시 기존 사진을 유지한다.
- FR-9.4 관심사·대화 방식은 각각 최대 20개, 40자로 제한한다.
- FR-9.5 한마디가 있는 공개 후기 3개 이상에서만 AI 요약을 제공한다.
- FR-9.6 요약 실패가 원문·칭찬 노출을 막지 않게 한다.

### FR-10. AI 탐색

- FR-10.1 로그인 회원만 이용한다.
- FR-10.2 추천·후기 요약 모두 AI 정보 제공 내용을 가입 약관에 포함하고 AI 사용 화면에서 간단히 안내한다. 기존 회원은 개정 약관 확인 후 이용한다.
- FR-10.3 자연어 요청, 빠른 응답, 새 대화, 행사·동행 카드 결과를 제공한다.
- FR-10.4 GPS 없이 설정 지역을 사용하고 미설정일 때 지역명을 묻는다.
- FR-10.5 비공개 주소·상세 지점·거리와 개인 식별 정보를 결과에서 제외한다.
- FR-10.6 행사와 동행 공고를 구분하고 각각 S09-3과 S02로 연결한다.
- FR-10.7 초기 AI 대화는 기기 메모리에서만 유지하고 화면 종료·로그아웃 시 삭제한다. 서버·브라우저 영구 저장소에 저장하지 않는다.
- FR-10.8 실제 외부 전송 전에 공급사·보관·암호화·법적 동의를 검증한다.

### FR-11. 알림·계정·안전

- FR-11.1 첫 채팅, 확정 요청, 확정, 조건 변경, 취소, 평가 알림을 제공한다.
- FR-11.2 전체/읽지 않음 필터와 모두 읽음을 제공한다.
- FR-11.3 알림 클릭 시 대상의 최신 상태를 확인하고 자동 상태 변경은 하지 않는다.
- FR-11.4 예정 시작 시각 순으로 취소 결과를 집계하며 중간 미정 결과가 있으면 이후 연속 판정을 보류한다. 정상 완료 시 횟수는 0이다. 첫 연속 3회 경고, 이후 연속 3회마다 7일 제한이며 경고·제재 시 횟수만 0, 경고 이력은 유지한다. 신규 작성·신규/재신청·새 확정 요청/수락을 차단하고 기존 확정 약속 관리·채팅·후기는 허용한다.
- FR-11.6 확정 동행이 있으면 탈퇴 차단, 후기 기간만 남으면 탈퇴 허용. 재가입은 즉시 허용하되 원래 제재 종료까지 기능 제한을 유지하고 기간을 연장·초기화하지 않는다. 동일 네이버 계정의 경고·제재·취소 기록을 유지한다.
- FR-11.5 무료 1:1 안심 수칙과 신고 시 캡처 접수 안내를 제공한다.
- FR-11.7 취소 처리 후 24시간 이내 이의 신청을 받는다. 횟수는 우선 반영하되 해당 취소에 근거한 경고·제재는 기한 종료까지 보류한다. 미신청이면 기한 종료 후, 신청하면 검토 종료 후 판정하고 인정 사유는 제외한다. 예정 시작 시각 순 중간 결과 미정에 따른 보류는 유지하며 7일 제한은 실제 적용 시각부터 계산한다.

## 6. 비기능 요구사항

### 개인정보·권한

- 관계·로그인·공고 상태별 공개 범위를 서버에서 재검증해야 한다.
- 목록·검색·AI에서 비공개 상세 장소를 반환하지 않아야 한다.
- 취소 후 실명·상세 위치 접근을 회수해야 한다.
- AI와 로그에 회원 채팅·실명·전화·계좌·비공개 위치 원문을 남기지 않아야 한다.

### 신뢰성

- 최종 동의·완료·후기 공개는 중복 실행되어도 약속·알림·반영값을 중복 생성하지 않아야 한다.
- 시간 만료와 자동 완료는 한국시간 기준으로 일관되게 계산해야 한다.
- 외부 API 실패와 결과 0건을 분리해야 한다.
- 등록·신청·메시지·평가 실패 시 사용자의 입력을 가능한 범위에서 유지해야 한다.

### 접근성·사용성

- 모달·바텀시트는 키보드 포커스 이동, Escape 닫기, 포커스 복귀를 지원한다.
- 버튼에는 상태와 목적을 설명하는 접근 가능한 이름을 제공한다.
- 색상만으로 상태를 구분하지 않고 텍스트·배지를 함께 사용한다.

## 8. 성공 지표

초기 지표는 다음 퍼널을 기준으로 정의하되 목표 수치는 출시 전에 확정한다.

- 로그인 시작→자격 확인→가입 완료율
- 공고 상세→신청 완료율
- 채팅 화면 진입→첫 전송·신청 성립률
- 신청 성립→확정 요청률, 확정 요청→신청자 수락·동행 확정률
- 확정→실제 완료율
- 실제 완료→평가 제출률
- 후기 공개 후 재방문·재신청률
- 개인정보 차단·신고·취소·불발 비율
- 행사·AI 결과→공고 상세 또는 모집 전환율

## 9. 출시 전 필수 검증

- 비로그인·미확정·확정·취소·제3자 공개 범위
- 확정 요청 +6시간/시작 만료, 신청자 수락과 동시 확정 방지
- 변경 요청 +6시간/기존·새 시작 만료, 상대 수락·충돌 검사, 미응답 기존 약속 유지
- 첫 전송 성공/실패와 신청·작성자 채팅방·알림의 일관성
- 철회 후 1분 재신청 차단과 거절 후 영구 차단(동일 공고)
- 종료 +24시간 자동 완료와 취소·노쇼·신고·분쟁 제외
- 후기 +7일 작성, 양쪽 즉시/한쪽 기한 종료 후 공개
- 확정 약속 탈퇴 차단, 후기 기간 탈퇴 허용, 탈퇴 후기 익명 유지
- 동일 네이버 계정 기록 유지·재가입 즉시 허용·원래 제재 종료까지 기능 제한 유지
- 예정 시작 시각 순 집계·미정 결과 판정 보류·정상 완료 초기화·경고 이력 유지·연속 3회 단위 경고/7일 반복 제한
- 취소 처리 +24시간 이의 신청 기한, 기한 종료까지 적용 보류, 미신청 기한 종료 후/신청 검토 종료 후 판정, 실제 적용 시각부터 7일 제한
- 모집 재개 시 이전 유효 신청 자동 복원·알림 및 거절/철회 신청 복원 방지
- 외부 API 실제 실패·빈 결과·지연 상태
- AI 정보 제공 안내와 개인정보 차단
- 두 사용자·서버 권한·새로고침·다중 기기에서의 상태 일관성

## 10. 후속 범위

이메일 인증, 계좌 인증, 유료 거래, 결제·정산·환불, 친구·초대, 알림 설정, 관리자 행사 등록, 안심 통화·캘린더는 현재 출시 범위에 포함하지 않는다. 와이어프레임에 버튼이나 배지를 선노출하지 않으며 정책·법률·운영·서버 설계가 확정된 뒤 별도 PRD로 추가한다.
