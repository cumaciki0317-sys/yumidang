# 유미당 IA — 현재 서비스 정보 구조

현재 정책 원본은 [정책.md](../../../정책.md), 제품 목적·범위는 [PRD](../requirements/PRD.md), 행동·예외·복귀는 [USER_FLOW](./USER_FLOW.md)다. 기존 화면 ID를 연결 기준으로 유지하되 현재 기능과 추후 화면을 구분한다. [와이어프레임 HTML](./yumidang-wireframes.html)은 이번 문서 작업에서 수정하지 않았으며 최신 정책의 구현 근거가 아니다.

## 1. 기준과 범위

- 현재는 여성·만19세 이상 대상의 무료1:1 동행이다. 네이버 로그인에서 이름·성별·생일·출생연도를 필수로 받아 자격을 확인하고 네이버 계정당 유미당 계정 하나를 연결한다.
- 사진 필수, 관심사·대화 방식·MBTI 선택이다. 가입 완료 버튼→안내 팝업→홈을 유지한다. 기존 회원 로그인은 원래 목적 화면으로 복귀한다.
- 일반 공고·행사 탐색과 작성용 장소·행사 선택은 목적이 다르다. 검색 일치와 이름·주소 표시 권한도 구분한다.
- 선택 이메일·유료 동행·1원 계좌 인증은 현재 이용 경로에서 제외하고 추후 검토로 분리한다. S07·S22 ID는 후속 설계용으로 보존하며 현재 메뉴로 연결하지 않는다.
- 새로운 화면 배치·명칭 개편은 프론트 담당 영역이다. 아래에는 기존 유효 요구와 정책상 필요한 정보·상태를 유지하며, 구현 여부는 따로 검증한다.

### 3-1. 가입·계정·프로필

- 네이버 이름·성별·생일·출생연도 중 누락·확인 불가가 있으면 가입 완료를 보류하고 네이버 정보 확인·재시도를 안내한다. 자격 정보를 수기로 덮어쓰거나 성향·이메일로 우회하지 않는다.
- 여성·만19세 이상, 네이버 계정당 유미당 계정 하나다. 일반 로그인에서도 받은 최신 정보로 자격을 재확인한다. 새 등록·신청·확정 제한과 기존 약속 확인·취소·지원 경로를 구분한다.
- 계정 접근 불가는 네이버 복구를 안내한다. 다른 네이버 계정으로 연결 변경·활동 기록 이전은 현재 제공하지 않는다.
- 사진을 등록해도 가입 완료 버튼을 누르기 전 가입 완료로 처리하지 않는다. 성향은 각각 최대20개·40자, MBTI는 네 쌍의 선택이다. 입력한 성향은 프로필 열람 권한이 있는 회원에게 공개한다.
- 현재 프로필·공고 카드에 추후 이메일·계좌 인증 배지를 현재 기능처럼 배치하지 않는다. 해당 인증의 지원·효력·표시 세부는 추후 검토다.

### 3-2. 홈·검색·작성 정보

- 공고 검색 네 항목은 제목·등록 장소명·등록 주소·연결 행사명이다. 소개·후기·상세 지점은 검색 대상이 아니다. 장소 입력 도구와 등록 공고의 열람 권한은 다르다.
- 작성자 나이는 만19~99 숫자 최소~최대 범위이며 나이 전체에는 상한을 적용하지 않는다. 비로그인은 전체만 사용한다. 희망 상대 나이는 작성자 나이와 별도 항목이다.
- 등록일 최신순 기본·시작일 빠른순 선택, 전체 상태 기본·모집 중만 보기 선택이다. 현재 무료만 제공하므로 유료 선택·금액·지급 방향을 현재 작성/신청 조건으로 표시하지 않는다.
- 시작·종료 일시는 분리하고 자정 넘김을 허용한다. 모집 마감 미설정 시 시작 시각을 명시한다. 행사 선택은 작성 일정을 자동 변경하지 않는다.
- 등록 실패·개인정보 차단·오탐 문의·임시저장 복구 상태를 구분한다. 최근 검색·임시저장은 같은 기기에서 관리하며 개수·보관 기간은 미정값으로 숨기지 않는다.

### 3-3. 행사·AI 탐색

- 일반 목록은 이번 주 신규 기본·진행 중 포함 선택이다. 한국시간 월요일00:00~다음 월요일00:00 미만을 한 주로 본다. 작성용 선택은 진행 중·예정이며 선택 기간과 겹치는 행사로 좁힌다.
- 행사 정렬은 진행 중→예정→종료, 각 그룹은 최근 시작순·시작일 빠른순·최근 종료순이다. 과거 조회는 가능하지만 취소는 새 조회·선택에서 숨기고 종료는 새 모집 대상으로 안내하지 않는다.
- Top10은 전국 전체 공연 기본·뮤지컬 전환이며 어제까지 최근7일 공식 순위를 매일 갱신한다. 일반 목록 필터와 별개임을 보이고 출처·집계기간·갱신시각·미수신 상태를 표시한다.
- 지역·유형은 제공처 원문·실제 목록을 따르고 혼선 시 검토한 대응표를 추가한다. 입장료·운영일·회차·휴관·잔여석은 확인된 정보만 표시한다.
- AI는 현재 대화 조건을 우선하고 관심사·대화 방식 의미 유사성·MBTI 정확 일치를 적용한다. 미입력은 확인 필요로 남긴다. 사용자가 고른 정렬을 유지한다.
- 공고와 행사 카드를 구분하고 조건·실제 카드·추천 이유·확인할 점을 제공한다. 권한을 넘는 공개나 실패를 성공으로 꾸미지 않는다. 반환 직전 최신 상태 확인, 변경 시 카드·설명 처리, 일부 결과·실패 처리 세부는 팀 검토다.
- 외부 회원정보 전송은 공급사 보관 검토와 사용자 확인 전 보류다. 첫 이용 고지·상시 재열람·조건 변경 재안내, 개인정보 수정 요청·응답 숨김·재시도를 제공할 설계다.

### 3-4. 완료·평가·신뢰정보

- S16은 개인 완료 확인과 동행 실제 완료를 별도 상태로 표시한다. 예상 종료 뒤 본인이 완료 확인하면 상대 확인 전 S17 제출이 가능하나 미완료 후기는 비공개다.
- 양쪽 확인 또는 예상 종료+24시간 자동 처리로 완료한다. 취소·불발·분쟁은 자동 완료에서 제외한다. 실제 성공 시각부터 완료 횟수 즉시·작성7일·한쪽 공개24시간을 계산한다.
- 양쪽 제출 후 즉시 공개, 한쪽은 실제 완료+24시간에 공개한다. 상대 후기 열람 가능 시 당도를 반영하며 실제 클릭은 필요 없다. 본인·타인 모두 현재 당도만 표시한다.
- 경험·별점1~5 필수, 한마디 선택, 좋아요 칭찬 최대3개다. 칭찬6종은 시간을 잘 지켜요 / 약속한 내용을 지켜요 / 소통이 원활해요 / 배려심이 있어요 / 대화가 즐거워요 / 함께하니 편안해요다.
- 공개 칭찬 상위5개·횟수→AI 요약→원문을 보여준다. 한마디 있는 공개 후기3개 이상만 요약하며 한마디 없는 평가·비공개 후기를 제외한다. 요약 실패·대기는 원문 없음과 다르다.

## 6. 정책·구현 확인이 필요한 부분

팀 검토로 남은 범위는 노쇼·분쟁의 증거/판단/기한, 제재 세부, 신고·차단·고객지원 경로와 권한, 채팅·제출 캡처·로그·탈퇴 기록 보관, AI 운영 한도·품질·외부 보관, 당도 산식, 검색·임시저장 개수/기간, 결과 표시 개수, 카테고리 목록·글자 수, 베타 범위·패키징·게시자다. [정책.md](../../../정책.md)에서 확정과 검토 상태를 함께 확인한다.

일반 신고·분쟁에서 운영자는 서버 채팅 원문을 직접 열람하지 않는다. 당사자가 필요한 구간을 캡처해 접수하도록 안내하며 캡처 처리 근거·접근·보관·삭제는 별도 검토다.

개인 완료 확인 후 후기 선제출, 연결 행사명 검색, 네이버 전용·무료 전용 화면, 상태별 공고 관리, Top10·정보 차단 등은 실제 코드·화면·서버 권한을 따로 검증해야 한다. 이번에는 문서만 갱신했고 기존 HTML이나 과거 브라우저 검증을 최신 동작의 증거로 사용하지 않는다.
