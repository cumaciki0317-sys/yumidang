# 유미당 IA — 현재 화면 요구사항

기준일:2026-10-05. [정책](../../../정책.md)·[PRD](../requirements/PRD.md)·[USERFLOW](USERFLOW.md)를 따른다. 활성 화면 목표는 S08을 제외한23개다. S07·S08·S22는 현재 화면 ID를 부여하지 않는다. 본 문서는 화면 요구사항이며 실제 서비스 검증 상태는 NOT_RUN이다.

## 1. 전역 내비게이션

하단 탭은 4개다.

| 탭 | 화면 | 역할 |
|---|---|---|
| 홈 | S00 | 신규 행사, 다가오는 약속, 카테고리, AI·작성 진입 |
| U·둘러보기 | S01 | 공고 검색·필터·정렬·상세 진입 |
| 채팅 | S10 | 신청·확정·종료 대화 목록 |
| 나 | S13 | 내 동행·공고·프로필·후기·안전·계정 관리 |

AI 탐색 S20과 공고 작성 S03은 하단 탭이 아니라 홈·둘러보기의 플로팅 버튼에서 진입한다. 알림 S12는 로그인 상태의 상단 종 아이콘에서 진입한다.

## 4. 화면별 정보 구조

### 4-1. 탐색

#### S00 홈

1. 상단: 유미당 로고, 본인 실명 또는 로그인, 알림
2. 이번 주 신규 중 미종료 행사: 가로 배너, 진행 상태, 전체보기
3. 다가오는 약속: 확정 상태·D-day·일정·공개 지역
4. 동행 카테고리: 전시·공연·맛집 등 카테고리 그리드
5. 플로팅 액션: AI 탐색, 공고 작성

#### S01 둘러보기

1. 고정 상단: 검색창, 필터, 정렬, 결과 수
2. 검색 대상: 제목·장소명·주소·연결 행사명
3. 필터: 카테고리·시도 지역·일정·작성자 나이·모집 중만 보기
4. 정렬: 등록일 최신순 / 시작일 빠른순
5. 결과 카드: 무료, 모집 상태, 일정, 공개 지역, 작성자, 연결 행사
6. 빈 결과와 조회 실패 상태

#### S09·S09-2·S09-3 행사/카테고리

- S09는 선택한 카테고리의 공고 목록과 작성 진입을 제공한다.
- S09-2는 일반 행사 목록, 공연 장르, 공식 공연·뮤지컬 Top 10, 작성용 행사 선택을 한 화면에서 상태로 구분한다.
- S09-3은 행사 기본 정보, 공식 출처·운영 안내, 관련 공고, 행사 기반 모집을 제공한다.

### 4-2. 공고와 신청

#### S02 공고 상세

- 공고 제목·카테고리·무료 1:1 표시
- 일정, 공개 지역, 희망 상대, 작성자 요약, 연결 행사
- 신청자: 신청 또는 기존 대화 연결
- 작성자: 수정·마감·삭제·신청자 선택
- 확정 당사자: 전체 이름과 상세 만남 위치
- 확정 제3자: 확정 상태만 표시, 당사자 비공개 정보 제외

#### S03→S04 작성

- S03: 기본 정보, 장소명/주소 검색, 상세 지점, 행사 연결, 임시저장
- S04: 희망 상대 나이, 바라는 점, 일정·마감·공개 지역, 무료 원칙 최종 확인
- 성공: 생성된 S02로 이동
- 실패: 입력 유지, 재시도

#### 신청 진입 — S02→S11

- S08의 별도 소개 메시지 입력을 제거하고 S11로 바로 이동한다.
- 첫 메시지 전송 전에는 작성자 알림·채팅 목록·신청 목록에 나타나지 않는다.
- 첫 전송 성공 시 신청과 작성자 측 1:1 채팅방이 생성된다.
- 본인 철회 후 1분 동안 재신청 불가, 이후 횟수 제한 없이 허용한다. 거절 후에는 재신청 불가다.
- 재신청은 기존 동일 공고·상대 채팅방을 재사용하고 새 메시지 전송 성공 시 성립한다.

### 4-3. 채팅과 확정

#### S10 채팅 목록

- 대기·확정·종료 상태 배지
- 읽지 않은 대화
- 종료 대화 보존
- 대화방 나가기 시 본인 목록 숨김 안내

#### S11 채팅방

- 상대 프로필, 당도, 공고 요약, 무료 상태
- 작성자: 거절 / 대화·합의 후 확정 요청 / 요청 철회
- 신청자: 최종 동의 수락 / 거절; 요청 후 6시간과 시작 시각 중 빠른 때 만료
- 확정 후: 상세 만남 위치, 약속 상세, 시작 전 취소
- 확정 후 양쪽 누구나 일정·장소 변경 제안; 상대 수락·충돌 검사 후 반영
- 변경 만료: 제안 후 6시간·기존 시작·새 시작 중 가장 빠른 때; 거절·미응답이면 기존 약속 유지
- 한 명 확정 후 다른 신청은 모집 종료·읽기 전용; 확정 취소 후 작성자가 모집 재개하면 이전 유효 신청·채팅 자동 복원 및 알림
- 신고 안내: 문제 구간 캡처 접수
- 종료 상태: 읽기 전용

### 4-4. 나와 프로필

#### S13 나

- 내 동행: 보낸 신청, 받은 신청, 진행·완료 약속, 평가
- 내 공고: 상태별 공고, 새 모집
- 내 프로필: 공개 프로필 미리보기, 사진, 취향·성향
- 받은 후기
- 안전·계정: 안심 수칙, 계정 상태, 로그아웃, 탈퇴 안내

#### S14·S15·S15-2

- S14: 관계별 이름, 사진, 나이, 성향, 현재 당도, 칭찬 차트, AI 요약, 원문 후기
- S15: 사진 선택·미리보기·교체, 저장 실패 시 기존 사진 유지
- S15-2: 관심사·대화 방식·MBTI·한 줄 소개 편집

### 4-5. 약속·완료·평가

- S16: 약속 상태, 일정, 공개 지역, 상세 지점, 동행인, 완료 처리, 안심 수칙, 채팅
- S17: 경험, 별점, 좋아요 칭찬, 한마디, 제출·공개 상태
- S18: 확정 전 철회, 시작 전 취소, 시작 후 중단·불발 신고
- S19: 안심 동행 5대 수칙

### 4-6. AI·알림·계정

- S12: 전체/읽지 않음, 모두 읽음, 확정 요청·확정·후기 알림, 대상 소실·실패
- S20: 로그인 가드, 간단한 AI 정보 제공 안내, AI/사용자 대화, 빠른 응답, 행사·동행 카드, 새 대화; 설정 지역 사용, 메모리만 유지·화면 종료/로그아웃 시 삭제
- S21: 예정 시작 시각 순 취소 집계·정상 완료 시 0, 첫 3회 경고·이후 연속 3회마다 7일 제한, 경고·제재 시 횟수만 0, 경고 이력 유지; 다른 네이버 계정 변경 메뉴 없음·계정 간 기록 이전 없음, 탈퇴·즉시 재가입·원래 제재 종료까지 기능 제한 유지
- 제한 UI: 신규 작성·신규/재신청·새 확정 요청/수락 차단, 기존 확정 약속 관리·채팅·후기 허용
- 취소 이의 UI: 취소 처리 후 24시간 이내 접수·신청 마감 시각 표시·횟수 우선 반영·기한 종료까지 관련 경고/제재 적용 보류; 미신청이면 기한 종료 후, 신청하면 검토 종료 후 판정; 7일 제한은 실제 적용 시각부터 계산

## 8. 프로토타입 해석 주의

- 화면 상단의 상태·역할 선택은 시나리오 검토 도구다.
- 예시 정보와 브라우저 저장은 실제 서버 데이터가 아니다.

- 목표 요구사항은 본 문서와 정책이며 실제 HTML 화면 수·모의 동작은 별도 확인한다. S08은 활성 화면에서 제외한다.
