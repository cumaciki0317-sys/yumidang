# 유미당 USER FLOW — 사용자 정책 답변 반영

> 기준 파일: `유미당 와이어프레임.html`  
> 문서 기준일: 2026-10-03  
> 관련 문서: [정책](./정책.md) · [IA](./IA.md) · [PRD](./PRD.md)

> 2026-10-03까지의 사용자 정책·운영 확인 답변 기준 목표 흐름이다. 기존 HTML의 S08은 제거 대상이며 아직 HTML에는 반영되지 않았다. 이번 정책 확인 질문은 모두 답변이 반영되었다.

## 1. 핵심 사용자 흐름

```text
탐색 S00/S01/S09/S09-2
→ 공고 상세 S02
→ 신청 버튼 → 신청자 채팅 화면 S11
→ 첫 메시지 전송 성공 → 신청 성립·작성자 채팅방 생성·채팅 도착
→ 서로 대화·합의
→ 작성자의 확정 요청
→ 신청자의 최종 수락
→ 약속 확정 S16
→ 완료 확인
→ 상호 평가 S17
→ 공개 프로필 S14 반영
```

공고 작성 흐름은 `S03 → S04 → 생성된 S02`, 행사 기반 모집은 `S09-2/S09-3 → S03`, 취소·철회는 `S11/S16 → S18`이다.

## 2. 로그인·가입·복귀

```text
로그인이 필요한 행동
→ S05 네이버 로그인
├─ 로그인 취소/연동 실패 → 오류 안내 → 재시도 또는 이전 화면
├─ 필수 정보 누락 → 네이버 정보 확인 안내 → 재시도
├─ 여성·만 19세 이상 불충족 → 가입 불가 안내
├─ 기존 회원 → 최신 정보 확인 → 원래 목적 화면 또는 홈
└─ 신규 회원 → S06
   → 프로필 사진 필수 등록
   → 관심사·대화 방식·MBTI 선택 입력
   → 가입 완료
   ├─ 사진 없음 → 완료 보류·사진 등록 안내
   └─ 성공 → 완료 팝업 → S00 홈
```

로그인 전 목적 화면은 기존 회원에게만 즉시 복귀한다. 신규 회원은 가입 완료 뒤 홈으로 이동한다. 사진을 선택한 것만으로 가입 완료가 되지 않는다.

## 3. 홈·둘러보기·카테고리 탐색

### 3-1. 홈 S00

```text
S00 홈
├─ 비로그인: 로그인 / 신규 행사 / 카테고리 / AI·작성 로그인 유도
└─ 회원: 본인 실명 / 알림
   ├─ 신규 행사 배너 → S09-3
   ├─ 전체보기 → S09-2
   ├─ 다가오는 약속 → S16
   ├─ 나의 동행 → S13
   ├─ 카테고리 → S09
   ├─ AI → S20
   └─ + 공고 작성 → S03
```

- 확정 약속이 없으면 빈 상태를 보여준다.
- 행사 조회 실패는 다시 시도와 함께 표시하며 빈 행사로 처리하지 않는다.

### 3-2. 둘러보기 S01

```text
S01 목록
→ 검색어 입력 또는 필터 열기
→ 카테고리·지역·일정·작성자 나이 선택
→ 적용하기
→ 등록일 최신순 또는 시작일 빠른순
→ 전체 상태 또는 모집 중만 보기
├─ 결과 있음 → 카드 본문 S02 / 작성자 S14
├─ 0건 → 조건 변경·초기화
└─ 조회 실패 → 재시도
```

- 필터는 적용 전까지 결과를 바꾸지 않는다.
- 비로그인은 일정·나이 상세 조건을 사용할 수 없다.
- 검색 대상은 제목·등록 장소명·등록 주소·연결 행사명이다.
- AI는 S20, `+`는 S03으로 이동한다.

### 3-3. 카테고리 S09

```text
S00 카테고리 선택 → S09
├─ 공고 카드 → S02
├─ 작성자 → S14
└─ 선택 카테고리로 모집 → S03
```

목록 0건과 조회 실패를 구분하며 모집 중만 보기의 기본값은 꺼짐이다.

```text
S03 작성

   ├─ 등록 실패 → 입력 유지·재시도
```

### 작성 중 이탈

```text
S03 뒤로가기
→ 이탈 확인
├─ 계속 작성 → S03 유지
└─ 나가기 → 같은 기기 임시저장
   → 재진입 시 복구 안내
   ├─ 복구 → 입력 복원
   └─ 폐기 → 새 작성
```

등록 성공이나 로그아웃 시 임시저장을 삭제한다. 행사 선택은 작성 일정을 자동 변경하지 않는다.

## 5. 공고 상세의 역할 분기

```text
S02 공고 상세
├─ 비로그인
│  ├─ 열람 → 공개 정보만
│  └─ 신청 → S05 로그인
├─ 로그인·미신청
│  ├─ 작성자 프로필 → S14
│  └─ 신청 → S11 첫 채팅 전송 전 화면
├─ 이미 신청/대화 중 → 기존 S11
├─ 작성자
│  ├─ 수정 → S03
│  ├─ 수동 마감
│  ├─ 삭제 확인
│  └─ 신청자 대화·선택 → S11 확정 요청
├─ 최종 동의 대기 → S11 수락/거절
├─ 확정 당사자 → 실명·상세 위치·S16
├─ 확정 공고 제3자 → 비공개 정보 제외
└─ 마감/삭제/조건 불일치 → 새 신청 불가 안내
```

수동 마감 후에도 기존 신청자와 대화하고 시작 전 최종 동의를 요청할 수 있다. 핵심 조건 변경 시 기존 요청은 무효화하고 새 조건으로 다시 동의받는다.

## 6. 신청 버튼→첫 채팅 S11

```text
S02 신청하기
├─ 과거 작성자 거절 → 같은 공고 재신청 불가
├─ 본인 철회 후 1분 미경과 → 재신청 불가·남은 시간 안내
└─ S11 신청자 채팅 화면
   → 공고 조건 확인·메시지 작성
   ├─ 첫 전송 없이 이탈 → 미신청·작성자 알림 없음·작성자 채팅방 없음
   ├─ 전송 실패 → 미신청·작성자 알림 없음·재전송
   └─ 첫 전송 성공
      → 신청 성립
      → 작성자 측 1:1 채팅방 생성과 채팅 도착
      → 대화·합의
```

별도 신청 메시지 화면 S08을 제거한다. 본인 철회 후 1분 경과 시 횟수 제한 없이 재신청하며 거절 후에는 불가하다. 재신청은 동일 공고·상대 채팅방과 이력을 재사용하며 새 메시지 전송 성공 시 성립한다. 기존 일정 겹침 경고는 유지하되 별도 신청 화면에서 처리하지 않는다.

## 7. 채팅·최종 동의·확정 S11

### 7-1. 확정 전

```text
첫 채팅 전송 성공·신청 성립 → S11 대화
├─ 신청자: 메시지 대화·공고/프로필 확인·신청 철회 S18
└─ 작성자: 메시지 대화
   ├─ 신청 거절 → 대화 종료
   └─ 채팅·합의 후 확정 요청(한 번에 1명)
      ├─ 신청자 거절/요청 철회/만료 → 미확정·신청/대화 유지
      └─ 신청자 수락
         → 최신 조건·권한·정원·일정 충돌 재확인
         ├─ 충돌/상태 변경 → 확정 차단·안내
         └─ 통과 → 확정·실명·상세 만남 지점 공개·S16 약속 생성
            → 다른 신청은 모집 종료·채팅 읽기 전용
```

확정 요청은 `요청 후 6시간`과 `동행 시작 시각` 중 빠른 때 만료된다. 만료 시 약속을 생성하지 않고 신청·대화를 유지한다. 요청 상대를 바꾸려면 기존 요청을 철회한다. 다른 신청의 모집 종료는 거절과 구분한다.

```text
확정 상대의 취소 → 기존 다른 신청은 모집 종료 상태 유지
→ 작성자가 모집 재개
→ 이전 유효 신청·채팅 자동 복원·상대방 알림
→ 다시 대화·확정 요청(현재 공고 조건·권한·일정 충돌 재확인)
```

거절·본인 철회된 신청은 자동 복원하지 않는다. 제재 중인 사용자는 복원 후에도 새 확정 요청·수락이 제한된다.

### 7-2. 조건 변경

```text
확정 전 공고 핵심 조건 변경
→ 신청자에게 변경 알림
→ 기존 최종 동의 요청 무효화
→ 새 조건으로 작성자 재요청 → 신청자 수락
```

### 7-3. 확정 후 일정·장소 변경

```text
S11 확정 상태 → 양쪽 누구나 일정·장소 변경 제안
→ 새 일정·장소 입력 → 제안 발송
├─ 거절/철회/만료 → 기존 약속 유지
└─ 상대 수락 → 일정 충돌 확인
   ├─ 충돌 → 변경 차단·기존 약속 유지
   └─ 통과 → 변경 반영·양쪽 알림
```

변경 제안은 `제안 후 6시간`, `기존 시작 시각`, `새 시작 시각` 중 가장 빠른 때 만료된다. 미응답이면 기존 약속을 유지한다.

### 7-4. 채팅 예외

- 전송 실패: 실패 메시지 표시→재전송
- 신고: 더보기→신고 안내→문제 구간 캡처 접수
- 종료 대화: 읽기만 가능, 새 메시지 차단
- 대화방 나가기: 본인 목록에서만 숨김, 상대 기록 보존

## 8. 행사 탐색·연결

### 8-1. 일반 행사

```text
S00 전체보기 또는 행사 메뉴 → S09-2
→ 이번 주 새로 시작한 행사
→ 선택: 진행 중 포함 / 지역 / 기간 / 유형 / 공연 장르
├─ 결과 없음 → 조건 변경
├─ 조회 실패 → 재시도
└─ 행사 선택 → S09-3
   ├─ 관련 공고 → S02
   ├─ 진행 중·예정 행사로 모집 → S03
   └─ 종료 행사 → 새 모집 차단
```

### 8-2. 공고 작성용 행사 선택

```text
S03 행사 연결 → S09-2 작성용 모드
→ 진행 중·예정 + 작성 일정과 겹치는 행사
→ 행사 선택
→ S03 복귀·행사 정보 연결
```

### 8-3. 공식 KOPIS Top 10

```text
S09-2 공식 순위
├─ 전국 전체 공연 Top 10(기본)
└─ 뮤지컬 Top 10
→ 행사 상세 S09-3
```

어제까지 최근 7일 공식 순위와 출처·갱신 시각을 표시한다. 미수신 시 예시 순위나 자체 추정치로 대체하지 않는다.

## 9. AI 동행 탐색 S20

```text
S00/S01 AI → S20
├─ 비로그인 → S05 로그인 안내
└─ 로그인
   → 기존 회원이면 개정 AI 약관 확인(미확인 시 AI 사용 전 확인)
   → AI 화면의 간단한 정보 제공 안내(가입 약관에 포함)
   → 자연어 요청 또는 빠른 응답
   → GPS 없이 설정 지역 사용; 미설정이면 지역명 질문
   → 조건 해석·추천
   ├─ 행사 카드 → S09-3
   ├─ 동행 공고 카드 → S02
   └─ 결과 없음/미지원 → 조건 수정 안내
```

- 사용자 메시지는 오른쪽, AI 메시지는 왼쪽에 표시한다.
- 행사와 동행 공고를 별도 그룹으로 표시한다.
- 비공개 상세 주소·거리·개인 식별 정보는 결과에서 제외한다.
- 초기 AI 대화는 기기 메모리만 사용하며 화면 종료·로그아웃 시 삭제한다. 서비스 서버·브라우저 영구 저장소에는 저장하지 않는다.
- 추천·후기 요약 모두 AI 안내 대상이다. 신규 회원은 가입 약관, 기존 회원은 개정 약관을 확인한 뒤 사용한다.
- 현재 프로토타입은 카테고리·주요 지역·무료·주말 조건까지를 범위로 한다.

```text
   → 사용자 후기 원문
```

공개 텍스트 후기 3개 미만이면 AI 요약 대기 안내를 표시한다. 요약 실패 시에도 칭찬과 원문은 유지한다.

## 11. 약속 완료 S16

```text
확정 → S16 예정
→ 예상 종료 시각 경과
→ 내 동행 완료 확인
├─ 한쪽만 확인
│  → 상대 확인 대기
│  → S17 후기 선제출 가능(비공개)
└─ 양쪽 확인 또는 종료 +24시간
   → 동행 실제 완료
   → 완료 횟수 반영
   → 평가 S17
```

예외 흐름:

```text
취소 → 자동 완료 제외·실명/상세 위치 숨김
불발·노쇼 → 자동 완료 제외·중단/불발 신고 S18
신고 검토 중 → 자동 완료 보류
분쟁 → 평가 작성·기한·공개 일시 중단
→ 동행 인정 후 남은 리뷰 기간 재개(최소 24시간 보장)
├─ 미완료이고 원래 종료+24시간 경과 → 즉시 완료·그때부터 리뷰 7일
├─ 미완료이고 원래 종료+24시간 미경과 → 원래 완료 기준 유지
└─ 이미 완료 → 검토 전 남은 리뷰 기간 재개·최소 24시간
```

## 12. 평가 S17

```text
S16 본인 완료 확인 후 → S17
→ 경험 선택: 좋아요 / 보통이에요 / 별로예요
→ 별점 1~5(필수)
→ 좋아요인 경우 공식 칭찬 최대 3개(선택)
→ 한마디(선택)
→ 제출
├─ 실패 → 입력 유지·재시도
└─ 성공 → 수정·중복 제출 잠금 → S16
   ├─ 실제 완료 전 → 비공개 대기
   ├─ 양쪽 제출 → 즉시 공개
   └─ 한쪽 제출 → 후기 작성 기한 종료 후 공개
```

후기 작성 기한은 실제 완료 +7일이다. 공개 시 프로필 후기·칭찬·당도에 반영한다.

후기 기간 중 상대가 탈퇴해도 남은 사용자는 기한까지 작성 가능하다. 탈퇴 회원 표시와 기존 공개 후기 익명 유지를 제공한다. 검토 중에는 작성·기한 진행·공개를 보류하고 인정 후 남은 기간을 재개하되 최소 24시간을 보장한다.

## 13. 철회·취소·불발 신고 S18

### 확정 전 철회

```text
S11/S13 → 신청 취소(철회)
→ 사유 선택·기타 입력
├─ 유지하기 → 이전 화면
└─ 철회하기
   ├─ 실패 → 재시도
   └─ 성공 → 상대 알림·대화 읽기 전용 → S10
```

철회 후 1분간 재신청을 막고 이후 횟수 제한 없이 허용한다. 연속 확정 취소 제재에는 포함하지 않는다.

### 시작 전 확정 취소

```text
S11/S16 → 확정 동행 취소
→ 사유 선택
├─ 유지하기 → 이전 화면
└─ 취소하기
   → 상대 알림
   → 실명 재마스킹·상세 주소 숨김
   → 대화 읽기 전용 → S10
```

### 시작 후 중단·불발

```text
시작 시각 이후 문제 발생
→ S18 중단·불발 신고
→ 상황 설명(필수)
→ 접수
→ 운영 검토
```

신고 접수만으로 노쇼·책임·제재를 자동 확정하지 않는다.

```text
상단 종 → S12
```

알림 클릭은 읽음 처리와 화면 이동만 수행한다. 동의·확정·평가 제출을 자동 실행하지 않는다.

## 15. 계정 상태·탈퇴 S21

```text
S13 안전·계정 → S21
→ 인증·실명·성별·나이·가입일 확인
→ 연속 확정 취소·제재 확인
├─ 정상/경고/이용 정지 안내
├─ 다른 네이버 계정으로 변경 → S05
└─ 회원 탈퇴
   ├─ 진행 확정 약속 있음 → 탈퇴 차단·취소 안내
   ├─ 후기 기간만 남음 → 탈퇴 허용·상대 작성 가능·기존 후기 익명 유지
   └─ 탈퇴 신청
      → 작성 공고·진행 신청 취소
      → 동일 네이버 계정의 제재·연속 취소 기록 유지
      → 재가입 즉시 허용
      ├─ 일반/경고만 있음 → 활동 제한 없음
      └─ 남은 제재 있음 → 원래 종료 시각까지 동일 기능 제한 유지
```

취소율 15%와 탈퇴 후 30일 재가입 제한은 폐기한다. 계정 간 기록 이전은 지원하지 않는다.

```text
확정 동행의 결과를 예정 시작 시각 순서로 집계
├─ 중간 결과 미정 → 이후 연속 판정 보류
├─ 정상 완료 → 연속 취소 횟수 0(경고 이력 유지)
└─ 본인 취소 → 횟수 우선 반영
   → 취소 처리 후 24시간까지 관련 경고·제재 적용 보류
   ├─ 24시간 이내 이의 신청 → 검토 종료 후 판정
   │  ├─ 사유 인정 → 취소를 제외하여 예정 시작 시각 순서로 재계산
   │  └─ 불인정 → 취소를 유지하여 판정
   └─ 기한 종료까지 이의 신청 없음 → 연속 판정 가능 시 적용
      → 적용 가능한 연속 3회
      ├─ 경고 이력 없음 → 첫 경고·횟수만 0
      └─ 경고 이력 있음 → 7일 제한·횟수만 0(이후 반복도 동일)
```

기한 내 신청이 있으면 검토 종료 후 인정 사유를 제외하거나 취소를 유지하여 같은 연속 3회 판정에 연결한다. 예정 시작 시각 순서의 중간 결과가 미정이면 이후 연속 판정은 계속 보류한다.

7일 제한은 실제 제재 적용 시각부터 계산하며 신규 작성·신규/재신청·새 확정 요청/수락을 차단한다. 기존 확정 약속 관리·채팅·후기는 허용한다. 신청 대기·검토 기간은 제재 기간에 포함하지 않는다.

## 17. 프로토타입·구현 검증 경계

- 상태·역할 버튼은 검토용이며 실제 권한 시스템이 아니다.
- 로그인, 장소, 행사, AI 데이터는 예시가 포함되어 있다.
- 출시부터 KOPIS·TourAPI·서울 열린데이터를 실제 연동한다. 실제 제공되는 유형·지역의 데이터만 노출한다.
- 시간 만료·자동 완료·후기 공개는 실제 서버 스케줄러와 다중 사용자 환경에서 검증해야 한다.
- 브라우저 메모리·IndexedDB의 저장은 실서비스 서버 저장과 동일하지 않다.
- 이메일 인증·계좌 인증·유료 거래·결제·친구·알림 설정은 현재 흐름에 없다.
