# UT 시나리오·관찰·개선 자료

UT는 유미(`yumi`) 담당이다. 이 폴더에는 사용성 시나리오·판정 기준·관찰 결과·개선 과제를 작성한다. 실제 UT 실행이나 회원 검증 완료를 이 안내의 생성으로 계산하지 않는다.

참고: [정책](../../../정책.md)·[IA](../design/IA.md)·[USERFLOW](../design/USERFLOW.md)·[현재 역할](../../collaboration/requests/minkyu/2026-10-14-role-reassignment.md).

관찰 자료는 대상/환경·단계·예상 행동·실제 행동·문제·개선 Task·검증/보류를 구분한다. QA는 민규·종현·유미 공통이며 서버 결함은 민규, 화면/앱 연동 결함은 종현에게 연결한다. 실제 회원 자료·원문 외부 전송의 기존 HOLD를 유지한다. 파일별 단독 수정과 유미의 명시 UT 경로 제한을 따른다.


행사 UX의 현재 시나리오 기준은 [최종 확정 명세](../../collaboration/requests/jonghyun/2026-10-20-event-ux-approved-spec.md)다. 일반 작성/행사 상세 진입별 영역 위치, 날짜가 달라도 행사 연결 가능·달력 날짜 강조, 직접 입력의 공고 전용 저장, 이미지 실패 시 글만,0건/실패 구별, 비표출 안내·공개 원천 전환, 취소/연기와 약속의 분리, 검증 동일 행사 통합 및 충돌 시 새 연결 제한을 관찰 항목으로 삼는다. 문서화는 UT 실행 결과가 아니며 현재 관찰 결과/통과 건수를 새로 만들지 않는다. 서버 미지원 상태는 모형 관찰과 실제 연결 검증을 구분한다.


[행사 UX 동작 미리보기](../design/행사UX_미리보기.html)는 합성 행사·공고로 확정 설계를 확인하는 별도 모형입니다. 실제 API 호출·회원 데이터·서버 저장·상태 검증·알림·동일 행사 통합 완료를 뜻하지 않습니다. 이 모형의 사용성 확인과 실제 서버 연결·실회원 UT 결과를 분리 기록한다.
