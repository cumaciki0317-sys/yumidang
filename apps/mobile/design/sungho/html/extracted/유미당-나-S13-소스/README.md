# S13 · 나: 디자인 전용 시안

기존 승인 레이아웃과 실제 세 탭(내 동행 / 내 공고 / 프로필)을 유지합니다. 상단 회색 선택기는 앱 밖의 디자인 검토 도구입니다.

## 경계
- views.json은 원본 initialState의 2026-10-12 10:00 UTC 스냅샷을 바탕으로 미리 확정한 12개 표시 예시입니다. 원본 세 회원과 비로그인 예시를 유지하며 새 회원 데이터는 추가하지 않았습니다.
- app.js는 보기와 탭을 바꾸기만 합니다. 로그인 판정, 회원 권한, 후기 자격, 날짜 계산, 목록 필터링, 검색·정렬, API, 저장, 로그아웃 실행은 없습니다.
- 후기 버튼은 해당 고정 예시에서 작성 가능한 경우에만 미리 포함했습니다. 취소·분쟁·마감·중복 제출의 실서비스 처리는 원본 앱 담당이며 이 파일을 정책 엔진으로 사용하지 않습니다.
- 일치하는 post-1/post-completed 신청 행은 선택한 공고 정보를 전달해 S11 HTML로 이동합니다. 그 외 목적지는 검토 패널에 연결 대상만 표시합니다. 로그인·로그아웃은 실행하지 않습니다.
- 모든 버튼은 기존 .96 / 100ms 시각 레이어 눌림을 사용합니다. 원래 히트 영역과 색상·불투명도는 유지합니다.
- 게스트 보기에는 회원 이름·사진·나이·당도·계정 설정을 표시하지 않습니다. 파일의 예시 데이터는 합성 프로토타입 데이터이며 실제 계정 정보가 아닙니다.

## 파일
- 유미당-나-S13.html: 최신 디자인 기준 HTML (공통 자산 포함 extracted 폴더로 전달)
- 이전 build.py 호환 명령은 제거했습니다. 기준 HTML을 직접 엽니다.
- node test-ui.cjs: 고정 보기·버튼·게스트 표시와 업무 로직 부재 검사
- views.json: 표시 문구·마크업 예시; API 스키마 또는 데이터 모델이 아님

원본 frontend/backend·정책·데이터/API·저장 기능은 수정하지 않았습니다. 서버 구현이나 배포 완료를 뜻하지 않습니다. 실제 앱 적용 시 원본 상태/권한/후기 조건에서 받은 표시 값과 콜백을 연결해야 합니다. 소스/모의 DOM 검사를 실제 브라우저·터치 검증으로 표현하지 않습니다.
