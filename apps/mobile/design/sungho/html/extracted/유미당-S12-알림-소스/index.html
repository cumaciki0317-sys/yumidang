검토 범위

동행 신청·확정 요청·동행 확정·일정 변경 제안·후기 작성·동행 완료의 고정 예시입니다. 동행 신청은 첫 메시지 전송 성공으로 생성된 상태입니다. 화면 외부 조작 패널에서 장면을 전환합니다.

알림 누름·모두 읽음·뒤로는 Expo 연결 이벤트입니다. 서버 읽음 처리와 화면 이동은 실행하지 않습니다. 모두 읽음 버튼은 요청 이벤트만 표시하며 성공·실패는 장면 선택으로 확인합니다. 비로그인·삭제·권한 변경·지난 요청은 별도 접근 결과 예시입니다.

연결 값: 관계별 공개 이름·사진, 알림 내용, 공고 제목, 약속 일정, 알림 도착 시각, 종류, 읽음 여부, 대상 ID. 확정 당사자는 전체 이름, 그 외는 마스킹 이름을 전달합니다. 사진과 일정은 합성·고정 예시입니다. 현재 서비스의 알림 종류 및 대상 상태에 맞춰 전달합니다.

전체/읽지 않음은 IA 및 Expo 미리보기 기준이며 실제 서비스 화면에는 필터 연결이 필요합니다.
