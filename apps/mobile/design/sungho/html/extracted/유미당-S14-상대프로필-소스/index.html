검토 범위

사진·이름·후기·당도는 합성 예시입니다. 공개 조건은 직접 선택하는 고정 장면이며 서버 권한 판정이나 당도 계산을 구현하지 않습니다.

메뉴·접기·펼치기·확인창·누름 효과만 조작합니다. 로그인·신고·차단·재조회·더보기는 아래에 연결 이벤트를 표시합니다. 결과는 장면에서 선택합니다.

Expo 연결

기준: CommunityScreens.tsx의 PreviewProfileScreen, RemoteScreens.tsx의 RemoteProfileScreen. 필요한 값: 공개 이름·사진·나이·완료 횟수·당도·소개·성향·칭찬 Top 5·공개 후기·요약 및 각각의 조회 상태.

후기는 하단 도달 시 5개씩 추가 조회합니다. 요청 중 중복 조회를 막고 nextCursor가 없으면 종료합니다. 실패 후 하단 영역을 벗어났다가 다시 진입하면 1회 재시도하며, 다시 시도 버튼도 제공합니다. HTML에서는 추가 조회 중·실패·결과 장면을 선택해 확인합니다. 요약 펼침 시 공개 조건 재확인, 신고 대상 profileId를 연결합니다. 탈퇴·비로그인·접근 불가에는 실제 프로필 값을 전달하지 않습니다. 실제 Expo에는 아직 적용하지 않았습니다.
