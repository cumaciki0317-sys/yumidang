백업 및 범위
최신 Library v6 HTML/ZIP을 별도 검증 백업한 뒤 수정. 원본 앱/백엔드 및 S05v9 변경 없음. 실제 가입·저장·업로드·정책 검증 엔진은 없으며 입력·선택·사진 표시와 명시적인 검토 상태만 제공.

현재 화면
- 사진 → 관심사 → 대화 방식 → MBTI 순서. 기본 정보 예시, 내 프로필 미리보기, 가입 마지막 단계 배지, 중복 상위 취향 및 성향 태그 제목/설명 제거. 사진 필수·성향 선택 안내는 상단에 한 번 유지.
- 사진 영역은 카드 외곽 테두리 없이 점선 원형 사진 구성. 필수/선택 표시는 모두 제목 바로 옆6px 간격, 12px/400으로 통일. 필수만 브랜드색으로 구분하며 기존 오른쪽 필수 배지는 제거. 사진 선택은 실제 DS16 보조 액션 표본에 맞춘 secondary 버튼.
- 사진 선택 버튼: DS16 갤러리 초기화/적용하기 중 보조 액션(초기화) 표본을 기준으로 width36%, height:auto/min49px, border0, radius15px, 배경 #F0F2F6, 글자 #6B7280, padding8px 6px, font1rem/700, line-height1.4, overflow-wrap:anywhere. 전용 사진 선택 컴포넌트는 DS에 없으므로 실제 보조 액션 표본을 재사용.
- v6에서 잘못 혼합했던 border1px·font13px·padding12px16px·min-width128px은 제거. 눌림도 DS16 원본 시각 레이어 스크립트를 사진 선택 버튼에만 범위 제한하여 재사용: .96/100ms ease-out, 실제 버튼의 hit영역 고정, focus4px/offset4, 비활성.43. 다른 버튼은 변경하지 않음.
- 사진→관심사/관심사→대화/대화→MBTI의 구간선 3개: #E7E3ED 1px, 위아래20px. 이전26px section margin과 사진 하단4px padding을 대체해 중첩하지 않음. 제목-내용12px, 본문 좌우20px 및 기존 폰트 크기 유지.
- 모든 인라인 오류: DS #BD4465, 13px/400/line-height1.7, 관련 영역 가까이 중앙정렬. role=alert와 aria-describedby/aria-invalid 연결. 기존 정책 문구 유지.
- 사진이 없으면 가입 완료 disabled/aria-disabled 및 opacity .43. 유효한 예시 사진 또는 로컬 표시 사진이 있으면 활성. 버튼은 실제 가입을 실행하지 않음. 사진 오류가 나면 기존 유효 사진을 유지하며 미등록 상태는 비활성.
- 로컬 이미지 디코딩은 표시 가능 여부만 확인. 새 선택/검토 상태 변경 뒤 늦게 끝난 이전 결과는 무시하고 URL을 회수. 파일 크기/형식 업무검증이나 외부 전송은 하지 않음.
