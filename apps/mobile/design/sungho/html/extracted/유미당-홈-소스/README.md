# 최신 디자인 기준

화면 검토와 Expo 디자인 적용 기준은 [유미당-홈.html](유미당-홈.html) 하나입니다.

- 하위 폴더의 CSS·JS·템플릿은 이전 분리 소스 또는 참조 자산이며, 현재 화면을 재생성하거나 Expo 디자인 기준으로 사용하지 않습니다. 최신 디자인은 기준 HTML과 그 HTML이 참조하는 자산에서 확인합니다.
- 구버전 홈 `yumidang-home/index.html`은 제거했습니다. 화면은 위 기준 HTML을 직접 엽니다.
- 공통 자산 참조를 유지하려면 `extracted` 폴더 구조 전체를 함께 전달합니다. 이전 ZIP과 분리 소스는 최신 납품본이 아닙니다.
- 승인된 고정 장면과 디자인 시안 범위만 해당하며 실제 Expo 연결 완료를 뜻하지 않습니다.
