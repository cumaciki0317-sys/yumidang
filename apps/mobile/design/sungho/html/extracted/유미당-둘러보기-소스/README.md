# 둘러보기 · 공고 탐색 통합 시안

기준 화면은 [유미당-둘러보기.html](유미당-둘러보기.html) 하나입니다.

- 공고를 누르면 `browse-detail.js`가 공고 상세 원본을 iframe src로 엽니다. 복사된 HTML이나 srcdoc을 만들지 않습니다.
- 뒤로 가기·상세 닫기는 같은 목록과 스크롤 위치를 유지하고 선택한 카드로 포커스를 돌려줍니다.
- 목록과 상세의 상태 검토 패널을 유지합니다. 실제 Expo 라우팅·서버 처리는 포함하지 않습니다.
- 이전 하위 index.html은 삭제했습니다. 연결 시안 별도 진입점도 사용하지 않습니다.
- 공통 자산 참조를 위해 extracted 폴더 구조를 함께 전달합니다.

이전 하위 분리 CSS·JS는 실행 중인 화면에서 참조하지 않음을 확인하고 제거했습니다. 하위 폴더의 자산과 과거 테스트·검증 문서는 보존 자료이며 최신 구현 기준이 아닙니다. 과거 테스트는 제거된 소스를 대상으로 하므로 현재 화면 검증에 사용하지 않습니다.
