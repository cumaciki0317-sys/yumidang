S11 · 채팅 디자인 전용 검토

기준: apps/mobile/src/screens/CommunityScreens.tsx PreviewChatScreen의 화면 요구를 대조합니다.
보존: 프로필·당도 표시, 제목 위치를 유지하는 공고 접기/펼치기, 더보기, 알림 켜기/끄기 표시, 입력창과 피드백, 기존 승인 스타일.

단순화 전 → 후
- 대화 중/첫 메시지 전/실패/차단/거절/종료/철회 대기/재신청 가능/삭제/완료/작성자 신청 없음 → 동일한 고정 장면 선택.
- 전송 후 메시지 누적과 신청 생성 예시 → 고정 '첫 전송 성공 결과' 장면으로 선택.
- 약속 대화 중/확정 요청 대기/확정/변경 대기/취소/시작 이후 → 동일한 고정 장면.
- 시계 이동으로 요청/변경 만료 → '확정 요청 만료', '변경 제안 만료' 고정 장면.
- 수락 충돌 체크 → '일정 충돌' 고정 장면.
- 일정·장소/취소·철회 사유/신고 설명 입력 → 입력폼 유지. 오류는 '입력 오류 표시 예시' 선택으로 확인.

버튼은 이벤트 설명 또는 폼 열기만 수행합니다. 전송 성공/실패와 업무 결과는 검토 선택으로 표시합니다.
시간·만료·일정 충돌·자격 계산, 업무 상태 자동 전환, 신청 생성, 메시지 누적, 저장/API 호출/외부 화면 이동/sessionStorage는 제거했습니다.
선택 공고 전달 및 실제 화면 이동은 앱 담당자의 callback 연결 과제입니다. 이 페이지는 고정 합성 데이터이며 업무 엔진으로 사용하지 않습니다.
