유미당 S02 공고 상세 · 디자인 검토용

실행: 유미당-공고상세.html 한 파일을 엽니다. ZIP 안의 유일한 HTML도 같은 실행 파일입니다. index.template.html.txt는 개발용 템플릿입니다.

현재 범위
- 외부 상태 선택기에서 31개 고정 디자인 장면을 선택합니다.
- 신청자 선택/거절/모집 마감/재개/삭제는 버튼과 기존 확인창 표현만 제공합니다.
- 확인해도 공고·신청·요청 상태는 변경되지 않습니다. 결과 장면은 상태 선택기로 봅니다.
- 재신청 대기60초는 고정된 예시입니다. 업무 타이머·자동 상태전이·저장·서버 연결은 없습니다.
- 시트, 드래그 스크롤, 눌림 표현, 메뉴, 확인창, 닫기와 다시보기는 UI 상호작용입니다.

정책에 맞춘 표시
- 별도 마감 설정이 없는 예시는 동행 시작 시각=모집 마감입니다.
- 대기 요청 만료는 장면 기준 시각+6시간과 동행 시작 중 빠른 시각입니다.
- 만료/완료 장면은 각각 시작/종료 이후의 고정 기준 시각을 외부 검토 패널에 표시합니다.
- 함께할 분 조건은 나이 정보만 사용합니다. 성별/새 조건을 추가하지 않습니다.
- 차단 장면에는 공고·프로필·신청 버튼을 표시하지 않고 기존 닫기 조작을 유지합니다.
- 확인된 당사자만 상세 위치를 보는 조건과 게스트 합성프로필 blur를 유지합니다.

원래 앱 frontend/backend와 실제 서비스 데이터는 수정하지 않았습니다.
비로그인 blur는 합성 시안의 표현이며 실제 보안정책을 대체하지 않습니다.
다른 화면 이동은 눌림 표현만 제공합니다. 연결본의 탐색↔상세만 실제 화면 전환입니다.

검증: node test-detail.js / node test-bottom-sheet.js
소스·mock DOM·타이머 검사입니다. 브라우저 시각/터치/클리핑 검증은 미실시입니다.
승인된 CSS와 정상 장면 구조는 유지하고, 정책상 차단 장면과 외부 설명만 정리했습니다.

공개 탐색 상태를 정확히 연결하기 위해 기존29장면에 최종동의대기 제3자·완료 제3자2장면을 추가했습니다. 모두 상세위치는 숨깁니다.
