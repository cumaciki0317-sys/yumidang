# 공고 상세 UI 검토 범위

장면의 단일 목록은 detail-model.js의 scenarios(32개)다. 로그인·역할·신청·동의 대기·확정·마감·거절·철회 대기·분쟁·완료·삭제·오류를 선택하여 확인한다.

확인 모달·접기·공고 관리 메뉴·목록 복귀만 UI 동작이다. 확정요청·거절·마감·재개·삭제 확인으로 업무 상태를 변경하지 않는다. 결과는 장면 선택으로 확인한다. 다른 앱 화면 이동은 목적지 설명만 제공한다. 개인정보 DOM 제외와 장면별 공개범위는 테스트한다. 실제 Expo/서버 상태 전환 검증이 아니다.

만료 시각은 선택된 고정 장면의 기준 시각에서 파생한 표시값이다. 실제 현재 시각·타이머로 만료하거나 수락 가능 여부를 결정하지 않으며 장면별 버튼 상태는 선택된 장면 키로만 정한다.
