# 공고 상세 기준 시안

기준 화면은 [유미당-공고상세.html](유미당-공고상세.html) 하나입니다.

- 둘러보기는 이 원본을 `?connected=1` iframe src로 열어 같은 상세 디자인과 상태 장면을 사용합니다.
- `listing-map.js`는 선택된 합성 공고 정보를 상세 표시 예시에 맞추는 연결 자료입니다.
- 독립 열기에서는 31개 상태 검토와 상세 다시 열기를 유지합니다.
- 구버전 생성 템플릿과 차단용 build.py를 삭제했습니다.
- 공통 자산 참조를 위해 extracted 폴더 구조를 함께 전달합니다. 실제 Expo 연결 완료를 뜻하지 않습니다.

이전 하위 분리 CSS·JS는 실행 중인 화면에서 참조하지 않음을 확인하고 제거했습니다. 하위 폴더의 자산과 과거 테스트·검증 문서는 보존 자료이며 최신 구현 기준이 아닙니다. 과거 테스트는 제거된 소스를 대상으로 하므로 현재 화면 검증에 사용하지 않습니다.
