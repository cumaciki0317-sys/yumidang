# 성호 디자인 작업 지침

이 폴더 편집 전 [UI_SCOPE.md](UI_SCOPE.md)를 읽고 그 범위만 작업한다. Expo는 기능 기준, 이 폴더는 디자인/고정 상태 시안이다. 업무 엔진·인증·앱 전체 라우팅을 재구현하지 않는다. 상태별 UI와 승인된 인터랙션은 보존한다. 소유권 검사와 check_ui_scope.py 검사를 수행한다. 공통 hook/설정은 바꾸지 않는다.

## 화면 확정 후 디자인시스템 동기화

사용자가 화면을 확정하고 다음 화면으로 넘어갈 때는 디자인시스템 갱신까지 해당 작업의 완료 범위에 포함한다. 현재 소스의 최종 CSS·표시 상태·승인 인터랙션을 대조해 기존 규칙을 수정하고, 변경된 규칙을 과거 설명 아래에 덧붙이기만 하지 않는다. `html/extracted/유미당-디자인시스템/유미당-디자인시스템/`의 가이드·토큰·화면 참조 및 Expo 인계를 함께 갱신한다. 화면별 예외를 전역 규칙으로 확대하지 않으며, 미확정 사항과 Expo 미적용 상태를 구분한다. 소스 경로·상태별 표시·컴포넌트 입력/이벤트·검증 범위를 남기고 참조가 유효한지 확인한다. 실제 Expo 코드·정책·백엔드는 이 동기화에 포함하지 않는다.
