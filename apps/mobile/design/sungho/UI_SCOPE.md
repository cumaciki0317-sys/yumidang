# 성호 UX/UI 작업 범위

사용자 확정 기준: 2026-10-13. 목표는 승인된 디자인을 기존 Expo에 적용하도록 준비하는 것이다.

## 허용
- 해당 Expo 화면·정책은 읽기 기준. 승인 디자인의 글꼴·색·여백·배치와 상태별 표현을 정리한다.
- 탭·접기·메뉴·모달·포커스·누름 효과·입력 피드백·로컬 사진 표시를 유지한다.
- 로딩/오류/빈 화면/비활성/권한별 노출/완료/만료 등은 검토 패널의 고정 장면으로 확인한다.
- 표시 컴포넌트는 props 값과 이벤트만 받는다. 연결 대상 Expo 이벤트와 필수 값은 간단히 기록한다.
- 사용자가 승인한 둘러보기↔상세 시트 연결만 화면 구성 검토를 위해 유지한다.

## 하지 않음
- HTML 로그인 성공 분기, 앱 전체 라우팅, 공유 세션/저장소, 검색/정렬 엔진, 메시지 누적, 신청 생성, 약속 만료·충돌 계산을 구현하지 않는다.
- 제품 기능을 추정해서 추가하지 않는다. 실제 Expo 화면·상태·API·인증·DB·정책·공통 설정·hook을 수정하지 않는다.
- HTML 전체 흐름 동등성을 디자인 완료 조건으로 삼지 않는다. 요청 없는 새 화면/문서/테스트 확대를 하지 않는다.

## 변경 및 누락 방지
1. 대상 화면과 Expo 근거, 바꿀 UI를 먼저 특정하고 소유권 검사한다.
2. 기존 장면 목록과 입력/버튼/피드백을 유지한다. 처리 코드 삭제 시 대응 결과 장면이 선택 가능한지 확인한다.
3. 업무 버튼은 이벤트 안내 또는 폼 열기만 한다. 결과는 검토 패널에서 선택한다.
4. 디자인 정리/표시 컴포넌트 준비/Expo 적용을 구분한다. 실제 Expo 연결 후 회귀 검수는 담당자 작업이다.
5. python3 apps/mobile/design/sungho/check_ui_scope.py 를 실행한다. 검사는 알려진 초과 구현 패턴을 찾는 보조장치이며 자동 보안 경계가 아니다.

최상위 AGENTS와 소유권 규칙이 계속 적용된다. 이 문서는 권한 확대가 아니다. 새로운 사용자 지시 없이 위 범위를 넓히지 않는다.

## 단순화 적용 확인

- 로그인 분기/가입 성공 이동, 앱 간 저장/라우팅, 채팅 메시지 누적 및 약속 시간 계산 제거.
- 홈 4상태, 둘러보기 15장면, 공고상세 31장면, 채팅 대화12·약속9장면, 행사목록18장면, S13 12장면을 검토 선택으로 유지. 인증 기존 오류/로딩/완료 선택도 유지.
- 폼·입력 피드백·탭·메뉴·모달·토글·승인 디자인 보존. 상세 fixed-scene 시각 파생은 표시용이며 실시간 업무 판정 아님.
- 화면별 상태 보존 검사, 연결 시트 검사, 범위 검사 통과. root 브라우저에서 채팅 확정 표시·변경 입력폼 확인. Expo 런타임 전체 동등성 검증을 뜻하지 않음.
- 범위 검사는 수동 실행 보조 검사이며 OS/공통 hook 강제 차단이 아니다. 공통 설정은 그대로다.

## 서비스 문구와 검토 설명 분리
- 화면 내부·모달·메시지·버튼 피드백에는 실제 사용자에게 제공할 문구만 표시한다.
- 고정 예시·미구현·이벤트 연결·실제 처리하지 않음 등 구현/검토 설명은 검토 패널에만 표시한다. Expo 적용 대상 UI에 섞지 않는다.
