# 평가·공개 후기 계약

2026-09-29 사용자 정정 기준. 이번 정책 변경은 승인된 하네스의 담당 경계 예외를 적용한다. 기존 SQL과 과거 인계는 보존하며 실제 검증 결과는 [새 인계](../../docs/collaboration/requests/jonghyun/2026-09-29-review-policy-handoff.md)를 따른다.

## 제출과 공개

양쪽 후기를 제출하면 완료 알림 기준 24시간 전이어도 즉시 공개한다. 한쪽만 제출하면 완료 알림 확인 가능 시각 +24시간부터 공개하고, 그 이후 작성 기한 안에 제출한 후기는 즉시 열람할 수 있다. 미완료·실제 분쟁·불발/노쇼는 제외하며 수동 완료는 양측 완료 확인을 요구한다. 일반 후기 작성 기간은 실제 완료 시각부터 7일이다. 분쟁 중 작성·기한·공개 보류, 동행 인정 후 남은 기간 재개·최소 24시간 보장의 기존 예외는 유지한다.

완료 후 작성 기간 안의 당사자만 제출한다. 제출 성공 후 수정은 금지하고 동일 요청 재시도는 같은 결과로 처리한다. 분쟁 중 작성·기한·공개를 보류하고 동행 인정 후 남은 기간 재개·최소 24시간 보장 규칙을 유지한다. 상세 입력·오류와 HTTP 경로는 [서비스 API](service-api.md), DB 호출·칭찬·공개 페이지 응답은 [후기 자동화 DB](review-automation-db.md)를 따른다.

양쪽 제출/7일 경과를 기다리던 이전 gate는 폐기한다. 기존 policy 대기 후보에도 새 조건을 적용한다. 명시적 override 숨김과 공개 후보가 없는 과거 후기는 자동 공개하지 않는다. 상대 열람과 제3자 공개의 권한 경계는 유지하고 공개 시점 조건은 일치시킨다. 공개 조건은 제출·조회에 적용하므로 물질화 정리나 하루 한 번 AI 작업까지 기다리지 않는다.

## 공개 원문과 요약

공개 프로필·칭찬 집계·AI 입력은 동일한 현재 공개 적격성을 확인한다. 한마디 없는 공개 평가는 칭찬 집계에는 포함하고 AI 입력에서는 제외한다. 공개 한마디 3개 이상일 때만 요약 후보가 된다. 원문 변경·숨김·분쟁으로 revision을 증가시키고 오래된 요약 게시·열람을 차단한다. 로그·작업 payload에 후기 원문을 넣지 않는다.

공개 정리 RPC는 모델 설정 없이 실행한다. AI 요약 등록은 별도 RPC와 하루 한 번 주기를 사용하며 모델 생성·실제 품질·운영 일일 스케줄러 배포는 이번 변경의 성공으로 간주하지 않는다. 당도 산식과 완료 횟수의 반영 보류는 후기 공개와 구분한다.

## 검증·화면 인계

양쪽 후기의 24시간 전 공개, 한쪽의 24시간 직전/경계/직후, 이후 제출의 즉시 열람, 실제 완료+7일 작성 종료, 분쟁·불발/노쇼·미완료 제외, policy 후보·override 보존과 공개/요약 적격성 일치를 확인한다. API 성공을 브라우저 UI 연결로 보고하지 않는다. 화면 담당은 유미·성호이며 이번 화면 연결은 미실행이다.
