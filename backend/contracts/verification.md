# 후속 선택 인증 계약

주담당: 민규. 기준: [정책.md](../../정책.md), [상세 설계](../../PLAN_상세설계.md). 이 문서는 현재 확정 정책을 구현할 계약이다. API·SQL·배포를 이번 문서 작업에서 수정하거나 검증하지 않았다.

## 현재 제공 범위

현재는 네이버 로그인과 무료 1:1 동행만 제공한다. 학교·직장 이메일 배지와 계좌 인증은 현재 가입·동행 흐름에 요구하지 않는다. 네이버 가입 자격은 [가입 계약](signup.md)을 따른다.

## 추후 도입 검토

- 학교·직장 이메일 인증의 지원 기관·효력·갱신·코드 만료·재시도 기준은 추후 검토다. 질문지에 제안됐던 1년 갱신을 운영 기본값으로 확정하지 않는다.
- 유료 동행은 추후 도입이며 유료 동행 신청·제안을 하려는 이용자는 1원 계좌 인증을 받아야 한다. 이는 현재 유료 기능 활성화 승인이 아니다.
- 추후 도입 시 무효로 확인된 계좌의 인증 배지는 숨긴다. 조회 실패·확인 불가를 무효 또는 정상으로 단정하지 않는다.
- 계좌 명의 대조·공급사·효력·갱신·취소, 인증 후 효력 상실과 진행 중 신청·최종 확정·상대 안내는 팀 검토다. 인증 성공·실패를 가상 응답으로 대신하지 않는다.
- 사업자·법인 회원·계좌, 수수료·플랫폼 결제·대금 보관·정산·환불 구조는 모두 후속 팀 검토다.

## 연결 시 작성할 기술 계약

실제 도입 결정 후 호출 주체·신뢰된 공급사 응답·동일 거래 귀속·중복 요청·재시도, 본인용 상태와 공개 배지 분리, 실패 시 입력 보존과 직접 재제출, 민감정보 비기록을 명시한다. 공급사 지원·계약·요금·실제 연결 결과와 정책 선택을 구분한다. 기존 port·adapter 파일 존재는 도입·검증 완료가 아니다.
