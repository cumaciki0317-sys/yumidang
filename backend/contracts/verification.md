# 현재 제외한 인증 기능의 경계

현재 기준은 [정책.md](../../정책.md)다. 아래에서 현재 정책 목표와 기존 기술 인터페이스를 구분한다. 이번 문서 동기화는 서버 코드·SQL·설정·DB·외부 호출·배포를 변경하거나 검증하지 않았다.

현재 가입·로그인·자격 확인은 [네이버 가입 계약](signup.md)만 사용한다. 학교·직장 이메일, 별도 휴대폰 본인인증, 1원 계좌 인증과 유료 동행·결제·정산은 현재 화면·이용 흐름에서 제외한다. 기존 인증 모듈·양식·테스트의 존재는 활성화나 후속 도입 확정이 아니다.

추후 도입은 별도 정책과 실제 진입 경로가 설계될 때 계약을 새로 정한다. 현재 무료 공고 작성·신청·최종 동의에 계좌·학교/직장 인증 단계를 추가하지 않는다. 인증 결과·배지를 가상 응답으로 만들어 제공하지 않는다.

기존 비상용 테스트 함수의 원격 활성화·발급 세션 상태는 인증 담당이 별도 확인한다. 이번 문서 정리로 코드·계정·원격 설정을 삭제하거나 비활성화했다고 보고하지 않는다.
