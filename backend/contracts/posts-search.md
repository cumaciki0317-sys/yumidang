# 공고 작성·공개 데이터 계약

주담당: 민규. 기준: [정책.md](../../정책.md), [상세 설계](../../PLAN_상세설계.md). 이 문서는 현재 확정 정책을 구현할 계약이다. API·SQL·배포를 이번 문서 작업에서 수정하거나 검증하지 않았다. 검색의 실제 API·카드·커서는 [검색 계약](search.md)을 함께 따른다.

## 작성·등록

현재 무료 동행만 작성한다. 카테고리·제목·소개·장소·시작/종료 날짜와 시간은 필수이며 종료가 시작보다 늦어야 하고 자정을 넘길 수 있다. 유료 유형·금액 입력은 현재 제공하지 않는다. 모집 마감은 선택이며 생략하면 시작 시각, 입력하면 시작 시각 이하여야 한다.

장소명은 Kakao Local 검색·선택, 주소는 Kakao 우편번호 서비스, 상세 만남 지점은 별도 입력한다. 카카오 장소 사용은 로그인 제공사와 별개다. 행사 연결은 선택이며 기존 입력·일정을 자동 변경하지 않는다. 성공하면 상세로 이동하고 실패하면 입력을 유지한다. 카테고리 실제 목록·항목별 글자 수는 팀 검토이며 기존 코드 제한을 새 제품 확정값으로 확대하지 않는다.

제목의 정확한 주소·상세 만남 지점 또는 본문의 전화번호·계좌·정확한 주소·상세 지점을 탐지하면 해당 부분을 안내하고 수정 전 등록을 막는다. 입력은 보존하고 오탐 문의를 제공한다. 탐지·오탐 세부 기준은 팀 검토다.

## 공개와 검색

공고 키워드는 제목·등록 장소명·등록 주소·연결된 행사명에 일치시킨다. 소개·후기·상세 만남 지점은 제외한다. 주소 검색에 일치해도 정확한 주소를 공개하지 않는다.

비로그인 공고 목록·상세는 시스템 별칭, 로그인 미확정 상대는 이름 마스킹, 양측 확정 당사자에게만 네이버 전체 이름과 정확한 주소·상세 지점을 제공한다. 일반 공개 지역은 동까지다. 취소 이후 해당 관계의 추가 공개는 종료한다.

등록일 최신순 기본·시작일 빠른순 선택, 전체 모집 상태 기본·모집 중만 보기 선택이다. 회원 나이 필터는 공고 작성자의 만 나이 19~99세 숫자 범위이며 전체에는 상한을 적용하지 않는다. 비로그인은 나이 전체만 사용한다. 주변·반경·거리순은 제공하지 않는다. 목록 더 보기·AI 추가 요청 수량은 팀 검토다.

## 수정·마감·삭제와 임시저장

확정 전 수정 가능하되 핵심 조건 변경은 기존 신청자 알림·진행 중 동의 무효화·새 조건 재동의를 요구한다. 수동 모집 마감은 새 신청만 막고 기존 신청·대화는 유지한다. 삭제는 일반 목록 숨김이며 미확정 신청·동의 종료, 대화 읽기 전용 전환과 참여자 알림을 수반한다. 확정된 약속 종료 전 공고 삭제는 막고 삭제로 약속을 취소하지 않는다. 영구 삭제·보관 기간은 별도 팀 검토다.

공고 임시저장은 같은 기기에만 저장하고 재진입 시 복구를 안내한다. 등록 성공·직접 삭제·로그아웃·기한 만료 때 삭제하며 삭제 후 복구하지 않는다. 개수·기한은 팀 검토다. 최근 검색도 기기 저장·개별/전체 삭제·로그아웃/기한 만료 삭제·복구 없음이며 개수·기한은 팀 검토다.

## 실제 API 차이

현재 `create_service_post`의 필드와 길이·타입 제한은 [서비스 API](service-api.md), 실제 저장·권한은 [핵심 DB](core-service-db.md)에 명시한다. 연결 행사명 검색·19~99 범위·선택 마감 기본값·수정/삭제의 새 규칙은 실제 코드/SQL 적용과 확인이 별도로 필요하다.
