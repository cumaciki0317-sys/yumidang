# 새 로컬 가상 데이터

## 현재 정책별 가상 자료

가입은 여성·만 19세 이상·네이버 계정당 하나·필수 사진을 기준으로 정상/누락/자격 미충족 사례를 분리한다. 현재 공고는 무료 1:1만 사용하고 유료·이메일 인증은 후속 기능의 별도 가상 사례로 구분한다. 검색은 작성자 만 나이 19~99 숫자 범위·연결 행사명, 후기는 개인 확인 후 선제 제출/양측 완료/24시간 공개/6개 칭찬 경계를 준비한다. 실제 회원 채팅·캡처를 seed로 복사하지 않는다. 이 문서 변경으로 seed나 테스트가 생성된 것은 아니다.

담당: 이 안내와 로드 설정은 민규만 수정한다. 민규 데이터는 `minkyu/`, 종현 데이터는 `jonghyun/`에 각각 작성한다. 다른 담당의 파일을 수정하지 않는다.

실제 사용자 정보를 복사하지 않는다. 회원·공고·매칭·후기는 민규, 행사·AI·작업 사례는 종현이 작성한다. 데이터 파일명과 로드 순서는 로컬 환경 구성 시 확정한다. 기존 테스트 인증을 네이버 정보·가입 자격 확인 완료로 취급하지 않는다. 현재 seed SQL은 없으며 자동 실행하지 않는다.
