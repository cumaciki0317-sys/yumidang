# 로컬 합성 자료 작성 기준

기준은 [정책](../../../정책.md)이다. 실제 회원 정보·채팅·신고 캡처·외부 키를 복사하지 않는다. 합성 자격 자료·Auth 세션은 실제 네이버 정보 수신·회원 자격 확인 성공이 아니다.

민규 자료는 `minkyu/`, 종현 자료는 `jonghyun/`에 작성한다. 코드/seed 변경은 각 소유권과 별도 구현 하네스를 따른다. 이 문서 수정은 seed 생성·로드·DB 실행을 포함하지 않는다.

현재 무료1:1·네이버 계정당1명·성인여성·필수사진과 정상/정보누락/자격미충족을 분리한다. 검색의19~99범위·전체상한없음·익명일정/나이전체·작성자가드, 첫채팅성공신청·기존방재사용·6시간동의, 실제완료/미완료선제후기·양쪽즉시/한쪽작성기한종료·공개3개요약·6개칭찬·확정당도 경계를 준비한다. 신고검토 중 기존공개유지와 운영자임시숨김도 분리한다.

현재 제외한 인증·유료 흐름을 정상 서비스 fixture로 넣지 않는다. 로드 설정·실제 자료 생성/정리는 별도 담당 작업이며 실행 결과를 따로 기록한다.
