# AI 에이전트 구현 위치

기준은 [정책](../../../../../../정책.md)·[탐색 계약](../../../../../contracts/ai-chat.md)·[요약 계약](../../../../../contracts/review-summary.md)이다. 네이버 가입 회원의 무료 동행/행사 탐색과 공개 텍스트 후기3개 이상 요약을 처리한다. 최신 정책의 실제 코드·모델·DB·배포 일치는 별도 검증이다.

- [chatbot/](chatbot/): 현재 화면 문맥·자연어 조건·허용 공개 검색·카드/설명·출력 검사.
- [review-summary/](review-summary/): 적격 후기 전체 분할·근거 검사·최대300자 요약·현재 revision 조건부 게시.
- [../providers/](../providers/): 공통 모델 계약·공급사 연결·예산·오류 처리.

탐색 진입점은 `functions/ai-chat/`, 요약은 `functions/review-summary-worker/`이며 중복 폴더를 만들지 않는다. 숫자 나이·익명 공개 권한·현재 정책의 한쪽 작성기한 종료 공개는 기존 공통 계약을 대조한다.

회원 AI 한도는 초기20회/일·KST자정 초기화·분당제한없음·회원당진행요청1개다. 모델 없는 조건 버튼/더보기는 미차감, 모델 처리를 시작한 새 사용자 요청은1회이며 내부 여러호출/자동재시도는 추가 차감하지 않는다. 계정 포함량50%·추가결제없음으로 시작하고 실제 연결 후 공급사일한도/토큰비용을 확인해 재설정한다.

탐색은20메시지·각500자·전체4,000자 화면메모리만, 후보10개씩3쪽·표시5개다. 재조회·일부확인·설명실패·개인정보입출력 차단은 탐색 계약을 따른다. 두 AI 가입필수동의 의도와 가입후철회처리중단·계정유지를 함께 기록하고 법적 정합성 확인 전 관련 가입 차단·외부 전송을 시행하지 않는다.

공급사 포텐스닷·Sonnet5 선택과 실제 지원은 별개다. 보관 회신 검토·사용자 확인 전 실회원 원문 전송은 보류하며 합성만 사용한다. 초기 품질지표는 영구 저장하지 않는다. 회원 채팅·실명·연락처·비공개 지점은 모델/로그에 넣지 않는다.
