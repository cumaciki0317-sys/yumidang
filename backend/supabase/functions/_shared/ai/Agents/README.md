# AI 에이전트 구현 위치

## 2026-10-20 현행 기준과 이 문서의 적용 범위

이 문서는 현재 요구와 구현 계약을 구분한다. 아래 기술 시그니처·기존 SQL·검증 기록은 실제 구현 근거이며 새 정책 요구가 자동 구현됐다는 뜻이 아니다.

- 담당은 현재 민규=BE·AI·검색·행사·서버 운영, 종현=FE·UX/UI·앱 API/세션 소비·빌드, 유미=UT·출시/지원 책임이다. 아래 옛 종현 BE·성호 UI 배정은 당시 기록이며 현재 실행 권한으로 사용하지 않는다. 구체 파일은 현행 소유권 정책을 따른다.

- 포텐스닷 문의 회신은 사용자가 공유했다. 공급사는 교육·프로토타입 범위, 일일/기간 제한·기능 축소·보안 우려로 공개 서비스에는 다른 API를 권고했다. 보관·학습·삭제·공동 사용의 구체 조건은 여전히 미확인이다. 포텐스닷 제품 활성화를 기다리는 계획으로 읽지 않는다. Gemini는 종현 테스트 전용 프로젝트에 결제 연결·월50,000원 사용중단 예산을 준비했으나 최종 청구가 지연 없이 반드시 5만원 이하라는 보장은 아니다. 합성 테스트와 대표 유미 계정 전환·제품 adapter·실회원 전송은 별도다. 대표 계정 전환은 회의/브랜치 통합 때 진행한다. Potens 기술 토큰 원장과 Gemini 원화 지출 원장은 분리한다.

- AI 탐색 동의는 첫 사용 시 받고 거절하면 일반 검색을 유지한다. 후기 요약은 가입 시 열람·내 프로필 생성/노출·작성 후기 활용을 기본 미선택인 별도 선택 세 항목으로 받는다. 전체 동의와 개별 자세히 보기를 유지하고 미동의 가입/일반 동행을 허용한다. 세 동의의 철회는 독립적이다. 현재 서버의 summary_allowed 하나·review_summary 일괄 철회가 이 세분화 요구를 구현했다고 해석하지 않는다. 테스트 계정 동의 간주는 실제 동의 증거·DB 값 변경·회원 원문 전송 승인이 아니다.

- 직접 입력 행사는 해당 공고에만 저장/표시하며 공용 목록·별도 행사 상세·검수 후 공용화는 만들지 않는다. 행사명 필수, 공개 행사장 장소/주소 선택이며 개인 주소를 금지한다. 새 연결은 예정/진행 중만 허용하고 종료·공식취소·연기일정미정은 제한한다. 단순 검색 누락은 취소/비표출이 아니다. 제공기관 비표출 원천의 정보와 상세 진입만 숨기고 공고/독립 만남 장소·다른 유효 공개 원천은 유지한다. 공식 동일 개최 식별근거만 통합에 사용하고 원천ID·공고관계·필드출처·가역 이력을 보존한다. 현재 eventId UUID 저장을 직접 입력·통합·비표출 구현 완료로 표시하지 않는다.

최신 기준: [정책.md](../../../../../../정책.md). 구현과 남은 조건: [서버·DB 대조 원장](../../../../../../docs/collaboration/requests/jonghyun/2026-10-20-policy-implementation-audit/server-audit.json).


## 2026-10-20 행사 UX 확정과 서버 구현 경계

기준은 [최종 행사 UX 확정](../../../../../../docs/collaboration/requests/jonghyun/2026-10-20-event-ux-approved-spec.md)이다. 사용자 명시 전체 문서 동기화 승인으로 반영하며 제품 설계 확정과 실제 코드·DB·배포 완료를 구분한다.

행사와 동행 일정 겹침 강제·행사 검색 동행 일정 자동 축소는 적용하지 않는다. 행사 기간을 약속 시간으로 대신 생성하지 않는다. 공식 동일 개최 근거 통합·원천별 비표출/핵심 충돌·직접입력 공고 전용 범위는 서버 공개 계약에 따라 소비해야 한다. 새 DTO·AI 소비·알림/변경계약은 민규 후속 구현·검증이며 아래 에이전트 구성 존재만으로 지원·외부 전송·운영 활성화를 주장하지 않는다.


기준은 [정책](../../../../../../정책.md)·[탐색 계약](../../../../../contracts/ai-chat.md)·[요약 계약](../../../../../contracts/review-summary.md)이다. 네이버 가입 회원의 무료 동행/행사 탐색과 공개 텍스트 후기3개 이상 요약을 처리한다. 최신 정책의 실제 코드·모델·DB·배포 일치는 별도 검증이다.

- [chatbot/](chatbot/): 현재 화면 문맥·자연어 조건·허용 공개 검색·카드/설명·출력 검사.
- [review-summary/](review-summary/): 적격 후기 전체 분할·근거 검사·최대300자 요약·현재 revision 조건부 게시.
- [../providers/](../providers/): 공통 모델 계약·공급사 연결·예산·오류 처리.

탐색 진입점은 `functions/ai-chat/`, 요약은 `functions/review-summary-worker/`이며 중복 폴더를 만들지 않는다. 숫자 나이·익명 공개 권한·현재 정책의 한쪽 작성기한 종료 공개는 기존 공통 계약을 대조한다.

회원 AI 한도는 초기20회/일·KST자정 초기화·분당제한없음·회원당진행요청1개다. 모델 없는 조건 버튼/더보기는 미차감, 모델 처리를 시작한 새 사용자 요청은1회이며 내부 여러호출/자동재시도는 추가 차감하지 않는다. 등록 계정별 한국시간 하루320만 토큰·전체 등록 계정 상한 합계를 함께 검사하고 추가 결제는 하지 않는다. 계정 전송 전 예산이 부족하면 다음 등록 계정을 선택하며 전송 후 오류·응답 유실의 무조건 전환은 금지한다. 실제 포함량·공급사 조건·초기화·계정별 원장·런타임을 검증하고 실제 연결 후 일일 한도·토큰 비용을 측정해 재설정한다.

탐색은20메시지·각500자·전체4,000자 화면메모리만, 후보10개씩3쪽·표시5개다. 재조회·일부확인·설명실패·개인정보입출력 차단은 탐색 계약을 따른다. 탐색은 첫 사용 동의·거절 시 일반 검색 유지다. 후기 요약은 가입 시 열람·내 프로필 생성/노출·작성 후기 활용을 별도 선택 세 체크와 전체 동의로 받고 작성 때 활용 안내만 반복한다. 세 동의는 독립 철회하며 원문 활용 철회는 해당 근거 제외·영향 요약 우선 숨김·남은 허용 공개 텍스트3개 이상 및 현재 동의 조건 충족 후 재생성·공개다. 계정·일반 동행·일반 후기·별점·당도는 유지한다. AI용 사본·외부 사본의 필요한 삭제는 확인 전 완료로 표시하지 않는다. 테스트 계정 동의 간주는 합성 시나리오 한정이며 실제 동의 증거를 대신하지 않는다. AI 미동의를 이유로 가입을 거부하거나 일반 동행·계정을 차단하지 않고 미동의 항목에 해당하는 AI 기능만 제한한다. 동의의 법적 분류·문구·공급사 확인 전 회원 원문 외부 전송 보류를 유지한다. 이 문서의 정책 동기화는 세분화 동의 저장·철회·열람 제한이 현재 코드·DB에 구현됐다는 뜻이 아니며 민규의 별도 구현 대조·검증이 필요하다.

포텐스닷·Sonnet5 코드는 교육·프로토타입 경로다. 사용자가 공유한 회신을 반영해 공개 서비스는 다른 API의 구체 조건을 확인한 뒤 연결하며 그 전 실회원 원문 전송은 보류하고 합성만 사용한다. 초기 품질지표는 영구 저장하지 않는다. 회원 채팅·실명·연락처·비공개 지점은 모델/로그에 넣지 않는다.
