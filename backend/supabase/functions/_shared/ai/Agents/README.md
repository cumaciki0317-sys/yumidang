# 유미당 AI 에이전트 구현 위치

## 현재 기능·정보 경계

기준은 [정책.md](../../../../../../정책.md)와 [AI 탐색 계약](../../../../../contracts/ai-chat.md), [요약 계약](../../../../../contracts/review-summary.md)이다. 네이버 가입을 마친 회원의 무료 1:1 공고·행사 탐색과 공개 후기 요약을 제공한다. 탐색은 실제 카드에 근거한 추천 이유·확인할 점을 작성하며, 관심사·대화 방식은 의미 유사성·MBTI는 정확 일치, 미입력은 확인 필요로 남긴다. 숫자 나이 19~99·연결 행사명 검색의 기존 코드 반영은 별도다. AI 정렬·재확인·일부 결과·실패 세부는 팀 검토다.

회원 간 채팅·실명·연락처·계좌·비공개 만남 지점은 AI 입력에 넣지 않는다. 탐색 원문은 현재 화면 메모리만 사용하고 서버 로그에 저장하지 않는다. 개인 연락처 등은 외부 전송 전 차단·수정 안내, 출력 발견 시 응답 숨김·재시도 안내를 적용한다. 탐지·오탐·재시도 한도는 팀 검토다.

모델은 포텐스닷 Sonnet 5이며 실제 회원 정보 전송은 보관 조건 팀 검토·사용자 확인 전 보류하고 합성 입력만 사용한다. 초기 추가 지출은 0원, 운영 수치·품질·보관 세부는 팀 검토다. 요약은 한마디 있는 적격 공개 후기 3개부터이며 개인 완료 후 선제 제출된 미완료 후기를 읽지 않는다. 실제 완료·후기 공개 시각은 DB 정책을 따르고 에이전트가 대신 결정하지 않는다.


담당: 종현담당 · 상태(2026-09-30): AI 탐색(C 방식 의미 비교 포함)·후기 요약 worker·포텐스닷 어댑터·예산 포트를 구현하고 가상 검사와 로컬 DB(제안 SQL) 검증을 마쳤다. 해당 시점 실제 모델 호출·허용 목록/정식 마이그레이션·Edge 배포는 대기였다. 이번 문서 작업에서는 현재 런타임이나 운영 활성화를 검증하지 않았다. [인계](../../../../../../docs/collaboration/requests/jonghyun/2026-09-29-claude-implementation-handoff.md)

- [chatbot/](chatbot/): 자연어 탐색 에이전트. 문맥 구성·조건 해석·공개 검색 도구·결과 카드·출력 검증 파일 8개.
- [review-summary/](review-summary/): 공개 리뷰 요약 에이전트. 원문 조회·3개 기준·요약·근거 검증·조건부 게시 파일 7개.
- [../providers/](../providers/): 두 에이전트가 사용하는 모델 계약·제공사 어댑터·오류 변환 파일 3개.

탐색 요청 진입점은 `functions/ai-chat/`, 요약 작업 진입점은 `functions/review-summary-worker/`에 유지한다. 두 진입점은 구현됐으며 실제 Edge 실행은 민규 연결 후 검증한다. 기존 `ai/chatbot/`과 `ai/review-summary/`의 구현용 파일을 이곳으로 이동했으므로 이전 위치에 중복 구현하지 않는다.
