# 유미당 AI 에이전트 구현 위치

담당: 종현담당 · 상태: AI 탐색·후기 요약의 내부 코어와 모델 라우터 구현, 가상 의존성으로 검증. 실제 모델·HTTP·DB 연결과 운영 검증은 대기.

- [chatbot/](chatbot/): 자연어 탐색 에이전트. 문맥 구성·조건 해석·공개 검색 도구·결과 카드·출력 검증 파일 8개.
- [review-summary/](review-summary/): 공개 리뷰 요약 에이전트. 원문 조회·3개 기준·요약·근거 검증·조건부 게시 파일 7개.
- [../providers/](../providers/): 두 에이전트가 사용하는 모델 계약·제공사 어댑터·오류 변환 파일 3개.

탐색 요청 진입점은 `functions/ai-chat/`, 요약 작업 진입점은 `functions/review-summary-worker/`에 유지한다. 두 진입점은 아직 미구현 골격이며, 공통 인증·DB와 실제 모델 제공사 연결 후 검증해야 한다. 기존 `ai/chatbot/`과 `ai/review-summary/`의 구현용 파일을 이곳으로 이동했으므로 이전 위치에 중복 구현하지 않는다.
