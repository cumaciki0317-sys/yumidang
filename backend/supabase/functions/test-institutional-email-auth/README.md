# 기관 이메일 테스트 함수 — 현재 서비스에서 제외

## 2026-10-20 현행 기준과 이 문서의 적용 범위

이 문서는 현재 요구와 구현 계약을 구분한다. 아래 기술 시그니처·기존 SQL·검증 기록은 실제 구현 근거이며 새 정책 요구가 자동 구현됐다는 뜻이 아니다.

- AI 탐색 동의는 첫 사용 시 받고 거절하면 일반 검색을 유지한다. 후기 요약은 가입 시 열람·내 프로필 생성/노출·작성 후기 활용을 기본 미선택인 별도 선택 세 항목으로 받는다. 전체 동의와 개별 자세히 보기를 유지하고 미동의 가입/일반 동행을 허용한다. 세 동의의 철회는 독립적이다. 현재 서버의 summary_allowed 하나·review_summary 일괄 철회가 이 세분화 요구를 구현했다고 해석하지 않는다. 테스트 계정 동의 간주는 실제 동의 증거·DB 값 변경·회원 원문 전송 승인이 아니다.

최신 기준: [정책.md](../../../../정책.md). 구현과 남은 조건: [서버·DB 대조 원장](../../../../docs/collaboration/requests/jonghyun/2026-10-20-policy-implementation-audit/server-audit.json).


현재 로그인은 [네이버 전용](../../../../정책.md)이며 학교·직장 이메일 인증은 현재 서비스에서 제외한다. 이 함수는 로그인 대안이나 현재 배지 발급 경로로 연결하지 않는다. 실제 이메일 소유·재학·재직·가입 자격을 검증한 것으로 표시하지 않는다.

## 남아 있는 코드의 성격

이 함수는 인증된 사용자용 테스트 검사다. 실제 메일을 보내지 않고 고정 코드 `246810`을 사용한다. 기존 코드가 요구하는 `TEST_INSTITUTIONAL_EMAIL_AUTH_ENABLED`, `TEST_INSTITUTIONAL_EMAIL_AUTH_EXPIRES_AT`과 JWT 검사는 실제 소유 확인을 대체하지 않는다. 브라우저에 서비스 키·원본 JWT·저장 이메일 기록을 전달하지 않는 경계는 유지한다.

코드·원격 배포·환경 설정은 이번 문서 작업에서 삭제하거나 변경하지 않았다. 기존 활성화 상태의 점검·정리는 별도 작업이며 이 안내로 함수를 새로 배포·활성화하지 않는다. 추후 도입 시 지원 기관·효력·갱신·코드 처리와 실제 발송 제공사를 별도로 검토한다.
