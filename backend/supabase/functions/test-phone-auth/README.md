# 테스트 전화 인증 — 현재 서비스 제외

현재 가입·로그인·자격은 [네이버 정책](../../../../정책.md)을 따른다. 이 임의 번호·고정 코드 테스트 함수를 현재 로그인·자격 확인에 연결하지 않는다. 실제 번호 소유·네이버 필수 정보·여성 만19세·필수사진 확인을 대체하지 않는다.

기존 함수는 테스트 계정/세션을 만들 수 있는 코드다. 현재 원격 활성화·기존 발급 세션·잔존 계정 상태는 인증 담당의 별도 확인 대상이며 이 문서 정리로 코드·원격 설정·계정을 비활성화/삭제했다고 보고하지 않는다. 새 배포·환경 활성화 안내로 사용하지 않는다.

필요한 후속은 현재 호출 경로의 제외 확인과 기존 테스트 접근의 정리 범위를 정하는 것이다. 실제 회원 자료를 테스트 인증에 연결하지 않으며 비밀값을 브라우저·문서·Git에 넣지 않는다.
